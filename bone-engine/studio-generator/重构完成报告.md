### 2.2 核心功能

1. **领域模型**：
   - 聚合根：`CodeTemplate`、`DataSource`、`CodeGenerationHistory`
   - 值对象：`CodeGenerationRequest`、`CodeGenerationResponse`、`GeneratedFile`、`DatabaseTable`、`TableColumn`
   - 领域服务：`CodeGeneratorService`

2. **应用层**：
   - 命令处理器：`CreateDataSourceHandler`、`UpdateDataSourceHandler`、`DeleteDataSourceHandler`、`GenerateCodeHandler`
   - 查询处理器：`DataSourceByIdHandler`、`DataSourceListHandler`、`LoadTablesHandler`
   - UseCase：`TestConnectionUseCase`（Mode A）、`GenerateCodeUseCase`、`CreateDataSourceUseCase`、`UpdateDataSourceUseCase`、`DeleteDataSourceUseCase`（Mode B）

3. **适配器层**：
   - 控制器：`DataSourceController`、`CodeGeneratorController`
   - API 端点：`/api/data-sources`、`/api/code-generator`

4. **基础设施层**：
   - 服务实现：`CodeGeneratorServiceImpl`
   - 配置：`application.yml`

### 2.3 技术特性

- **双模式 UseCase 策略**：Mode A（简单模式）和 Mode B（企业模式）
- **AI 能力集成**：使用 `@Capability` 注解标记可被 AI 发现的能力
- **CQRS 分离**：命令和查询处理器分离，实现读写分离
- **统一响应格式**：使用 `ApiResponse` 和 `PageResult`
- **事务管理**：命令处理器使用 `@Transactional` 注解
- **异常处理**：统一的异常处理机制
