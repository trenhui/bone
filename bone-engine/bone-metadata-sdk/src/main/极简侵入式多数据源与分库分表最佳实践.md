# 极简侵入式多数据源与分库分表最佳实践方案

## 方案概述

本方案基于业界最佳实践，整合**dynamic-datasource**动态路由与**Sharding-JDBC**分库分表能力，通过纯注解驱动方式实现极低业务代码侵入，覆盖读写分离、多租户、分库分表等高频场景，兼顾易用性与生产稳定性。

### 核心优势
- **极低侵入性**：纯注解驱动，业务代码几乎无需修改
- **声明式配置**：通过简单配置即可完成复杂的数据源管理
- **透明切换**：对业务层完全透明的数据源切换机制
- **高性能设计**：优化的连接池管理和数据源切换策略
- **完整生态支持**：与Spring Boot完美集成，支持各类ORM框架

## 三、自动路由配置

### 3.1 多租户自动路由配置

```java
/**
 * 多租户自动路由配置
 * 基于请求头的X-Tenant-ID自动识别租户并切换数据源
 * 注意：需要导入com.baomidou.dynamic.datasource.toolkit.DynamicDataSourceContextHolder
 */
@Configuration
public class TenantRoutingConfig {

    /**
     * 多租户请求拦截器
     */
    @Component
    public static class TenantInterceptor implements HandlerInterceptor {
        private static final Logger log = LoggerFactory.getLogger(TenantInterceptor.class);
        private static final String TENANT_ID_HEADER = "X-Tenant-ID";
        private static final String TENANT_DATASOURCE_PREFIX = "tenant_";

        @Override
        public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
            String tenantId = request.getHeader(TENANT_ID_HEADER);
            if (tenantId != null && !tenantId.trim().isEmpty()) {
                String datasourceName = TENANT_DATASOURCE_PREFIX + tenantId;
                try {
                    DynamicDataSourceContextHolder.push(datasourceName);
                    log.debug("Switched to tenant datasource: {}", datasourceName);
                } catch (Exception e) {
                    log.error("Failed to switch to tenant datasource: {}", datasourceName, e);
                    // 数据源不存在时不影响业务继续执行，使用默认数据源
                }
            }
            return true;
        }

        @Override
        public void afterCompletion(HttpServletRequest request, HttpServletResponse response, 
                                   Object handler, Exception ex) {
            // 确保清理线程上下文中的数据源信息
            if (!DynamicDataSourceContextHolder.isEmpty()) {
                DynamicDataSourceContextHolder.poll();
            }
        }
    }

    /**
     * 注册多租户拦截器
     */
    @Bean
    public WebMvcConfigurer tenantWebConfig(TenantInterceptor tenantInterceptor) {
        return registry -> {
            registry.addInterceptor(tenantInterceptor)
                    .addPathPatterns("/**")
                    .excludePathPatterns("/error", "/actuator/**");
        };
    }
}
```

### 3.2 自定义路由策略配置

```java
/**
 * 自定义数据源路由策略配置
 */
@Configuration
public class DataSourceRouteStrategyConfig {

    /**
     * 从库负载均衡策略 - 轮询
     * 注意：需要引入dynamic-datasource相关依赖以使用AbstractLoadBalanceAlgorithm
     */
    @Bean
    public DsLoadBalanceAlgorithm roundRobinLoadBalance() {
        return new AbstractLoadBalanceAlgorithm() {
            private final AtomicInteger counter = new AtomicInteger(0);

            @Override
            protected String doChoose(List<String> dsNames, String sql) {
                int index = Math.abs(counter.getAndIncrement() % dsNames.size());
                return dsNames.get(index);
            }
        };
    }

    /**
     * 基于SQL的数据源路由策略
     * 注意：SQLStatement需要引入相关SQL解析库，如JSqlParser
     */
    @Component
    public static class SqlBasedDataSourceRouter extends AbstractRoutingStrategy {
        @Override
        public String doRouting(SQLStatement sqlStatement) {
            String sql = sqlStatement.getSql();
            // 根据SQL内容进行路由
            if (sql.toUpperCase().contains("INSERT") || sql.toUpperCase().contains("UPDATE") 
                || sql.toUpperCase().contains("DELETE")) {
                return "master";
            }
            return "slave";
        }
    }
}
```

### 3.3 数据源动态管理

```java
/**
 * 数据源动态管理器
 * 支持运行时动态添加、修改、删除数据源
 * 注意：需要导入com.baomidou.dynamic.datasource.provider.DynamicDataSourceProvider
 * 和com.baomidou.dynamic.datasource.provider.YmlDynamicDataSourceProvider等相关类
 */
@Service
public class DynamicDataSourceManager {
    private final DynamicDataSourceProvider dataSourceProvider;
    private final DataSource dataSource;
    private static final Logger log = LoggerFactory.getLogger(DynamicDataSourceManager.class);
    
    @Autowired
    public DynamicDataSourceManager(DynamicDataSourceProvider dataSourceProvider, DataSource dataSource) {
        this.dataSourceProvider = dataSourceProvider;
        this.dataSource = dataSource;
    }
    
    /**
     * 添加数据源
     */
    public void addDataSource(String name, DataSourceProperty property) {
        if (dataSourceProvider instanceof YmlDynamicDataSourceProvider) {
            YmlDynamicDataSourceProvider provider = (YmlDynamicDataSourceProvider) dataSourceProvider;
            Map<String, DataSourceProperty> properties = provider.getDatasourceProperties();
            properties.put(name, property);
            
            // 刷新数据源
            if (dataSource instanceof DynamicRoutingDataSource) {
                DynamicRoutingDataSource ds = (DynamicRoutingDataSource) dataSource;
                DataSource newDataSource = DataSourceCreator.createDataSource(property);
                ds.addDataSource(name, newDataSource);
                log.info("Added new datasource: {}", name);
            }
        }
    }
    
    /**
     * 移除数据源
     */
    public void removeDataSource(String name) {
        if (dataSource instanceof DynamicRoutingDataSource) {
            DynamicRoutingDataSource ds = (DynamicRoutingDataSource) dataSource;
            ds.removeDataSource(name);
            log.info("Removed datasource: {}", name);
        }
    }
    
    /**
     * 获取所有可用的数据源名称
     */
    public Set<String> getAllDataSourceNames() {
        if (dataSource instanceof DynamicRoutingDataSource) {
            DynamicRoutingDataSource ds = (DynamicRoutingDataSource) dataSource;
            return ds.getDataSources().keySet();
        }
        return Collections.emptySet();
    }
}
```

## 四、业务使用示例

### 4.1 读写分离场景

```java
/**
 * 用户服务实现
 * 注意：需要导入com.baomidou.dynamic.datasource.annotation.DS注解
 */
@Service
@Slf4j
public class UserService {
    
    @Autowired
    private UserMapper userMapper;

    /**
     * 查询用户详情 - 默认使用从库，提高主库性能
     */
    @DS("slave")
    public User getUserById(Long userId) {
        log.info("Querying user by id: {}", userId);
        Assert.notNull(userId, "User id cannot be null");
        return userMapper.selectById(userId);
    }

    /**
     * 批量查询用户列表 - 使用从库
     */
    @DS("slave")
    public List<User> queryUsers(UserQuery query) {
        log.info("Querying users with conditions: {}", JSON.toJSONString(query));
        LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
        if (query.getUsername() != null) {
            wrapper.like(User::getUsername, query.getUsername());
        }
        if (query.getStatus() != null) {
            wrapper.eq(User::getStatus, query.getStatus());
        }
        return userMapper.selectList(wrapper);
    }

    /**
     * 保存用户信息 - 强制使用主库
     */
    @DS("master") // 指定使用主库
    @Transactional(rollbackFor = Exception.class)
    public Long createUser(User user) {
        log.info("Creating user: {}", JSON.toJSONString(user));
        Assert.notNull(user, "User cannot be null");
        Assert.hasText(user.getUsername(), "Username cannot be empty");
        
        user.setCreateTime(LocalDateTime.now());
        user.setUpdateTime(LocalDateTime.now());
        user.setCreateBy(SecurityContextHolder.getContext().getAuthentication().getName());
        
        userMapper.insert(user);
        return user.getId();
    }

    /**
     * 更新并获取最新用户信息 - 使用主库避免主从延迟问题
     */
    @DS("master") // 指定使用主库，避免主从延迟问题
    @Transactional(rollbackFor = Exception.class)
    public User updateUser(User user) {
        log.info("Updating user: {}", JSON.toJSONString(user));
        Assert.notNull(user, "User cannot be null");
        Assert.notNull(user.getId(), "User id cannot be null");
        
        user.setUpdateTime(LocalDateTime.now());
        user.setUpdateBy(SecurityContextHolder.getContext().getAuthentication().getName());
        
        userMapper.updateById(user);
        // 立即从主库查询最新数据，避免主从延迟问题
        return userMapper.selectById(user.getId());
    }
}
```

### 4.2 多租户场景

```java
/**
 * 订单服务实现
 */
@Service
@Slf4j
public class OrderService {
    
    @Autowired
    private OrderMapper orderMapper;
    
    @Autowired
    private OrderItemMapper orderItemMapper;

    /**
     * 查询订单详情 - 拦截器自动处理租户数据源
     */
    public OrderDTO getOrderById(Long orderId) {
        log.info("Querying order by id: {}", orderId);
        Assert.notNull(orderId, "Order id cannot be null");
        
        // 数据源由TenantInterceptor自动处理
        Order order = orderMapper.selectById(orderId);
        if (order == null) {
            return null;
        }
        
        // 查询订单商品列表
        List<OrderItem> items = orderItemMapper.selectByOrderId(orderId);
        
        // 组装DTO返回
        OrderDTO dto = new OrderDTO();
        BeanUtils.copyProperties(order, dto);
        dto.setItems(items);
        return dto;
    }

    /**
     * 创建订单 - 拦截器自动处理租户数据源
     */
    @Transactional(rollbackFor = Exception.class)
    public OrderDTO createOrder(OrderCreateRequest request) {
        // 注意：OrderStatus和RandomStringUtils需要导入相应的类
        log.info("Creating order with request: {}", JSON.toJSONString(request));
        validateOrderRequest(request);
        
        // 数据源由TenantInterceptor自动处理
        Order order = new Order();
        order.setOrderNo(generateOrderNo());
        order.setUserId(request.getUserId());
        order.setTotalAmount(request.getTotalAmount());
        order.setOrderStatus(OrderStatus.PENDING.getCode());
        order.setCreateTime(LocalDateTime.now());
        order.setUpdateTime(LocalDateTime.now());
        
        // 保存订单主表
        orderMapper.insert(order);
        
        // 保存订单商品明细
        List<OrderItem> items = request.getItems().stream().map(item -> {
            OrderItem orderItem = new OrderItem();
            orderItem.setOrderId(order.getId());
            orderItem.setProductId(item.getProductId());
            orderItem.setProductName(item.getProductName());
            orderItem.setQuantity(item.getQuantity());
            orderItem.setUnitPrice(item.getUnitPrice());
            return orderItem;
        }).collect(Collectors.toList());
        
        items.forEach(orderItemMapper::insert);
        
        // 组装返回DTO
        OrderDTO dto = new OrderDTO();
        BeanUtils.copyProperties(order, dto);
        dto.setItems(items);
        return dto;
    }
    
    private void validateOrderRequest(OrderCreateRequest request) {
        Assert.notNull(request, "Order create request cannot be null");
        Assert.notNull(request.getUserId(), "User id cannot be null");
        Assert.notEmpty(request.getItems(), "Order items cannot be empty");
        Assert.isTrue(request.getItems().size() <= 100, "Order items cannot exceed 100");
    }
    
    private String generateOrderNo() {
        return String.format("%s%s", 
                LocalDate.now().format(DateTimeFormatter.ofPattern("yyyyMMdd")),
                RandomStringUtils.randomNumeric(10));
    }
}
```

### 4.3 分库分表场景

```java
/**
 * 分库分表用户服务实现
 * 注意：使用Sharding-JDBC时，数据源切换由框架自动完成，通常不需要@DS注解
 */
@Service
@Slf4j
public class ShardingUserService {
    
    @Autowired
    private UserMapper userMapper;
    
    @Autowired
    private TransactionTemplate transactionTemplate;

    /**
     * 自动分片路由查询用户信息，对业务透明
     */
    public User getUserById(Long userId) {
        log.info("Sharding scenario - querying user by id: {}", userId);
        Assert.notNull(userId, "User id cannot be null");
        return userMapper.selectById(userId);
    }

    /**
     * 批量查询用户信息 - 跨分片查询示例
     */
    public List<User> getUsersByIds(Set<Long> userIds) {
        log.info("Sharding scenario - batch querying users by ids: {}", userIds);
        Assert.notEmpty(userIds, "User ids cannot be empty");
        Assert.isTrue(userIds.size() <= 500, "Batch query size cannot exceed 500");
        
        // Sharding-JDBC会自动将SQL路由到对应的分片
        return userMapper.selectBatchIds(userIds);
    }

    /**
     * 插入用户信息 - 自动分片路由
     */
    @Transactional(rollbackFor = Exception.class)
    public Long insertUser(User user) {
        log.info("Sharding scenario - inserting user: {}", JSON.toJSONString(user));
        validateUser(user);
        
        // 如果未指定ID，使用雪花算法生成
        if (user.getId() == null) {
            user.setId(SnowflakeIdGenerator.nextId());
        }
        
        user.setCreateTime(LocalDateTime.now());
        user.setUpdateTime(LocalDateTime.now());
        
        // 自动根据user_id路由到对应的库和表
        userMapper.insert(user);
        return user.getId();
    }
    
    /**
     * 批量插入用户 - 性能优化示例
     */
    @Transactional(rollbackFor = Exception.class)
    public boolean batchInsertUsers(List<User> users) {
        log.info("Sharding scenario - batch inserting users, batch size: {}", users.size());
        Assert.notEmpty(users, "Users list cannot be empty");
        Assert.isTrue(users.size() <= 1000, "Batch insert size cannot exceed 1000");
        
        // 设置通用字段
        LocalDateTime now = LocalDateTime.now();
        users.forEach(user -> {
            validateUser(user);
            if (user.getId() == null) {
                // 可以使用ShardingSphere内置的雪花算法或自定义实现
                user.setId(SnowflakeIdGenerator.nextId()); // 需导入相应的雪花算法实现类
            }
            user.setCreateTime(now);
            user.setUpdateTime(now);
        });
        
        // 按分片键分组后批量插入，减少跨库操作
        Map<Integer, List<User>> shardedUsers = users.stream()
                .collect(Collectors.groupingBy(user -> (int) (user.getId() % 2)));
        
        for (Map.Entry<Integer, List<User>> entry : shardedUsers.entrySet()) {
            userMapper.batchInsert(entry.getValue()); // 确保UserMapper中定义了batchInsert方法
        }
        
        return true;
    }
    
    private void validateUser(User user) {
        Assert.notNull(user, "User cannot be null");
        Assert.hasText(user.getUsername(), "Username cannot be empty");
        Assert.hasText(user.getEmail(), "Email cannot be empty");
        Assert.hasText(user.getPhone(), "Phone cannot be empty");
    }
}
```

## 五、最佳实践建议

### 5.1 降低侵入性原则
- **优先使用注解**：@DS注解是最简单直观的数据源切换方式，与DynamicDataSourceContextHolder配合使用
- **避免硬编码**：数据源名称应通过配置管理
- **集中处理**：使用AOP或拦截器集中处理通用逻辑
- **抽象通用行为**：将数据源切换逻辑封装到基础类或工具类中
- **确保一致性**：注解方式与编程方式切换数据源时保持统一的上下文管理

### 5.2 读写分离最佳实践
- **读操作默认使用从库**：提高主库性能，分散读压力
- **写操作强制使用主库**：确保数据一致性
- **写入后立即读取的场景使用主库**：避免主从延迟问题
- **关键业务读操作使用主库**：对一致性要求高的场景优先选择主库
- **从库故障转移**：配置多个从库并实现自动故障转移机制

### 5.3 多租户最佳实践
- **使用拦截器自动识别租户**：避免业务代码中处理租户逻辑
- **确保数据源正确清理**：使用try-finally确保数据源上下文被正确清理，或在拦截器的afterCompletion方法中清理
- **支持租户动态添加**：通过DynamicDataSourceManager实现租户数据源的动态注册和管理
- **租户数据隔离审计**：记录租户数据访问日志，便于审计和问题排查
- **租户数据源连接池优化**：为不同租户配置合适的连接池参数，避免资源竞争

### 5.4 分库分表最佳实践
- **合理选择分片键**：选择高基数、均匀分布的字段作为分片键，如用户ID、订单ID
- **避免跨库join**：设计表结构时考虑减少跨库join操作，必要时进行数据冗余
- **批量操作优化**：按分片键分组后执行批量操作，减少跨库操作
- **分页查询优化**：避免使用offset过大的分页查询，考虑使用游标方式或按分片并行查询
- **定期数据清理**：实现数据分片的自动归档和清理机制
- **热点数据处理**：对热点数据采用特殊分片策略，如单独分片或读写分离

### 5.5 性能优化建议
- **合理配置连接池**：为不同数据源配置独立的连接池参数
- **使用读写分离提高吞吐量**：增加从库数量提升读操作性能
- **缓存热点数据**：对频繁访问的数据使用缓存减少数据库压力
- **异步处理非核心操作**：将非核心写操作异步化处理
- **定期监控数据源性能**：监控各数据源的连接数、响应时间等指标

## 六、常见问题与解决方案

### 6.1 主从延迟问题
- **问题描述**：写入主库后立即从从库读取，可能读取到旧数据
- **解决方案**：
  1. 写入后立即读取的场景使用主库查询
  2. 实现主从延迟检测，当延迟超过阈值时自动切换到主库
  3. 使用消息队列确保数据同步完成后再进行读取

### 6.2 数据源切换异常
- **问题描述**：线程上下文中的数据源信息未正确清理，导致后续操作使用错误的数据源
- **解决方案**：
  1. 使用try-finally确保数据源上下文被正确清理
  2. 实现AOP切面统一处理数据源切换和清理
  3. 配置拦截器在请求结束时清理数据源上下文

### 6.3 事务一致性问题
- **问题描述**：在事务中切换数据源可能导致事务失效或数据不一致
- **解决方案**：
  1. 确保事务内的所有操作使用同一个数据源，避免在事务内部使用@DS注解切换数据源
  2. 对分布式事务场景使用Seata等分布式事务框架，确保跨数据源操作的一致性
  3. 在设计时避免在单个事务中访问多个数据源，采用最终一致性模式
  4. 使用TransactionTemplate显式管理事务范围，确保数据源在事务开始前已正确切换

### 6.4 分库分表的复杂查询性能问题
- **问题描述**：跨多个分片的复杂查询性能较差
- **解决方案**：
  1. 优化SQL，避免全表扫描和复杂join，使用索引覆盖查询
  2. 使用读写分离，复杂查询走从库，避免影响主库性能
  3. 考虑使用物化视图或缓存预计算结果
  4. 设计合理的分片策略，减少跨分片查询，如按热点数据单独分片
  5. 对频繁的聚合查询，考虑使用实时计算引擎预计算结果

### 6.5 动态数据源热加载
- **问题描述**：运行时需要动态添加或修改数据源配置
- **解决方案**：
  1. 使用DynamicDataSourceManager实现数据源动态刷新和管理
  2. 通过配置中心(如Nacos、Apollo)实现数据源配置的动态更新
  3. 实现数据源健康检查和自动恢复机制，定期检查数据源可用性
  4. 添加数据源变更的事件监听，确保相关组件能够及时响应数据源变化
  5. 实现优雅关闭机制，确保数据源移除时不影响正在进行的事务

通过以上方案和最佳实践，可以实现对业务代码极低侵入的多数据源管理，同时保证系统的性能、可维护性和数据一致性。
