## 二、核心工具类（直接复制）

### 2.1 数据源路由工具
```java
/**
 * 数据源路由工具类
 */
@Component
public class DataSourceRouter {
    
    /**
     * 在指定数据源执行操作
     */
    public static <T> T execute(String dataSource, Supplier<T> action) {
        try {
            DynamicDataSourceContextHolder.push(dataSource);
            return action.get();
        } finally {
            DynamicDataSourceContextHolder.poll();
        }
    }
    
    /**
     * 无返回值操作
     */
    public static void execute(String dataSource, Runnable action) {
        execute(dataSource, () -> {
            action.run();
            return null;
        });
    }
}
```

### 2.2 多租户拦截器
```java
/**
 * 多租户数据源拦截器
 */
@Component
public class TenantInterceptor implements HandlerInterceptor {
    
    private static final String TENANT_HEADER = "X-Tenant-ID";
    
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        String tenantId = request.getHeader(TENANT_HEADER);
        if (tenantId != null) {
            DynamicDataSourceContextHolder.push("tenant_" + tenantId);
        }
        return true;
    }
    
    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) {
        DynamicDataSourceContextHolder.clear();
    }
}

/**
 * 注册拦截器
 */
@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Autowired
    private TenantInterceptor tenantInterceptor;
    
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(tenantInterceptor).addPathPatterns("/api/**");
    }
}
```

### 2.3 健康检查
```java
/**
 * 数据源健康检查
 */
@Component
public class DataSourceHealthIndicator implements HealthIndicator {
    
    @Autowired
    private DynamicRoutingDataSource dynamicDataSource;
    
    @Override
    public Health health() {
        Map<String, Object> details = new HashMap<>();
        boolean allHealthy = true;
        
        dynamicDataSource.getDataSources().forEach((name, ds) -> {
            try (Connection conn = ds.getConnection()) {
                details.put(name, conn.isValid(2) ? "UP" : "DOWN");
            } catch (Exception e) {
                details.put(name, "DOWN: " + e.getMessage());
            }
        });
        
        return allHealthy ? Health.up().withDetails(details).build() 
                         : Health.down().withDetails(details).build();
    }
}
```

## 三、业务使用示例

### 3.1 读写分离场景
```java
@Service
@DS("slave")  // 类级别默认数据源
public class UserService {
    
    @Autowired
    private UserMapper userMapper;
    
    // 读操作 - 自动负载均衡到从库
    public User getUser(Long userId) {
        return userMapper.selectById(userId);
    }
    
    // 写操作 - 切换到主库
    @DS("master")
    @Transactional
    public void updateUser(User user) {
        userMapper.updateById(user);
    }
    
    // 实时读 - 避免主从延迟
    @DS("master")
    public User getRealTimeUser(Long userId) {
        return userMapper.selectById(userId);
    }
}
```

### 3.3 分表分库场景
```java
@Service
public class ShardingUserService {
    
    @Autowired
    private UserMapper userMapper;
    
    /**
     * 自动分片 - 根据user_id路由
     */
    public User getShardingUser(Long userId) {
        return DataSourceRouter.execute("sharding_user", () -> 
            userMapper.selectById(userId));
    }
    
    /**
     * 批量查询优化
     */
    public List<User> getUsersByIds(List<Long> userIds) {
        // 按分片分组查询
        Map<Integer, List<Long>> shardedIds = userIds.stream()
            .collect(Collectors.groupingBy(userId -> (int)(userId % 4)));
        
        List<User> result = new ArrayList<>();
        for (List<Long> shardIds : shardedIds.values()) {
            List<User> users = DataSourceRouter.execute("sharding_user", 
                () -> userMapper.selectBatchIds(shardIds));
            result.addAll(users);
        }
        return result;
    }
}
```

### 3.4 混合数据源操作
```java
@Service
public class ComplexBusinessService {
    
    @Autowired
    private UserService userService;
    
    @Autowired
    private OrderMapper orderMapper;
    
    @Autowired
    private AuditMapper auditMapper;
    
    /**
     * 跨多个数据源操作
     */
    public void processUserOrder(Long userId, Order order) {
        // 1. 从用户库读取（从库）
        User user = userService.getUser(userId);
        
        // 2. 在订单库操作（分片）
        DataSourceRouter.execute("sharding_user", () -> {
            order.setUserId(userId);
            orderMapper.insert(order);
            return null;
        });
        
        // 3. 在主库记录审计
        DataSourceRouter.execute("master", () -> {
            auditMapper.logOperation("create_order", userId);
            return null;
        });
    }
}
```

## 五、最佳实践总结

### 5.1 配置规范
```yaml
# 数据源命名规范
datasource:
  master     # 主库 - 写操作
  slave_[n]  # 从库 - 读操作
  sharding_* # 分片数据源
  tenant_*   # 租户数据源
```

### 5.2 代码规范
```java
// ✅ 推荐做法
@Service
@DS("slave")  // 类级别默认
public class ReadService {
    public Data query() { ... }  // 自动使用slave
    
    @DS("master")  // 方法级别覆盖
    public void update() { ... }
}

// ❌ 避免做法
@Controller
public class BadExample {
    @DS("master")  // 不要在Controller层控制数据源
    public void operation() { ... }
}
```
