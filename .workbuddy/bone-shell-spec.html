二级菜单交互规范

以下规范基于 Ant Design Pro 导航最佳实践，适用于后台管理系统的侧边栏菜单层级交互。

⚙ 系统管理 ▶
系统配置
服务监控
操作日志
部署管理
👆
点击展开/收起
单击父级菜单项切换子菜单可见性。不使用 hover 触发——避免误触，兼容触屏设备。
Trigger: click event
📋
手风琴模式
同时仅展开一个菜单分组。点击 A 分组时自动收起之前展开的 B 分组，保持侧栏整洁。
accordion: true（默认）
➤
箭头旋转动画
父级菜单右侧箭头在展开时旋转 90°，收起时回正。0.2s transition 提供流畅反馈。
transform: rotate(90deg)
📍
高亮当前子项
当前激活的子菜单项使用 Primary 浅色背景 + 蓝色文字 + 蓝色圆点标记。父级自动展开。
.active { background: primary-bg }
🔗
父级可路由
父级菜单点击时路由到该分组的默认子页（如「系统管理」→ 默认打开「系统配置」）。
defaultOpenKey: 首个子项
📐
缩进视觉层级
子菜单项左侧缩进 12px + 5px 圆点标记，与父级形成清晰的父子层级关系。

页面通用交互契约

全平台统一的页面交互契约，覆盖页面进入、Tab 切换、数据操作、表单提交等核心场景。

🥖
面包屑导航
始终显示「菜单分组 / 当前页面」，由侧边导航的选中状态自动生成。点击上级面包屑返回分组默认页。
Header 左侧 | auto-generate
📑
页内 Tab 切换
当页面内需要切换不同视图/分类时使用（如系统配置的 基础/安全/通知）。Tab 切换不刷新页面，仅替换内容区。注意：同一组子页面不应同时存在侧边栏子菜单和页内 Tab——避免双重导航。
≤5 tabs | 不与侧边子菜单重复
➕
创建 → 弹窗
创建/新增操作使用 Modal 弹窗（400~720px 宽）。表单 ≤ 10 字段用 400~600px，多步骤向导用 720px。提交时按钮显示 loading spinner，提交成功后关闭弹窗并刷新列表，失败则保持弹窗 + 错误提示。
Modal 400-720px | loading state | 失败保留
📋
详情 → 抽屉
查看实体详情使用右侧 Drawer（480~720px 宽），分 Tab 展示不同维度的详细信息。支持在抽屉内切换编辑态直接修改。关闭抽屉时如有未保存变更弹出 ConfirmModal 二次确认。
Drawer 480-720px | dirty check on close
🗑
删除 → 确认框
删除操作弹出 Confirm Modal，标题为「确认删除」，内容说明不可逆。批量删除先选中行 → 点击批量删除 → 确认框列出受影响数量。
ConfirmModal | danger button
🔍
搜索 + 筛选
表格上方搜索栏：左侧快捷搜索框 + 右侧筛选按钮。输入关键词后 300ms 防抖自动过滤。点击筛选展开 Filter Panel（折叠面板），多条件 AND 组合。
300ms debounce + Filter Panel
📄
分页规范
默认每页 20 条，可选 10/20/50/100。显示总数和当前页范围。切换分页时滚动到表格顶部。
defaultPageSize: 20 | scrollToTop
📥
导出操作
导出按钮放在表格工具栏右侧。导出当前筛选结果。大量数据时显示进度条，完成后自动下载。
Export button → Progress → Download
🔄
自动刷新
仪表盘/监控类页面默认 30s 自动轮询。页面可见时运行，切后台暂停。手动刷新按钮始终可用。
30s interval | page-visible only

键盘无障碍规范

后台系统重度依赖键盘操作效率，以下为全平台统一的无障碍交互契约。

↹
Tab 导航
Tab 键按 DOM 顺序在可聚焦元素间移动（表单控件、按钮、链接）。Shift+Tab 反向移动。表格内 Tab 跳转到下一行同一列。
Tab / Shift+Tab
⏎
Enter 提交
表单内任一 input 聚焦时按 Enter 触发表单提交（等价于点击主按钮）。Modal/Drawer 内 Enter 提交并关闭。搜索框 Enter 触发搜索。
Enter → submit / search
⎋
Esc 关闭
Esc 关闭当前 Modal / Drawer / Popover / Dropdown。有未保存变更时弹出 ConfirmModal 二次确认。按层级逐层关闭。
Esc → close (dirty check)
⌨
Focus Trap
Modal 和 Drawer 打开时焦点锁定在组件内部，Tab 在首尾元素间循环。关闭后焦点回到触发元素（如「新建」按钮）。
Focus trap in Modal/Drawer
⌃
快捷键
全局 Ctrl+K 唤起命令面板（快速搜索菜单/页面）。Ctrl+S 保存当前表单。Ctrl+F 聚焦搜索框。快捷键在输入框聚焦时不拦截。
Ctrl+K / Ctrl+S / Ctrl+F
↑↓
列表/菜单导航
下拉菜单支持 ↑↓ 键移动焦点，Enter 选中。侧边栏菜单支持 ↑↓ 键在菜单项间移动。分页组件支持 ←→ 翻页。
↑↓ in dropdowns / ←→ in pagination
