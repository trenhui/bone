# 2026-09-15

- **Git 多远程推送配置（Bone 仓库）**：`origin` 配 `git@gitee.com:meishan315/bone.git`（ssh，fetch+push）与 `git@github.com:trenhui/bone.git`（ssh，push）双 pushurl，一次 `git push origin` 同时推 Gitee + GitHub（均为 SSH）。本仓库设了 `credential.helper=osxkeychain`（对 https 有效，对 ssh 无影响，无害保留）。
- **重要认知纠正**：git 命令在**用户本机**执行，以本机网络/SSH key 为准；WorkBuddy 运行时的网络测试（GitHub SSH 22/443 超时、仅 HTTPS 通）**不能代表用户本机**。不要据此把用户要的 SSH remote 降级成 https。判断用户本机连通性应让用户在本地终端跑 `ssh -T git@github.com` 验证。
- **pre-commit 钩子 bug 修复**：`scripts/check.sh` 会对「含 `src/main/java` 改动的模块」跑 `mvn test -Dtest='*ArchitectureTest'`，但 `bone-architecture-test` 模块无此类测试，surefire 报 "No tests matching" 导致钩子必败、熔断计数累加。已在 `mvn -f "$POM" test` 后补 `-Dsurefire.failIfNoSpecifiedTests=false`（提交 `5d7897b4` 已随本次双推入库）。后续改该模块可正常提交。
