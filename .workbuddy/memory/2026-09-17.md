## 发现：pre-commit 钩子的 ArchUnit 门禁是 no-op

`scripts/check.sh` 第 2 步：
```bash
MODULE_PATHS=$(echo "$CHANGED_FILES" | grep 'src/main/java' || true | sed 's|/src/main/java/.*||' | sort -u)
```
管道优先级高于 `||`，实际解析为 `(echo | grep) || (true | sed | sort)`，于是 `MODULE_PATHS` 拿到的是**文件全路径**（sed 从未生效）；后面 `POM="$MODULE_PATH/pom.xml"` 永远不是文件 → `[ -f "$POM" ]` 恒假 → **ArchUnit 静默跳过**。钩子输出可验：打印了 `[2/5] 就近 ArchUnit 架构检查...` 却一条 `ArchUnit: ...` 都没有，紧接着就是 `[3/5]`。
建议改为把 `|| true` 挪到管道末尾：
```bash
MODULE_PATHS=$(echo "$CHANGED_FILES" | grep 'src/main/java' | sed 's|/src/main/java/.*||' | sort -u || true)
```
（属共享治理脚本、修好后会真正开始拦人，需用户确认后再改。）
