02

API 客户端与 fail-closed 呈现

原来

无寻源/风险前端客户端，2xx 易被误当成功。

现在

sourcingApi/supplierRiskApi 以顶层 success 判定，403/404/网络失败/success=false 映射明确降级；请求体不含自报身份字段。

原因 采购域「2xx ≠ 成功」红线 + 身份只由后端登录态裁决。
