# editing - 精确代码编辑技能 v2.1

## 职责
基于契约精准编辑代码，保持现有代码风格，只修改需要修改的部分。

## 核心原则
- **最小修改**：只修改需求相关的代码，不碰无关代码
- **保持风格**：严格遵循现有代码的缩进、命名、注释风格
- **验证编译**：编辑后立即编译验证，错误自动修复
- **增量更新**：支持在现有代码基础上增量添加功能

## 执行步骤
1. **读取目标文件**：完整读取需要修改的文件
2. **分析上下文**：理解现有结构、导入、命名
3. **定位修改点**：精准定位需要插入/修改的位置
4. **执行修改**：保持风格，最小改动
5. **编译验证**：运行 `mvn compile` 或 `tsc` 验证
6. **自愈**：如果编译错误，自动修复最多 3 次

## 修复策略
- **缺失导入**：自动添加缺少的 import
- **命名冲突**：保持一致的命名风格，重命名冲突
- **语法错误**：修复括号、分号、大括号匹配
- **类型错误**：修复 TypeScript/Java 类型不匹配

## 红线
- 不重构现有代码结构，除非需求明确要求
- 不删除已有注释，除非注释过期
- 不改变公共 API 签名
- 不碰 generated 目录
