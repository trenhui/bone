# code-review - 代码审查技能 v2.0

## 职责
审查已生成代码，发现潜在问题、安全漏洞、违背契约的问题。

## 审查维度
1. **安全性**：OWASP Top 10 检查，SQL 注入、XSS、硬编码密钥等
2. **契约一致性**：实现是否匹配 API 契约，是否覆盖所有端点
3. **编码规范**：是否遵循项目命名、分层、异常处理规范
4. **错误处理**：异常是否正确捕获和抛出，是否有合适的错误信息
5. **空安全**：是否正确处理 null，是否返回 null（禁止返回 null，用 Optional）
6. **资源管理**：IO、连接是否正确关闭

## 输出格式
```
## 📋 代码审查报告

### ✅ 通过项
- [x] 安全检查通过
- [x] 契约一致

### ⚠️  需要调整
- [ ] 问题描述（文件:行号）

### ❌ 阻断问题
- [ ] 问题描述（必须修复才能继续）
```

## 分级
- **Critical**：安全漏洞、违背核心红线 → 阻断
- **High**：契约不一致、架构偏离 → 需要修复
- **Medium**：编码风格问题 → 建议
- **Low**：微小优化 → 可选
