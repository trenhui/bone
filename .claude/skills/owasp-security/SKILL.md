# owasp-security - OWASP 安全审查技能

## 职责
检查代码中的 OWASP Top 10 安全漏洞，发现问题立即阻断。

## 检查清单

### A1: 注入
- [ ] SQL 注入：是否使用参数化查询？禁止字符串拼接 SQL
- [ ] 命令注入：是否执行外部输入拼接的系统命令？
- [ ] XML 注入：是否禁用外部实体？

### A2: 失效的身份认证
- [ ] 密码是否明文存储？必须使用 BCrypt/PBKDF2
- [ ] 是否硬编码密钥/密码/API Token？
- [ ] JWT 密钥是否泄露？

### A3: 敏感数据暴露
- [ ] 是否日志打印敏感数据（密码、身份证、银行卡）？
- [ ] HTTPS 是否启用？
- [ ] 敏感字段是否添加 @JsonIgnore？

### A5: 安全配置错误
- [ ] 是否启用了默认调试信息？
- [ ] 错误栈是否暴露给用户？
- [ ] CORS 配置是否过于宽松？

### A6: 过时的加密
- [ ] 是否使用 md5/sha1 存储密码？
- [ ] 是否使用弱加密算法？

### A7: 身份认证遗漏
- [ ] 权限检查是否在每一层都做？
- [ ] ID 越权：是否验证当前用户有权访问该资源？

### A8: 软件已知漏洞
- [ ] 依赖是否有已知 CVE？（不检查，由 Dependabot 处理）

### A9: XSS
- [ ] 用户输出是否正确转义？React 默认可信，是否 dangerouslySetInnerHTML？
- [ ] 是否直接插入 HTML 到 DOM？

### A10: 反序列化
- [ ] 是否使用安全的反序列化？
- [ ] 是否接受不可信来源的序列化数据？

## 处理规则
- 发现 Critical 问题 → 立即阻断，不允许合并
- 发现 High 问题 → 需要人工确认
- 低风险问题 → 建议修复
