# /test 命令 - 测试与验证

## 职责
运行集成测试，检查覆盖率，验证契约一致性。

## 执行步骤
1. **加载契约和 checkpoint**
2. **运行测试**：执行 `mvn test` 或对应前端测试命令
3. **覆盖率检查**：读取 JaCoCo 报告，验证是否达标（>80%）
4. **契约一致性校验**：检查代码实现是否匹配契约定义
5. **更新 checkpoint**：设置 `phase = "review"`
6. **输出测试报告**：展示测试结果、覆盖率、发现的问题

## 检查点
- 所有单元测试必须通过
- 覆盖率必须满足 guardrails 要求
- API 端点必须覆盖契约中定义的所有方法
- 所有 `domain_rules` 必须满足

## 异常处理
- 测试失败且属于 L1/L2-A → 尝试自动修复
- 测试失败且属于 L2-B → 暂停，等待人工确认
- 测试失败且属于 L3 → 阻断，报告问题
