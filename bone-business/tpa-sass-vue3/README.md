# TPA 管理端（Vue3）

基于 Vue3 + Vite + TypeScript + Element Plus 的 TPA SaaS 管理前端，对接 [`../tpa-saas/`](../tpa-saas/) 后端。

## 本地运行

```bash
npm install
npm run dev
```

环境变量与 API 基址见 `vite.config` / `.env*`（以仓库内实际文件为准）。

## 说明

上游模板为 [vue3-element-admin](https://github.com/youlaitech/vue3-element-admin)；Bone 仓库内以本目录实现与配置为准，勿沿用模板 README 中的克隆地址与演示站点。
