# TPA 管理端（Vue3）

基于 Vue3 + Vite + TypeScript + Element Plus 的 TPA 管理端（**在役，维护期**）。

**迁移目标**：功能与 [`../tpa-sass-react/`](../tpa-sass-react/) 对齐后归档本目录；**勿再添加新业务功能**。路线见 [`../TPA-MIGRATION.md`](../TPA-MIGRATION.md)。

## 本地运行

```bash
npm install
npm run dev
```

当前对接 [`../tpa-saas/`](../tpa-saas/)（Java）。环境变量与 API 基址见 `vite.config` / `.env*`。

## 说明

上游模板为 [vue3-element-admin](https://github.com/youlaitech/vue3-element-admin)；Bone 仓库内以本目录实现为准，勿沿用模板 README 中的克隆地址与演示站点。
