# procuraAI 原型交互设计（D2 · Hi-Fi 级页面定义）

> **对应**：PRD FR-205（处置流）、FR-503（关联自查）、FR-712（逐字核对）、FR-713（评分预估）、FR-721/722/723（起草闭环）、FR-801（任务编排）、FR-802（反馈闭环）、FR-803（审查结果锚点交互）。
> **约束**：本设计仅为产品界面定义，**不含任何内部演示引导内容**（横幅、演示按钮、话术、流程串联提示等）；所有文案面向真实用户（法务/采购/合同管理员）。

---

## 1. 信息架构（5 个一级页面）

```
procuraAI 工作台
├── 1 审查中心        ← 招标体检 / 合同审查（含三一致）入口
├── 2 履约预警        ← 预警台账 / 节点日历
├── 3 合同起草        ← 条款库 / 起草任务（M7，P1 启用）
├── 4 供应商画像      ← 画像明细 / 关联自查（M3，P1 启用）
└── 5 规则与评测      ← 规则库管理 / 评测集 / 标注任务（管理员）
```

> 工作台首页：待办（需确认的风险条目、到期预警、起草任务）+ 近 30 日审查量/规则命中分布/采纳率三卡片。

---

## 2. 审查报告页（核心页面 · FR-803）

**布局（左右分栏）**：

```
┌─────────────┬──────────────────────────────────────┐
│ 风险面板      │  原文阅读区（左 60% / 右 40%）        │
│ ┌─────────┐ │  文档渲染（PDF/Word 转页）             │
│ │ 高 3 中 5│ │  · 命中条款黄色高亮（锚点）            │
│ │ 低 8     │ │  · 点击面板条目 → 原文滚动定位+闪烁    │
│ ├─────────┤ │  · 拖动选中文字 → "添加到风险条目"     │
│ │ 条目列表  │ │                                      │
│ │ ▸ R01    │ │  三一致对照表（R25 命中时）           │
│ │ ▸ R12    │ │  ┌────────┬────────┬────────┐       │
│ │ ▸ LLM-03 │ │  │ 招标要求 │ 投标承诺 │ 合同条款 │ │
│ │ ...      │ │  └────────┴────────┴────────┘       │
│ └─────────┘ │                                      │
└─────────────┴──────────────────────────────────────┘
```

**风险条目卡片字段**：级别（高/中/低 + 颜色）+ 置信度 + 风险类型 + 原文引用（quote_original，点击跳转原文）+ 法规依据（basis，点击跳转法规库条文）+ 修改建议（suggestion）+ 状态（待确认/已采纳/已驳回/已改判）。

**逐条确认交互（HITL）**：
- 每条风险底部三按钮：**采纳 / 驳回 / 改判**；
- 驳回必填理由分类（六类：不构成风险/适用范围不符/依据不成立/重复条目/误读原文/其他）+ 备注；
- 改判：可编辑级别与建议文本，留痕 diff；
- 全部处理完 → 报告状态流转（进行中 → 已确认 → 已归档）。

**原文高亮与锚点规则**：高亮随 review_snapshot 版本（IR 章节引用稳定，回滚后锚点不漂移）；命中条款可一键"仅显示命中页"。

## 3. 处置流页（FR-205 · 合同审查后处理）

```
状态机：待修订 → 修订中 → 已重审 → 定稿（最多 3 轮，超限转人工）

修订任务卡片：风险条目数 · 修改建议汇总（只读） · 负责人（法务/合同管理员）
交互：
  · 法务在原文区直接改合同文本（在线编辑或下载修订稿上传）
  · "提交重审" → 仅重审变更条款 + 20% 抽检（进度条展示重审进度）
  · 重审结果：无新增高风 → 可定稿；有新增高风 → 进入下一轮
  · 全程留痕：修订历史（谁/何时/改了什么/依据条目）
```

## 4. 履约预警页（M4）

- **台账视图**：合同号/供应商/节点类型（付款/验收/质保/履约截止）/到期日/剩余天数/状态（临期/到期/逾期/已消警）/金额；
- **节点日历**：月视图标色（T-15 黄 / T-0 橙 / T+0 红 / 已闭环绿）；
- **消警交互**：点"核销"→ 选择核销依据（ERP 付款记录自动 / 验收单上传 / 人工说明）→ 记录留痕；逾期未处理自动升级抄送负责人。

## 5. 投标响应页（M6 · P1）

- **拆解派发**：招标文件上传 → 资质/技术/商务/评分规则四栏拆解预览 → 逐项派发给负责人（站内 + OA 待办）；
- **响应模板生成**：字段级填空（AI 预填 + 工商逐字核对提示：**营业执照信息不一致处以黄色标注，须人工确认后方可保留**）；
- **评分预估**：客观分（资质/价格/证书）AI 预估 ± 区间展示 + 主观分提示人工评估；
- **变更对比**：招标澄清/变更文件上传 → 与原始文件 diff 高亮 → 影响条目标记。

## 6. 合同起草页（M7 · P1）

- **条款库**：标准条款/备选条款/禁用条款三分类（仅法务确认条款可引用）；审查中人工采纳/改判结论回流展示；
- **起草任务**：选择模板（采购协议/框架协议/NDA）→ 填写变量（主体/金额/期限/验收）→ 生成初稿 → 自动触发审查 → 回审结果内嵌展示（起草-审查闭环）；
- **禁用条款提示**：引用禁用条款时即时红字提示 + 法务审批入口。

## 7. 规则管理页（管理员）

- 规则库双源视图（法规源 R / 企业源 ER）：启用/停用/版本/灰度比例/生效范围（租户/合同类型）；
- 规则测试：单条规则对评测集回归（≥1 正例 + 1 反例）结果展示；
- 评测集管理：样本列表/标签分布/标注任务指派（双人标注 + 仲裁，Kappa 展示）；
- 灰度面板：shadow 观察 → A/B 采纳率对比 → 全量发布 → 回滚按钮。

## 8. 通用交互约束

| 约束 | 规则 |
|------|------|
| 无依据不出结果 | 风险条目无"原文引用+法规依据"不允许展示（空引用条目降级提示人工补录） |
| 取消与确认 | 批量操作（全量采纳/批量驳回）二次确认弹窗；单条操作即时生效可撤销 |
| 加载与降级 | LLM 不可用时页面提示"规则审查模式"，不渲染 LLM 专属字段 |
| 权限 | 法务/采购/管理员/IT 四角色菜单与操作集不同（RBAC 见数据字典 D3） |
| 响应式 | 适配 1280+ 桌面为主，平板可读（FR-T4 响应式要求） |
