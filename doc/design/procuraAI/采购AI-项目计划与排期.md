# procuraAI 项目计划与排期（D4）

> **对应**：立项评估 §4（四阶段路径）· 补齐计划 P0 D4。本计划覆盖**阶段 0（商业验证立项）+ 阶段 1（POC）**，POC 通过后按数据决策是否进入标杆阶段排期。

---

## 1. WBS（工作分解，阶段 0 + POC）

| 工作包 | 内容 | 负责角色 |
|--------|------|----------|
| W0.1 种子客户筛选 | 客户清单打分（POC 方案 D1 §2）、首轮拜访、POC 意向 | 售前/商务 |
| W0.2 样本协议 | 数据使用协议、脱敏约定、销毁条款 | 法务支持 |
| W1.1 环境部署 | GPU/应用节点、Docker Compose、FP8 模型加载、评测基线 | 交付/算法 |
| W1.2 样本准备 | 样本收集、脱敏、已知风险预标（ground truth） | 法务顾问 |
| W2.1 规则引擎 | R01-R25 预检跑通、四类条款命中分布、零漏检验证 | 算法 |
| W2.2 LLM 审查 | 深审流程跑通、约束解码校验、降级矩阵验证 | 算法/后端 |
| W3.1 调优 | 规则 2 轮调优、提示词版本化、评测回归 | 算法 |
| W3.2 三一致校验 | R25 五组对照验证、对照表渲染 | 算法/前端 |
| W4.1 复核对比 | 法务逐条确认、耗时对比、采纳率统计 | 交付 |
| W4.2 报告与演示 | POC 报告、闸门判定、立项意向确认 | 售前 |

## 2. 里程碑与排期（对齐 6 周 POC）

| 里程碑 | 时点 | 出口标准 |
|--------|------|----------|
| M0 立项与样本 | D0+2 周 | 种子客户签署 POC 意向；≥30 份样本到位（脱敏+预标） |
| M1 环境就绪 | D0+3 周 | 部署清单验证通过；评测基线报告 |
| M2 规则层零漏检 | D0+4 周 | R01-R25 预检 30 份零漏检（法定情形） |
| M3 端到端跑通 | D0+5 周 | 解析→规则→LLM→输出全链路；检出对比初版 |
| M4 POC 完成 | D0+8 周 | 四闸门判定（G1-G4）；POC 报告；立项意向函 |

## 3. 人力计划（最小交付组，6 人）

| 角色 | 投入 | 阶段重点 |
|------|------|----------|
| 算法工程师 ×1 | 100% | 规则引擎、LLM 链路、评测回归 |
| 后端工程师 ×2 | 100%/50% | 接口、数据模型、适配器、队列 |
| 前端工程师 ×1 | 100% | 审查报告页（锚点/确认面板）、预警页 |
| 测试工程师 ×1 | 50% | 评测基线、验收用例执行 |
| 售前/交付顾问 ×1 | 100% | 客户对接、基线测量、报告 |
| 法务支持（兼职） | 20% | 样本预标、依据复核、规则确认 |

> P0 验证通过后、标杆阶段前评估扩编（交付 ×2、客户成功 ×1）。

## 4. 依赖清单（外部关键路径）

| 依赖 | 前置条件 | 风险点 | 应对 |
|------|----------|--------|------|
| GPU 80G 卡 | 采购/借调到位 | 供应链周期 | 立项即下单；先纯规则跑通兜底 |
| 客户样本 | 客户法务配合 | 脱敏周期超预期 | W0.2 协议先行；预置样本兜底 |
| 客户部署环境 | 客户 IT 放行 | 网络/安全审批慢 | 提前发部署清单与等保配合材料 |
| 等保备案（并行） | 定级材料 | 周期 1–3 个月 | D7 提前启动，不阻塞 POC |
| 标注人力 | 评测集扩充 | 双人标注耗时 | W1 起用预置 200 条，POC 后扩充 |

## 5. 风险登记册（立项评估 R1-R6 细化到执行层）

| # | 风险 | 概率/影响 | 执行层应对 |
|---|------|:---:|------|
| R1 竞品挤压 | 中/高 | POC 数据对标（检出率 vs 竞品公开指标）；差异化话术备好 |
| R2 政策弹性 | 中/中 | 优先考核最紧客户；标杆后行业复制 |
| R3 样本不足 | 中/高 | 预置样本兜底；样本协议签早 |
| R4 客户环境慢 | 中/中 | 规则降级先跑；部署清单提前发 |
| R5 组织缺口 | 中/中 | 最小 6 人组；标杆阶段再扩 |
| R6 从方案到产品 | 高/高 | 原型（D2）+ 契约（D3）先行冻结；以 POC 数据验证，不以文档完备代替 |
| R7 采纳率不达标 | 中/高 | 调优 2 轮后仍 <60% → 降级"仅规则+人工复核"形态交付 |
| R8 规则误报冲击信任 | 中/中 | 误报率 ≤5% 门禁；驳回理由回流评测集（FR-802 闭环） |
