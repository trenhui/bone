# Synap Equity 数据源获取与验证方案

> **文档编号**：SE-DATA-001　**版本**：v0.1　**日期**：2026-10-12　**作者**：产品委员会
> **对应 PRD**：《Synap Equity 产品方案》v0.9 FR-D1/FR-D2、§12.1 第 1 周、附录 B「T0 前置缺口」
> **定位**：解决 MVP 第 1 周的**唯一阻塞项**——「2 只标的×2 期财报入库并通过人工核对」必须有可执行的取数路径。本文给出 A 级数据源清单、获取方式、验证清单、口径映射与快照策略。

---

## 1. 结论先行

| 结论 | 内容 |
|---|---|
| A 级数据源是否可得 | **可得且免费**：巨潮资讯网、上交所、深交所、上市公司公告原文均为公开披露，无需授权 |
| MVP 取数方式 | **人工下载 + 半自动解析**（不依赖数据商 API），单只标的取数目标 ≤30 分钟 |
| 是否阻塞 MVP | **不阻塞**——A 级通道可覆盖 10 只种子标的×2 期财报；B 级数据商仅为 P1 增强 |
| 主要风险 | 公告非结构化（PDF/HTML）解析耗时；口径映射需人工核对（已设计核对清单） |

---

## 2. 数据源分级（沿用 PRD FR-D1）

| 级别 | 来源 | 可用性 | MVP 使用 |
|---|---|---|---|
| **A 级（公开披露）** | 巨潮资讯网、上交所/深交所官网、上市公司公告 | 免费、可直接使用 | ✅ **MVP 唯一数据源** |
| B 级（数据商授权） | Wind/同花顺/聚宽/CSMAR 等 | 需授权付费 | ⏸ P1 接入（行业分位/历史分位） |
| C 级（爬取） | 未经授权的第三方站点爬取 | 合规风险 | ❌ 禁止 |

---

## 3. A 级数据源清单与获取路径

| 数据类别 | 来源 | 获取方式 | 频率 |
|---|---|---|---|
| 三大财务报表（年报/季报） | 巨潮资讯网（cninfo.com.cn） | 按股票代码检索公告 → 下载 PDF | 按报告期 |
| 财务指标（EPS/净资产等） | 巨潮/交易所披露的报表内计算 | 由报表派生（不依赖第三方指标） | — |
| 公司基本信息（行业/股本） | 交易所公司主页 + 公告 | 人工录入 + 公告核对 | 一次性 |
| 分红/送转 | 分红派息公告 | 下载公告 | 按事件 |
| 日行情（收盘价/成交） | 交易所公布的每日行情 | 官方历史行情下载（CSV） | 日频 |
| 停牌/退市/ST 标记 | 交易所公告 | 人工登记 | 按事件 |

**获取方式说明（诚实边界）**：
1. 巨潮/交易所**无公开稳定 API**（部分有非官方接口），MVP 采用**人工下载 PDF/CSV + 解析脚本**，牺牲自动化换合规与确定性；
2. 解析后用**人工核对清单**（§6）逐项校验，确保入库数据正确——这是「字段提取准确率 ≥95%」指标的来源；
3. 优先选择**财务数据表格式公告（XBRL/Excel 附件）**，减少 PDF 解析误差。

---

## 4. 取数工作流（单只标的）

```plaintext
① 确定标的信息（代码/名称/行业/股本）  → 台账登记
② 检索并下载最近 2 期财报（PDF/附件）
③ 解析脚本抽取报表字段（营收/净利/净资产/现金流/负债…）
④ 人工核对清单逐项校验（对照 PDF 原文）
⑤ 写入结构化表 + 打时点快照（as_of = 公告披露日）
⑥ 交接估值引擎消费（引擎只见快照）
```

**验收**：单只标的取数 + 核对 ≤30 分钟；2 只标的×2 期在第 1 周内完成。

## 5. 口径映射表（数据源字段 → 内部字段）

| 内部字段 | 数据源位置 | 口径说明 |
|---|---|---|
| `revenue` | 利润表「营业总收入」/「营业收入」 | 取营业总收入（含其他业务），标注口径 |
| `net_profit` | 利润表「归属于母公司所有者的净利润」/「扣非」 | 扣非优先（见估值方法学 §2） |
| `equity` | 资产负债表「归属于母公司所有者权益合计」 | 不含少数股东权益 |
| `total_assets` | 资产负债表「资产总计」 | — |
| `total_liabilities` | 资产负债表「负债合计」 | — |
| `interest_debt` | 短期借款+长期借款+应付债券+一年内到期非流动负债 | 需人工汇总 |
| `ocf` | 现金流量表「经营活动产生的现金流量净额」 | — |
| `capex` | 现金流量表「购建固定资产、无形资产和其他长期资产支付的现金」 | — |
| `shares` | 公司基本信息/股本变动公告 | as_of 时点总股本 |
| `报告期` | 公告披露 | 记录**披露日**与**报告期末**两个日期 |
| `as_of` | 公告披露日 | 快照时间戳，禁止早于披露日的数据可见 |

---

## 6. 验证清单（人工核对 Checklist）

每期财报入库前逐项核对（勾选留痕）：

- [ ] 报告期与披露日正确（披露日 = 快照 `as_of`）
- [ ] 营业收入与利润表原文一致（±0）
- [ ] 归母净利润（扣非）与原文一致；缺失时已标注
- [ ] 归母净资产与资产负债表原文一致
- [ ] 资产总计/负债合计与原表一致
- [ ] 经营现金流净额与原表一致
- [ ] 总股本与股本变动公告一致
- [ ] 无未来数据（本期数据未使用晚于 `as_of` 的后续报表）
- [ ] 单位与币种统一（元 / CNY）
- [ ] 核对人、核对时间留痕

---

## 7. 快照策略（时点即真相）

| 项 | 规则 |
|---|---|
| 快照粒度 | 日频（行情）+ 报告期（财务） |
| 时间戳 | 每条数据记录 `disclosed_at`（披露时间）；计算只可见 `disclosed_at ≤ as_of` 的数据 |
| 不可变 | 快照一经写入不可修改；财报追溯调整（重述）作为**新快照版本**追加，不改历史 |
| 存储 | `snapshot_financial` / `snapshot_price`（DDL 见《技术方案》§4） |
| 审计 | 支持「按 as_of 回放」；抽查披露时间戳证明无泄漏（PRD FR-T3） |

---

## 8. 数据质量校验（三档）

| 档 | 校验项 | 处理 |
|---|---|---|
| 硬校验（拒绝入库） | 必填字段缺失、单位不一致、`as_of` 早于披露日 | 报错，人工修正 |
| 软校验（警告+标注） | 扣非缺失、同比异常（>200% 或 <-50%）、勾稽不平（资产≠负债+权益） | 标注「待复核」，不阻断 |
| 一致性校验 | 与上期报表勾稽（期初=上期期末） | 不一致则标注并复核 |

## 9. 风险与降级

| 风险 | 等级 | 降级策略 |
|---|---|---|
| 公告格式复杂、解析失败 | 中 | 人工录入关键字段（牺牲时间换正确性） |
| 部分公司无扣非数据 | 低 | 降级为归母净利润 + 标注 |
| 行业分类缺失 | 中 | 人工按申万三级录入（种子池仅 10 只，可控） |
| 后续需行业/历史分位 | — | P1 接入 B 级数据商（不阻塞 MVP） |
