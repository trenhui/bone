# Synap Equity 估值方法学（公式级）

> **文档编号**：SE-VAL-001　**版本**：v0.1　**日期**：2026-10-12　**作者**：产品委员会
> **对应 PRD**：《Synap Equity 产品方案》v0.9 §7.1/§7.2/§7.6、附录 B「T0 前置缺口」
> **定位**：本文是「可复算」承诺的**技术底稿**——PRD 只写规则，本文写**公式、口径、参数、边界**。开发、评测、评审三方以本文对齐口径；本文任何口径变更须走版本记录（§11）。

## 1. 目的与范围

| 项 | 说明 |
|---|---|
| 目的 | 让任何人（开发/评审/用户）在**相同输入**下得到**逐位一致**的估值输出，并使每个中间量可追溯 |
| 覆盖 | 数据口径定义、PE/PB（MVP 主法）、DCF（实验性）、区间锚定与三情景、财务质量指标、策略参数映射 |
| 不覆盖 | 行业专属模型（银行/保险/地产等特殊估值）、预测报表建模（P3）、多市场（港股/美股） |
| 硬约束 | 全部计算为**确定性纯函数**（无 LLM、无随机、无系统时间依赖，时间由入参 `as_of` 显式给定） |

**可复算定义**：`估值(标的, as_of, 参数集) → 输出`，相同三元组重复执行输出逐字段一致（浮点按定点化规则，见 §9.2）。

## 2. 数据口径定义（先定口径，再谈公式）

| 口径项 | 规则 | 缺失时处理 |
|---|---|---|
| 报告期 | 使用**已披露**的最新年报/季报；`as_of` 之前未披露的报表一律不可见 | 不可见即视为不存在（防泄漏） |
| 净利润口径 | 优先**归母净利润（扣非）**；无扣非数据时用归母净利润并在输出标注 `扣非口径缺失` | 标注后继续，质量评分扣档 |
| TTM | 最近 4 个季度滚动：`TTM = Q_last + 年报_prev − Q_last_prev`（对齐报告期跨年） | 不足 4 季时用最近完整年报并标注 |
| 每股指标 | 采用**最新总股本**；涉及增发/回购时取 `as_of` 时点股本 | 无数据则拒绝产出 |
| 净资产 | 归母净资产（不含少数股东权益） | 无则拒绝产出 |
| 币种/单位 | 统一人民币、单位「元」；展示层做亿元换算，**计算层禁止换算** | — |
| 复权 | 估值计算**不复权**（用原始价格）；展示区间的历史走势才复权 | — |
| 数据源优先级 | 巨潮资讯 > 交易所披露 > 上市公司公告原文（A 级，见数据源方案） | — |

## 3. PE 估值（MVP 主法一）

### 3.1 基础公式

```text
EPS(TTM)        = 归母净利润(TTM, 扣非优先) / 总股本
合理市值(PE)     = 归母净利润(TTM) × 目标PE
合理价格(PE)     = 合理市值(PE) / 总股本 = EPS(TTM) × 目标PE
```

### 3.2 目标 PE 区间锚定（核心算法，PRD §7.1「区间锚定规则」的公式化）

对标的自身取近 **3 年**（默认 `N=3`）PE(TTM) 日频序列分位，与行业中位数交叉：

```text
PE_self_low  = P10(自身近3年 PE_TTM)
PE_self_high = P90(自身近3年 PE_TTM)
PE_peer_mid  = median(同业可比公司 PE_TTM)     # 同业口径见 §6

PE_low  = max(PE_self_low,  PE_peer_mid × 0.70)
PE_high = min(PE_self_high, PE_peer_mid × 1.30)
PE_mid  = median(PE_low, PE_high, PE_peer_mid)

约束：若 PE_low ≥ PE_high（交集为空）→ 降级为自身分位 [P10, P90]，输出标注「区间锚定降级：交集为空」
约束：PE_low ≤ 0（亏损或极端）→ 该公司 PE 法不适用，转 PB 法并标注
```

理由：自身分位反映历史定价习惯，行业中位数提供横向锚点；「∩ 取交」避免单一锚点被极端值带偏（对标 Simply Wall St 标准化假设被批评的痛点，本文以显式锚定规则替代黑盒标准化）。

### 3.3 输出

```text
估值区间 = EPS(TTM) × [PE_low, PE_mid, PE_high]
           ↓
        [悲观价, 基准价, 乐观价]（三情景见 §7）
```

## 4. PB 估值（MVP 主法二）

```text
BPS = 归母净资产(最新报告期) / 总股本
目标PB 区间锚定：
  PB_low  = max(P10(自身近3年 PB), 行业中位数(PB) × 0.70)
  PB_high = min(P90(自身近3年 PB), 行业中位数(PB) × 1.30)
  PB_mid  = median(PB_low, PB_high, 行业中位数(PB))
合理价格(PB) = BPS × [PB_low, PB_mid, PB_high]
```

**适用规则**：
- 金融/重资产行业（银行、保险、地产、公用事业）→ **PB 为主法**，PE 为辅；
- 亏损公司（PE 法不适用）→ **PB 为主法**；
- 轻资产/高成长（PE 法适用）→ **PE 为主法**，PB 作校验。

**主法判定（确定性规则）**：

| 条件 | 主法 |
|---|---|
| 归母净利润(TTM) > 0 且 行业非金融重资产 | PE |
| 归母净利润(TTM) ≤ 0 或 行业为金融/重资产 | PB |
| 两者均不适用（净资产为负等） | 拒绝产出，提示「估值方法不适用」 |

## 5. DCF（实验性，MVP 仅手动假设）

> 定位：**实验性模块**。无分析师/预测数据源时，仅当用户手动输入假设才计算，输出带强警告，不作为卡片主结论。

### 5.1 公式

```text
FCFF_t = EBIT_t × (1 − t) + D&A_t − Capex_t − ΔNWC_t
TV      = FCFF_n × (1 + g) / (WACC − g)            # Gordon 永续增长
EV      = Σ_{t=1..n} FCFF_t / (1 + WACC)^t  +  TV / (1 + WACC)^n
Equity  = EV − 有息净负债 + 货币资金调整项          # 简化：净负债 = 有息负债 − 现金
每股价值 = Equity / 总股本
```

### 5.2 默认参数（配置化，用户可改）

| 参数 | 默认 | 边界 | 说明 |
|---|---|---|---|
| 预测期 n | 5 年 | 3–10 | — |
| WACC | 9% | 6–15% | `WACC = E/(D+E)×Re + D/(D+E)×Rd×(1−t)`；MVP 允许直接输入 |
| 永续增长 g | 2.5% | 0–5%，且 g < WACC−1% | **不得超过名义 GDP 增速上限（取 5%）** |
| 税率 t | 15% | 0–25% | 高新技术企业优惠税率启发式，用户可改 |
| EBIT 增速 | 手动输入 | — | **MVP 不自动预测**（无非分析师数据源） |

### 5.3 强警告（缺一不可）

1. 页面与报告须显示「DCF 为实验性方法，假设由用户输入，结果高度敏感」；
2. 输出**敏感性矩阵**（WACC × g 的 3×3 网格，P1）；
3. 不与 PE/PB 主结论混排，单列「实验性参考」。

## 6. 同业与行业口径（可比公司定义）

| 项 | 规则 |
|---|---|
| 行业分类 | 采用**申万三级**（或中信三级）行业分类 |
| 可比公司池 | 同三级行业内市值 Top 30（不足 30 取全部），剔除 ST/*ST、上市不足 1 年 |
| 行业中位数 | 可比公司池 PE/PB 的**中位数**（非均值，抗极端值） |
| 数据时点 | 一律取 `as_of` 时点可得数据（防泄漏） |

## 7. 三情景与区间口径

| 情景 | 锚定规则 | 用途 |
|---|---|---|
| 悲观 | 基准假设 × 0.5（增速类）；估值取 `PE_low/PB_low` | 风险测试下沿 |
| 基准 | 历史 3 年 CAGR（营收/利润增速）；估值取 `PE_mid/PB_mid` | 主结论 |
| 乐观 | 基准假设 × 1.3（增速类）；估值取 `PE_high/PB_high` | 上沿 |

**统一输出形状**（禁止单一目标价）：

```text
合理估值区间：[悲观价, 基准价, 乐观价]
当前价位置    ：低估档 / 合理档 / 高估档（PRD FR-S2 三分档）
关键假设       ：增速、目标PE/PB、折现率等（显式清单）
```

**档位判定（FR-S2 联动）**：

| 当前价 vs 区间 | 档位 |
|---|---|
| 价格 < 悲观价（区间底部以下） | 低估档 |
| 悲观价 ≤ 价格 ≤ 乐观价 | 合理档 |
| 价格 > 乐观价（区间顶部以上） | 高估档 |

## 8. 财务质量指标（五维体检简化版，8–10 指标）

| 维度 | 指标 | 公式 | 档位阈值（简） |
|---|---|---|---|
| 盈利 | ROE(TTM) | 归母净利(TTM)/归母净资产 | ≥15% 优 / 8–15% 中 / <8% 弱 |
| 盈利 | 毛利率 | (营收−营业成本)/营收 | 行业分位比较 |
| 盈利 | 净利率 | 归母净利/营收 | 行业分位比较 |
| 成长 | 营收 CAGR(3y) | (本期/3年前)^(1/3)−1 | ≥15% 优 / 5–15% 中 |
| 成长 | 净利 CAGR(3y) | 同上（归母扣非） | 同上 |
| 现金流 | 经营现金流/净利 | OCF/归母净利 | ≥1 优 / 0.5–1 中 / <0.5 弱 |
| 现金流 | 自由现金流 | OCF − Capex | >0 为正 |
| 偿债 | 资产负债率 | 总负债/总资产 | 行业分位比较 |
| 偿债 | 有息负债/EBITDA | 有息负债/EBITDA(TTM) | <3 优 |
| 质量 | 非经常性损益占比 | 非经常性损益/净利润 | <20% 优 |

**五维评分**：各维度取子指标加权平均（权重配置化，默认等权），输出 0–100 分与档位（优/中/弱）。指标缺失按 §2 降级标注，不臆造。

## 9. 可复算性与一致性（引擎级要求）

| 要求 | 落地 |
|---|---|
| 纯函数 | 引擎入参仅 `(数据快照, 参数集)`；无全局状态、无系统时间、无网络 |
| 幂等 | 同输入重复执行输出逐位一致（单元测试 P0） |
| 定点化 | 金额保留 2 位小数、比率保留 4 位；中间计算用 Decimal，禁止二进制浮点累计误差 |
| 方法族登记 | 同一标的的估值方法族（PE/PB/DCF）登记于档案，变更须显式记录原因与影响（PRD §6.2 一致性优先） |
| 参数可溯 | 每个输出字段附带 `{数据源, 公式ID, 参数值}` 溯源三元组 |
