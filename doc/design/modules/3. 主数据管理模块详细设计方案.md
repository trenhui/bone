# 主数据管理模块详细设计方案

## 1. 模块概述

主数据管理模块是 BONE 平台的核心数据治理模块，负责企业核心业务实体的统一管理、数据质量控制和主数据生命周期管理，为企业提供高质量、一致、可信的主数据服务。

**核心目标**：
- 提供主数据的统一建模和管理能力
- 确保主数据的一致性和完整性
- 实现主数据的质量监控和治理
- 支持主数据的生命周期管理
- 提供主数据的标准化和规范化

## 2. 功能设计

### 2.1 主数据模型管理

**功能描述**：支持主数据模型的创建、编辑、发布和版本管理，定义主数据的结构和属性。

**详细功能**：
- **模型创建**：创建主数据模型，定义模型名称、描述、属性等
- **属性管理**：添加、编辑、删除模型属性，设置属性类型、长度、约束等
- **关系管理**：定义主数据模型之间的关系
- **版本管理**：管理模型的版本历史，支持版本对比和回滚
- **模型发布**：将模型从草稿状态发布为可用状态

**用户故事**：
> 作为数据管理员，我希望创建和管理主数据模型，以便统一管理企业核心数据。

### 2.2 主数据管理

**功能描述**：支持主数据的创建、编辑、审核、发布和生命周期管理。

**详细功能**：
- **数据录入**：手动录入主数据，支持批量导入
- **数据编辑**：修改主数据的属性值
- **数据审核**：审核主数据的变更，确保数据质量
- **数据发布**：将主数据从草稿状态发布为可用状态
- **生命周期管理**：管理主数据的状态，如启用、禁用、归档等
- **数据历史**：记录主数据的变更历史

**用户故事**：
> 作为数据管理员，我希望管理主数据的完整生命周期，确保数据的准确性和一致性。

### 2.3 数据质量监控

**功能描述**：监控主数据的质量，检测和处理数据质量问题。

**详细功能**：
- **质量规则**：定义数据质量规则，如唯一性、完整性、准确性等
- **质量检测**：根据规则检测数据质量问题
- **质量报告**：生成数据质量报告，展示质量指标和问题
- **质量修复**：提供数据质量问题的修复建议和工具
- **质量趋势**：监控数据质量的变化趋势

**用户故事**：
> 作为数据质量分析师，我希望监控主数据的质量，及时发现和解决数据质量问题。

### 2.4 主数据集成

**功能描述**：支持主数据与其他系统的集成，确保数据的一致性和同步。

**详细功能**：
- **集成配置**：配置与其他系统的集成参数
- **数据同步**：同步主数据到其他系统
- **变更通知**：当主数据发生变更时通知相关系统
- **集成监控**：监控集成状态和同步结果
- **错误处理**：处理集成过程中的错误

**用户故事**：
> 作为系统集成专员，我希望配置主数据与其他系统的集成，确保数据的一致性。

### 3.3 关键实现

#### 3.3.1 主数据模型管理

```java
package com.bone.masterdata.application.command.handler;

import com.bone.masterdata.application.command.cmd.CreateMasterDataModelCmd;
import com.bone.masterdata.domain.model.MasterDataModel;
import com.bone.masterdata.domain.model.vo.ModelName;
import com.bone.masterdata.domain.repository.MasterDataModelRepository;
import com.bone.masterdata.common.exception.BusinessException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

@Component
@RequiredArgsConstructor
public class CreateMasterDataModelHandler {
    private final MasterDataModelRepository modelRepository;
    
    @Transactional
    public Long handle(CreateMasterDataModelCmd cmd) {
        ModelName modelName = new ModelName(cmd.getName());
        
        // 检查模型名称是否已存在
        if (modelRepository.existsByName(cmd.getName())) {
            throw new BusinessException("模型名称已存在");
        }
        
        MasterDataModel model = MasterDataModel.create(
            cmd.getId(),
            cmd.getTenantId(),
            modelName,
            cmd.getDescription()
        );
        
        modelRepository.save(model);
        
        return model.getId().getValue();
    }
}
```

```java
package com.bone.masterdata.application.command.handler;

import com.bone.masterdata.application.command.cmd.CreateMasterDataCmd;
import com.bone.masterdata.domain.model.MasterData;
import com.bone.masterdata.domain.model.MasterDataModel;
import com.bone.masterdata.domain.repository.MasterDataRepository;
import com.bone.masterdata.domain.repository.MasterDataModelRepository;
import com.bone.masterdata.common.exception.BusinessException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

@Component
@RequiredArgsConstructor
public class CreateMasterDataHandler {
    private final MasterDataRepository masterDataRepository;
    private final MasterDataModelRepository modelRepository;
    
    @Transactional
    public Long handle(CreateMasterDataCmd cmd) {
        // 验证模型存在
        MasterDataModel model = modelRepository.findById(cmd.getModelId())
                .orElseThrow(() -> new BusinessException("模型不存在"));
        
        MasterData masterData = MasterData.create(
            cmd.getId(),
            cmd.getTenantId(),
            model.getId(),
            cmd.getCode(),
            cmd.getAttributes()
        );
        
        masterDataRepository.save(masterData);
        
        return masterData.getId().getValue();
    }
}
```

#### 3.3.3 数据质量监控

```java
package com.bone.masterdata.application.command.handler;

import com.bone.masterdata.application.command.cmd.CreateQualityRuleCmd;
import com.bone.masterdata.domain.model.QualityRule;
import com.bone.masterdata.domain.model.vo.RuleName;
import com.bone.masterdata.domain.repository.QualityRuleRepository;
import com.bone.masterdata.common.exception.BusinessException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

@Component
@RequiredArgsConstructor
public class CreateQualityRuleHandler {
    private final QualityRuleRepository ruleRepository;
    
    @Transactional
    public Long handle(CreateQualityRuleCmd cmd) {
        RuleName ruleName = new RuleName(cmd.getName());
        
        // 检查规则名称是否已存在
        if (ruleRepository.existsByName(cmd.getName())) {
            throw new BusinessException("规则名称已存在");
        }
        
        QualityRule rule = QualityRule.create(
            cmd.getId(),
            cmd.getTenantId(),
            ruleName,
            cmd.getType(),
            cmd.getExpression(),
            cmd.getMessage()
        );
        
        ruleRepository.save(rule);
        
        return rule.getId().getValue();
    }
}
```

### 4.2 完整建表 SQL（MySQL 8.0+）

```sql
-- ===========================================================
-- 主数据管理模块完整建表SQL
-- 数据库：bone
-- 引擎：InnoDB, 字符集：utf8mb4
-- 遵循 doc/architecture/Bone-DDD-最终实践方案.md（第二部分）与主 PRD 数据约定：
--   主键使用 BIGINT（雪花算法）
--   软删除：deleted TINYINT(1)
--   乐观锁：version INT
--   审计：created_by, updated_by, created_at, updated_at
--   租户：tenant_id
-- ===========================================================

-- 主数据实体扩展配置表
CREATE TABLE mdm_entity (
    id                  BIGINT          NOT NULL COMMENT '主数据实体主键（Snowflake）',
    tenant_id           BIGINT          NOT NULL COMMENT '租户ID',
    meta_entity_id      BIGINT          NOT NULL COMMENT '关联元数据实体ID（meta_entity.id）',
    entity_code         VARCHAR(200)    NOT NULL COMMENT '主数据实体编码，如CUSTOMER,MATERIAL',
    entity_name         VARCHAR(200)    NOT NULL COMMENT '主数据实体显示名称',
    description         TEXT            DEFAULT NULL COMMENT '描述',
    is_versioning       TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '是否启用版本控制：0-否，1-是',
    workflow_enabled    TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '是否启用审批流：0-否，1-是',
    status              TINYINT         NOT NULL DEFAULT 1 COMMENT '状态：0-禁用，1-启用',
    created_by          BIGINT          DEFAULT NULL COMMENT '创建人ID',
    updated_by          BIGINT          DEFAULT NULL COMMENT '修改人ID',
    created_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '创建时间',
    updated_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) COMMENT '更新时间',
    deleted             TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已删除',
    version             INT             NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
    PRIMARY KEY (id),
    UNIQUE KEY uk_mdm_entity_code (tenant_id, entity_code),
    UNIQUE KEY uk_mdm_entity_meta (tenant_id, meta_entity_id),
    KEY idx_mdm_entity_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='主数据实体扩展配置表';

-- 主数据记录表
CREATE TABLE mdm_record (
    id                  BIGINT          NOT NULL COMMENT '记录主键（Snowflake）',
    tenant_id           BIGINT          NOT NULL COMMENT '租户ID',
    mdm_entity_id       BIGINT          NOT NULL COMMENT '主数据实体ID',
    record_code         VARCHAR(200)    NOT NULL COMMENT '业务唯一编码（如物料编码）',
    display_name        VARCHAR(500)    NOT NULL COMMENT '记录显示名称',
    current_data        JSON            NOT NULL COMMENT '当前生效的属性数据（JSON格式）',
    status              VARCHAR(20)     NOT NULL DEFAULT 'DRAFT' COMMENT '状态：DRAFT,PENDING,APPROVED,PUBLISHED,ARCHIVED',
    version_number      INT             NOT NULL DEFAULT 1 COMMENT '当前版本号',
    effective_from      DATETIME(3)     DEFAULT NULL COMMENT '生效开始时间',
    effective_to        DATETIME(3)     DEFAULT NULL COMMENT '生效结束时间',
    is_current          TINYINT(1)      NOT NULL DEFAULT 1 COMMENT '是否当前有效版本：0-否，1-是',
    parent_record_id    BIGINT          DEFAULT NULL COMMENT '父记录ID，用于层次结构',
    created_by          BIGINT          DEFAULT NULL COMMENT '创建人ID',
    updated_by          BIGINT          DEFAULT NULL COMMENT '修改人ID',
    created_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '创建时间',
    updated_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) COMMENT '更新时间',
    deleted             TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已删除',
    version             INT             NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
    PRIMARY KEY (id),
    UNIQUE KEY uk_mdm_record_code (tenant_id, mdm_entity_id, record_code),

    KEY idx_mdm_record_status (status),

-- 主数据记录版本历史表
CREATE TABLE mdm_record_version (
```

## 7. 性能与安全

### 7.1 性能优化

- **缓存策略**：使用 Redis 缓存主数据模型和常用主数据，减少数据库查询
- **批量处理**：批量处理主数据导入和导出，减少数据库操作次数
- **索引优化**：为常用查询字段创建索引，提高查询性能
- **异步处理**：质量检查和集成同步使用异步处理，避免阻塞主线程
- **数据分区**：对主数据历史表和集成日志表进行分区，提高查询性能

### 7.2 安全措施

- **权限控制**：基于 RBAC 的细粒度权限控制
- **数据隔离**：多租户数据隔离，确保数据安全
- **传输加密**：使用 TLS 1.3 加密所有网络传输
- **输入验证**：严格的输入验证，防止注入攻击
- **审计日志**：记录所有主数据操作，支持审计追踪
- **数据脱敏**：对敏感主数据进行脱敏处理

## 11. 总结

主数据管理模块是 BONE 平台的核心数据治理模块，通过提供主数据模型管理、主数据生命周期管理、数据质量监控和主数据集成等功能，为企业提供高质量、一致、可信的主数据服务。该模块采用了先进的技术栈和架构设计，支持复杂的主数据管理需求。

**核心优势**：
- **统一的主数据模型**：支持灵活的主数据模型定义和管理
- **完整的生命周期管理**：从创建到归档的全生命周期管理
- **强大的数据质量监控**：自动检测和修复数据质量问题
- **高效的集成能力**：与外部系统的无缝集成
- **智能的AI辅助**：AI驱动的数据质量分析和修复

**应用场景**：
- 企业核心数据管理：统一管理客户、产品、供应商等核心数据
- 数据质量治理：确保数据的准确性和一致性
- 系统集成：实现不同系统之间的数据同步和一致性
- 业务分析：为业务分析提供高质量的数据基础

主数据管理模块的设计充分考虑了数据治理的复杂性和企业级应用的需求，为 BONE 平台提供了强大的数据治理能力，使企业能够更好地管理和利用其核心数据资产。
