# 主数据管理模块详细设计方案

## 1. 模块概述

主数据管理模块是 BONE 平台的核心能力之一，负责主数据实体的创建、管理、数据质量控制和数据发布，是实现企业数据治理的关键模块。

**核心目标**：
- 提供主数据实体的定义和管理能力
- 实现数据质量规则的配置和执行
- 支持主数据记录的导入、管理和发布
- 提供数据质量分析和报告
- 确保主数据的一致性和准确性

## 2. 功能设计

### 2.1 主数据实体管理

**功能描述**：支持主数据实体的创建、编辑、删除和发布，管理实体的字段和属性。

**详细功能**：
- **实体创建**：创建主数据实体，设置名称、描述、分类等基本信息
- **字段管理**：添加、编辑、删除实体字段，设置字段类型、长度、约束等
- **实体版本**：管理主数据实体的版本历史
- **实体发布**：将主数据实体从草稿状态发布为可用状态
- **从业务实体转换**：支持将业务实体转换为主数据实体

**用户故事**：
> 作为业务分析师，我希望定义主数据实体，管理实体字段，以构建主数据模型。

### 2.2 数据质量管理

**功能描述**：配置和执行数据质量规则，检查和报告数据质量问题。

**详细功能**：
- **质量规则配置**：创建和管理数据质量规则，如唯一性、格式、范围、引用完整性等
- **规则执行**：执行数据质量检查，评估数据质量
- **质量报告**：生成数据质量报告，展示质量问题和趋势
- **质量指标**：定义和计算数据质量指标，如完整性、准确性、一致性等
- **问题修复**：提供数据质量问题的修复建议和工具

**用户故事**：
> 作为业务分析师，我希望配置数据质量规则，执行质量检查，生成质量报告，以确保主数据质量。

### 2.3 主数据记录管理

**功能描述**：管理主数据记录，支持数据的导入、编辑、发布和归档。

**详细功能**：
- **数据导入**：支持从Excel、CSV等格式导入主数据
- **数据编辑**：编辑主数据记录，支持批量编辑
- **数据发布**：将主数据记录从草稿状态发布为可用状态
- **数据归档**：归档不再使用的主数据记录
- **数据导出**：支持将主数据导出为Excel、CSV等格式
- **数据搜索**：支持主数据记录的高级搜索和过滤

**用户故事**：
> 作为业务分析师，我希望管理主数据记录，支持批量导入导出，以维护主数据。

### 3.4 关键实现

#### 3.4.1 主数据实体管理

```java
package com.bone.masterdata.application.command.handler;

import com.bone.masterdata.application.command.cmd.CreateMasterDataEntityCmd;
import com.bone.masterdata.domain.model.entity.MasterDataEntity;
import com.bone.masterdata.domain.model.entity.vo.MasterDataEntityName;
import com.bone.masterdata.domain.repository.MasterDataEntityRepository;
import com.bone.masterdata.common.exception.BusinessException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

@Component
@RequiredArgsConstructor
public class CreateMasterDataEntityHandler {
    private final MasterDataEntityRepository entityRepository;
    
    @Transactional
    public Long handle(CreateMasterDataEntityCmd cmd) {
        MasterDataEntityName entityName = new MasterDataEntityName(cmd.getName());
        
        // 检查实体名称是否已存在
        if (entityRepository.existsByName(cmd.getName())) {
            throw new BusinessException("主数据实体名称已存在");
        }
        
        MasterDataEntity entity = MasterDataEntity.create(
            entityName,
            cmd.getDescription(),
            cmd.getCategory()
        );
        
        entityRepository.save(entity);
        
        return entity.getId().getValue();
    }
}
```

#### 3.4.2 数据质量管理

```java
package com.bone.masterdata.application.command.handler;

import com.bone.masterdata.application.command.cmd.CreateDataQualityRuleCmd;
import com.bone.masterdata.domain.model.quality.DataQualityRule;
import com.bone.masterdata.domain.model.quality.vo.RuleName;
import com.bone.masterdata.domain.model.quality.vo.RuleSeverity;
import com.bone.masterdata.domain.repository.DataQualityRuleRepository;
import com.bone.masterdata.common.exception.BusinessException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

@Component
@RequiredArgsConstructor
public class CreateDataQualityRuleHandler {
    private final DataQualityRuleRepository ruleRepository;
    
    @Transactional
    public Long handle(CreateDataQualityRuleCmd cmd) {
        RuleName ruleName = new RuleName(cmd.getName());
        RuleSeverity severity = new RuleSeverity(cmd.getSeverity());
        
        DataQualityRule rule = DataQualityRule.create(
            cmd.getMasterDataEntityId(),
            ruleName,
            cmd.getType(),
            cmd.getExpression(),
            severity
        );
        
        ruleRepository.save(rule);
        
        return rule.getId().getValue();
    }
}
```

#### 3.4.3 主数据记录管理

```java
package com.bone.masterdata.application.command.handler;

import com.bone.masterdata.application.command.cmd.ImportMasterDataRecordsCmd;
import com.bone.masterdata.domain.model.record.MasterDataRecord;
import com.bone.masterdata.domain.repository.MasterDataRecordRepository;
import com.bone.masterdata.domain.repository.MasterDataEntityRepository;
import com.bone.masterdata.common.exception.BusinessException;
import com.bone.masterdata.common.util.ExcelUtils;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.multipart.MultipartFile;

import java.util.List;

@Component
@RequiredArgsConstructor
public class ImportMasterDataRecordsHandler {
    private final MasterDataRecordRepository recordRepository;
    private final MasterDataEntityRepository entityRepository;
    
    @Transactional
    public List<Long> handle(ImportMasterDataRecordsCmd cmd) {
        // 验证主数据实体存在
        entityRepository.findById(cmd.getMasterDataEntityId())
                .orElseThrow(() -> new BusinessException("主数据实体不存在"));
        
        // 解析Excel文件
        List<MasterDataRecord> records = ExcelUtils.parseExcelFile(
            cmd.getFile(), 
            cmd.getMasterDataEntityId()
        );
        
        // 保存记录
        List<MasterDataRecord> savedRecords = recordRepository.saveAll(records);
        
        // 返回记录ID列表
        return savedRecords.stream()
                .map(record -> record.getId().getValue())
                .toList();
    }
}
```

## 7. 性能与安全

### 7.1 性能优化

- **缓存策略**：使用 Redis 缓存主数据实体和规则，减少数据库查询
- **批量处理**：批量导入和导出数据，减少数据库操作次数
- **索引优化**：为常用查询字段创建索引
- **异步处理**：质量检查和数据导入采用异步方式，避免阻塞主线程
- **分区策略**：对主数据记录进行分区存储，提高查询性能

### 7.2 安全措施

- **权限控制**：基于 RBAC 的细粒度权限控制
- **数据验证**：严格的输入验证，防止注入攻击
- **数据脱敏**：敏感主数据脱敏处理
- **审计日志**：记录所有主数据操作，支持审计追踪
- **数据加密**：敏感主数据加密存储
