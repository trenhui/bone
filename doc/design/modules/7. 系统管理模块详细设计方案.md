## 1. 模块概述

### 1.1 模块定位

系统管理模块是BONE平台的支撑模块，负责系统的配置管理、监控告警、日志管理和部署支持，确保系统的稳定运行和可维护性。该模块提供了全面的系统管理功能，包括系统配置的管理、监控指标的收集和分析、告警的配置和处理、日志的管理和分析，以及Kubernetes部署的支持。

### 1.2 核心功能

- **系统配置**：管理系统全局配置，调整系统参数，控制功能开关
- **监控告警**：查看系统监控指标，配置告警规则，接收告警通知
- **日志管理**：查看系统运行日志，支持日志搜索和分析
- **Kubernetes部署支持**：通过Helm Chart在Kubernetes集群中一键部署BONE平台
- **系统健康检查**：监控系统各组件的健康状态
- **系统指标收集**：收集系统运行的关键指标

### 1.3 设计目标

- **可靠性**：确保系统的稳定运行和高可用性
- **可观测性**：提供全面的系统监控和日志管理能力
- **可维护性**：简化系统管理和维护流程
- **安全性**：确保系统配置和管理操作的安全性
- **易用性**：提供简单直观的系统管理界面
- **可扩展性**：支持系统的水平扩展和功能扩展

## 2. 功能设计

### 2.1 系统配置

**功能描述**：管理系统全局配置，调整系统参数，控制功能开关。

**核心功能**：
- 修改系统配置：修改配置项（如服务端口、缓存大小、日志级别）
- 管理功能开关：开启或关闭功能开关（如代码生成、主数据管理）
- 查看配置历史：查看配置变更历史
- 导入/导出配置：批量导入和导出配置

**业务规则**：
- 配置项分为：系统级、服务级、功能级
- 敏感配置项（如数据库密码）支持加密存储
- 配置变更支持版本管理
- 配置变更需要记录审计日志

### 2.2 监控告警

**功能描述**：查看系统监控指标，配置告警规则，接收告警通知。

**核心功能**：
- 查看监控指标：查看系统指标（CPU、内存、磁盘使用率）、服务指标（API响应时间、错误率、QPS）、数据库指标（连接数、查询响应时间）
- 配置告警规则：添加、编辑、删除告警规则
- 接收告警通知：通过邮件、短信、企业微信、钉钉等方式接收告警通知
- 查看告警历史：查看历史告警记录

**业务规则**：
- 支持的告警级别包括：严重、警告、信息
- 支持的通知方式包括：邮件、短信、企业微信、钉钉
- 告警规则支持按时间范围设置
- 告警通知需要记录审计日志

### 2.3 日志管理

**功能描述**：查看系统运行日志，支持日志搜索和分析。

**核心功能**：
- 查看系统日志：查看系统运行日志，包括时间、级别、服务、内容
- 搜索系统日志：按时间范围、级别、服务、关键词等条件搜索日志
- 分析系统日志：生成日志分析报告，包括错误分布、趋势分析、热点服务等
- 导出系统日志：导出日志为Excel、CSV格式

**业务规则**：
- 日志级别包括：ERROR、WARN、INFO、DEBUG、TRACE
- 支持按多条件组合搜索
- 日志支持导出为Excel、CSV格式
- 日志保留期：180天

### 2.4 Kubernetes部署支持

**功能描述**：通过Helm Chart在Kubernetes集群中一键部署BONE平台，并自动配置监控和告警。

**核心功能**：
- Helm Chart管理：提供官方Helm Chart，支持配置MySQL、Redis、RocketMQ等外部依赖
- 自动水平伸缩：基于CPU和内存阈值自动调整Pod副本数
- 监控集成：自动配置Prometheus监控和Grafana仪表盘
- 高可用配置：提供PodDisruptionBudget保证可用性
- 滚动更新：支持滚动更新策略，确保服务不中断

**业务规则**：
- 支持Kubernetes 1.24+版本
- 支持自动水平伸缩（HPA）：基于CPU和内存阈值
- 提供PodDisruptionBudget保证可用性（minAvailable: 2）
- 支持滚动更新策略（maxSurge: 25%，maxUnavailable: 0）

## 3. 技术实现

### 3.1 技术栈选型

| 技术 | 版本 | 用途 |
|------|------|------|
| Java | 17+ | 核心开发语言 |
| Spring Boot | 3.2+ | 后端框架 |
| Prometheus | 2.45+ | 监控系统 |
| Grafana | 10.0+ | 监控面板 |
| ELK Stack | 8.0+ | 日志管理 |
| Kubernetes | 1.24+ | 容器编排 |
| Helm | 3.0+ | 应用管理 |
| Redis | 7.0+ | 缓存 |
| MySQL | 8.0+ | 关系型数据库 |

### 3.2 架构设计

**架构层次**：
- **前端层**：系统管理界面，提供系统配置、监控告警、日志管理等操作
- **应用层**：系统服务，处理系统管理的业务逻辑
- **引擎层**：监控引擎、日志引擎、部署引擎
- **数据层**：存储系统配置、告警规则、系统日志等数据

**核心流程**：
1. 用户通过前端界面管理系统配置
2. 系统服务处理配置变更，更新配置存储
3. 监控引擎收集系统指标，触发告警
4. 日志引擎收集和分析系统日志
5. 部署引擎管理Kubernetes部署

### 3.3 核心组件

| 组件 | 职责 | 技术实现 |
|------|------|----------|
| 系统服务 | 处理系统管理的业务逻辑 | Spring Boot 3.2 |
| 监控引擎 | 收集和分析系统指标 | Prometheus + Grafana |
| 日志引擎 | 收集和分析系统日志 | ELK Stack |
| 部署引擎 | 管理Kubernetes部署 | Helm + Kubernetes API |
| 配置管理器 | 管理系统配置 | Spring Boot 组件 |
| 告警管理器 | 管理告警规则和通知 | 自定义组件 |

### 3.4 监控实现

**监控体系**：
- **基础设施监控**：CPU、内存、磁盘、网络
- **应用监控**：API响应时间、错误率、QPS
- **业务监控**：实体创建数、代码生成数、流程执行数

**监控工具**：
- **Prometheus**：收集和存储监控指标
- **Grafana**：可视化监控指标
- **Alertmanager**：处理告警通知

**监控指标**：
- JVM指标：堆内存使用、GC次数、线程数
- 应用指标：请求数、响应时间、错误率
- 数据库指标：连接数、查询响应时间
- 系统指标：CPU使用率、内存使用率、磁盘使用率

### 3.5 部署实现

**Helm Chart结构**：
```
bone-chart/
├── Chart.yaml
├── values.yaml

│   ├── deployment.yaml
```

**部署命令**：
```bash

```

**部署配置**：
- **开发环境**：单节点Kubernetes，内嵌数据库和中间件
- **测试环境**：多节点Kubernetes，独立数据库和中间件
- **预生产环境**：多节点Kubernetes，生产级配置
- **生产环境**：高可用Kubernetes集群，多AZ部署

### 4.4 数据库表结构（含中文注释）

```sql
-- ============================================================
-- 系统管理模块完整建表SQL
-- 数据库：bone
-- 引擎：InnoDB, 字符集：utf8mb4
-- 遵循 doc/architecture/Bone-DDD-最终实践方案.md（第二部分）与主 PRD 数据约定：
--   主键使用 BIGINT（雪花算法）
--   软删除：deleted TINYINT(1)
--   乐观锁：version INT
--   审计：created_by, updated_by, created_at, updated_at
--   租户：tenant_id
-- ============================================================

-- 系统配置表
CREATE TABLE sys_config (
    id                  BIGINT          NOT NULL COMMENT '配置主键（Snowflake）',
    tenant_id           BIGINT          NOT NULL DEFAULT 0 COMMENT '租户ID',
    config_key          VARCHAR(255)    NOT NULL COMMENT '配置键',
    config_value        TEXT            NOT NULL COMMENT '配置值',
    description         TEXT            DEFAULT NULL COMMENT '配置描述',
    config_type         VARCHAR(50)     NOT NULL DEFAULT 'SYSTEM' COMMENT '配置类型：SYSTEM-系统级，SERVICE-服务级，FEATURE-功能级',
    is_encrypted        TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '是否加密：0-明文，1-AES256加密',
    is_sensitive        TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '是否敏感：0-否，1-是（前端不可见）',
    created_by          BIGINT          DEFAULT NULL COMMENT '创建人ID',
    updated_by          BIGINT          DEFAULT NULL COMMENT '修改人ID',
    created_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '创建时间',
    updated_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) COMMENT '更新时间',
    deleted             TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已删除',
    version             INT             NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
    PRIMARY KEY (id),
    UNIQUE KEY uk_sys_config_key (tenant_id, config_key),
    KEY idx_sys_config_type (config_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='系统配置表';

-- 系统配置变更历史表
CREATE TABLE sys_config_history (
    id                  BIGINT          NOT NULL COMMENT '历史主键（Snowflake）',
    tenant_id           BIGINT          NOT NULL DEFAULT 0 COMMENT '租户ID',
    config_id           BIGINT          NOT NULL COMMENT '关联配置ID',
    old_value           TEXT            DEFAULT NULL COMMENT '旧值',
    new_value           TEXT            NOT NULL COMMENT '新值',
    operator_id         BIGINT          NOT NULL COMMENT '操作人ID',
    operator_name       VARCHAR(100)    NOT NULL COMMENT '操作人用户名',
    change_reason       VARCHAR(500)    DEFAULT NULL COMMENT '变更原因',
    created_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '变更时间',
    PRIMARY KEY (id),
    KEY idx_sys_ch_config_id (config_id),
    KEY idx_sys_ch_operator (operator_id),
    KEY idx_sys_ch_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='系统配置变更历史表';

-- 告警规则表
CREATE TABLE sys_alert_rule (
    id                  BIGINT          NOT NULL COMMENT '规则主键（Snowflake）',
    tenant_id           BIGINT          NOT NULL DEFAULT 0 COMMENT '租户ID',
    rule_name           VARCHAR(255)    NOT NULL COMMENT '规则名称',
    metric              VARCHAR(255)    NOT NULL COMMENT '监控指标：cpu_usage,memory_usage等',
    threshold           DOUBLE          NOT NULL COMMENT '阈值',
    operator            VARCHAR(10)     NOT NULL DEFAULT '>' COMMENT '比较操作符：>,<,>=,<=,==',
    level               VARCHAR(20)     NOT NULL DEFAULT 'WARNING' COMMENT '告警级别：CRITICAL-严重，WARNING-警告，INFO-信息',
    notification_channels JSON         DEFAULT NULL COMMENT '通知渠道列表，如["email","dingtalk"]',
    is_enabled          TINYINT(1)      NOT NULL DEFAULT 1 COMMENT '是否启用：0-禁用，1-启用',
    description         VARCHAR(500)    DEFAULT NULL COMMENT '规则描述',
    created_by          BIGINT          DEFAULT NULL COMMENT '创建人ID',
    updated_by          BIGINT          DEFAULT NULL COMMENT '修改人ID',
    created_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '创建时间',
    updated_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) COMMENT '更新时间',
    deleted             TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已删除',
    version             INT             NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
    PRIMARY KEY (id),
    KEY idx_sys_ar_tenant (tenant_id),
    KEY idx_sys_ar_enabled (is_enabled),
    KEY idx_sys_ar_metric (metric)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='告警规则表';

-- 告警事件表
CREATE TABLE sys_alert_event (
    id                  BIGINT          NOT NULL COMMENT '事件主键（Snowflake）',
    tenant_id           BIGINT          NOT NULL DEFAULT 0 COMMENT '租户ID',
    rule_id             BIGINT          NOT NULL COMMENT '关联告警规则ID',
    metric_value        DOUBLE          NOT NULL COMMENT '触发时的实际值',
    message             TEXT            NOT NULL COMMENT '告警消息',
    status              VARCHAR(20)     NOT NULL DEFAULT 'FIRING' COMMENT '告警状态：FIRING-触发中，RESOLVED-已解决',
    fired_at            DATETIME(3)     NOT NULL COMMENT '告警触发时间',
    resolved_at         DATETIME(3)     DEFAULT NULL COMMENT '告警解决时间',
    created_by          BIGINT          DEFAULT NULL COMMENT '系统自动触发时为NULL',
    created_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '记录创建时间',
    PRIMARY KEY (id),
    KEY idx_sys_ae_rule (rule_id),
    KEY idx_sys_ae_tenant_status (tenant_id, status),
    KEY idx_sys_ae_fired_at (fired_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='告警事件表';

-- 系统日志表
CREATE TABLE sys_system_log (
    id                  BIGINT          NOT NULL COMMENT '日志主键（Snowflake）',
    tenant_id           BIGINT          NOT NULL DEFAULT 0 COMMENT '租户ID',
    level               VARCHAR(20)     NOT NULL COMMENT '日志级别：ERROR,WARN,INFO,DEBUG,TRACE',
    service_name        VARCHAR(100)    NOT NULL COMMENT '服务名称',
    logger              VARCHAR(255)    DEFAULT NULL COMMENT 'Logger名称',
    message             TEXT            NOT NULL COMMENT '日志消息',
    trace_id            VARCHAR(128)    DEFAULT NULL COMMENT '分布式追踪ID',
    span_id             VARCHAR(128)    DEFAULT NULL COMMENT 'Span ID',
    thread_name         VARCHAR(255)    DEFAULT NULL COMMENT '线程名称',
    exception           MEDIUMTEXT      DEFAULT NULL COMMENT '异常堆栈',
    created_at          DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '日志时间',
    PRIMARY KEY (id, created_at),
    KEY idx_sys_log_level (level),
    KEY idx_sys_log_service (service_name),
    KEY idx_sys_log_trace (trace_id),
    KEY idx_sys_log_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='系统日志表（分区）'
PARTITION BY RANGE (YEAR(created_at)) (
    PARTITION p2025 VALUES LESS THAN (2026),
    PARTITION p2026 VALUES LESS THAN (2027),
    PARTITION p2027 VALUES LESS THAN (2028),
    PARTITION p_future VALUES LESS THAN MAXVALUE
);
```

**安全策略**：
- 最小权限原则：用户只能访问必要的系统管理功能
- 定期安全审计：定期审计系统配置和权限
- 安全备份：定期备份系统配置和监控数据
