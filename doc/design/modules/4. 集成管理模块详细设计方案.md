# 集成管理模块详细设计方案

> **对齐**：工程实现与门禁以 `doc/architecture/Bone-DDD-最终实践方案.md` 为准；能力与优先级以 `doc/prd/BONE产品需求文档正式版.md` 第 4 章为准。  
> **仓库对照**：集成能力分两处实现——**集成引擎** `bone-engine/bone-integration`（默认 HTTP **30888**）、**平台集成服务** `bone-platform/bone-integration`（默认 **8085**，`context-path` 常为 `/api`）。端口以根 [README.md](../../../README.md) 与各模块 `application.yml` 为准。

## 1. 模块概述

集成管理模块是 BONE 平台的核心能力之一，负责系统间的集成和流程编排，是实现企业集成能力的关键模块。

**核心目标**：
- 提供连接器管理能力，支持与外部系统的连接
- 实现可视化的流程编排，支持系统间的数据流转
- 提供流程监控和执行日志，确保集成流程的可靠性
- 支持场景化的集成模板，提高集成开发效率
- 提供集成流程的版本管理和生命周期管理

## 2. 功能设计

### 2.1 连接器管理

**功能描述**：管理与外部系统的连接器，支持连接器的创建、配置、测试和监控。

**详细功能**：
- **连接器创建**：创建各种类型的连接器，如 REST、SOAP、JDBC、FTP、MQ 等
- **连接器配置**：配置连接器的连接参数，如 URL、用户名、密码等
- **连接器测试**：测试连接器的连接状态和可用性
- **连接器监控**：监控连接器的连接状态和使用情况
- **连接器模板**：提供常用连接器的模板，如数据库、API 等

**用户故事**：
> 作为集成工程师，我希望配置与外部系统的连接器，测试连接状态，以实现系统集成。

### 2.2 流程编排

**功能描述**：使用可视化工具设计和管理集成流程，支持流程的创建、编辑、测试和激活。

**详细功能**：
- **流程创建**：创建集成流程，设置流程名称、描述等基本信息
- **可视化设计**：使用拖拽式界面设计流程，添加和配置流程节点
- **节点配置**：配置流程节点的参数和属性
- **流程测试**：测试流程的执行效果
- **流程激活**：激活流程，使其正式运行
- **流程版本**：管理流程的版本历史，支持版本对比和回滚

**用户故事**：
> 作为集成工程师，我希望使用可视化工具设计集成流程，配置流程节点和连接关系，以实现系统间的数据流转。

### 2.3 流程监控

**功能描述**：监控集成流程的执行状态，查看执行日志，处理错误。

**详细功能**：
- **执行状态监控**：监控流程的执行状态，如运行中、成功、失败等
- **执行日志查看**：查看流程的详细执行日志，包括每个节点的执行状态和输入输出数据
- **错误处理**：处理流程执行过程中的错误，支持手动重试和错误修复
- **执行统计**：统计流程的执行次数、成功率、平均执行时间等指标
- **告警通知**：当流程执行失败时，发送告警通知

**用户故事**：
> 作为集成工程师，我希望监控集成流程的执行状态，查看执行日志，处理错误，以确保流程正常运行。

### 3.4 关键实现

#### 3.4.1 连接器管理

```java
package com.bone.integration.application.command.handler;

import com.bone.integration.application.command.cmd.CreateConnectorCmd;
import com.bone.integration.domain.model.connector.Connector;
import com.bone.integration.domain.model.connector.vo.ConnectorName;
import com.bone.integration.domain.model.connector.vo.ConnectorType;
import com.bone.integration.domain.repository.ConnectorRepository;
import com.bone.integration.common.exception.BusinessException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

@Component
@RequiredArgsConstructor
public class CreateConnectorHandler {
    private final ConnectorRepository connectorRepository;
    
    @Transactional
    public Long handle(CreateConnectorCmd cmd) {
        ConnectorName connectorName = new ConnectorName(cmd.getName());
        ConnectorType connectorType = new ConnectorType(cmd.getType());
        
        // 检查连接器名称是否已存在
        if (connectorRepository.existsByName(cmd.getName())) {
            throw new BusinessException("连接器名称已存在");
        }
        
        Connector connector = Connector.create(
            connectorName,
            connectorType,
            cmd.getConfig()
        );
        
        connectorRepository.save(connector);
        
        return connector.getId().getValue();
    }
}
```

#### 3.4.2 流程编排

```java
package com.bone.integration.application.command.handler;

import com.bone.integration.application.command.cmd.CreateFlowCmd;
import com.bone.integration.domain.model.flow.IntegrationFlow;
import com.bone.integration.domain.model.flow.FlowNode;
import com.bone.integration.domain.model.flow.FlowConnection;
import com.bone.integration.domain.model.flow.vo.FlowName;
import com.bone.integration.domain.repository.IntegrationFlowRepository;
import com.bone.integration.domain.repository.FlowNodeRepository;
import com.bone.integration.domain.repository.FlowConnectionRepository;
import com.bone.integration.common.exception.BusinessException;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Component
@RequiredArgsConstructor
public class CreateFlowHandler {
    private final IntegrationFlowRepository flowRepository;
    private final FlowNodeRepository nodeRepository;
    private final FlowConnectionRepository connectionRepository;
    
    @Transactional
    public Long handle(CreateFlowCmd cmd) {
        FlowName flowName = new FlowName(cmd.getName());
        
        // 检查流程名称是否已存在
        if (flowRepository.existsByName(cmd.getName())) {
            throw new BusinessException("流程名称已存在");
        }
        
        IntegrationFlow flow = IntegrationFlow.create(
            flowName,
            cmd.getDescription()
        );
        
        IntegrationFlow savedFlow = flowRepository.save(flow);
        
        // 保存流程节点
        List<FlowNode> nodes = cmd.getNodes().stream()
                .map(nodeCmd -> FlowNode.create(
                    savedFlow.getId(),
                    nodeCmd.getName(),
                    nodeCmd.getType(),
                    nodeCmd.getConfig(),
                    nodeCmd.getPositionX(),
                    nodeCmd.getPositionY()
                ))
                .toList();
        nodeRepository.saveAll(nodes);
        
        // 保存流程连接
        List<FlowConnection> connections = cmd.getConnections().stream()
                .map(connCmd -> FlowConnection.create(
                    savedFlow.getId(),
                    connCmd.getSourceNodeId(),
                    connCmd.getTargetNodeId(),
                    connCmd.getCondition()
                ))
                .toList();
        connectionRepository.saveAll(connections);
        
        return savedFlow.getId().getValue();
    }
}
```

@Component
@RequiredArgsConstructor
public class ExecuteFlowHandler {
    private final IntegrationLogRepository logRepository;
    private final IntegrationFlowRepository flowRepository;
    
    @Transactional
    public Long handle(ExecuteFlowCmd cmd) {
        // 验证流程存在
        IntegrationFlow flow = flowRepository.findById(cmd.getFlowId())

            flow.getId(),
            cmd.getInputData()

## 7. 性能与安全

### 7.1 性能优化

- **缓存策略**：使用 Redis 缓存连接器配置和流程定义，减少数据库查询
- **异步处理**：流程执行采用异步方式，避免阻塞主线程
- **批处理**：批量处理流程执行记录，减少数据库操作次数
- **连接池**：使用连接池管理外部系统连接，提高连接效率
- **负载均衡**：支持多实例部署，实现负载均衡

### 7.2 安全措施

- **权限控制**：基于 RBAC 的细粒度权限控制
- **数据验证**：严格的输入验证，防止注入攻击
- **敏感信息保护**：连接器配置中的敏感信息加密存储
- **审计日志**：记录所有集成操作，支持审计追踪
- **网络安全**：使用 TLS 加密与外部系统的通信
