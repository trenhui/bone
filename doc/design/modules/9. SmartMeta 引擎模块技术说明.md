## 2. 根包与分层思想

引擎源码根包：

`bone-metadata-engine-core/src/main/java/com/bone/metadata/engine/`

设计取向（与 Bone 全局 DDD 叙述对齐，但本引擎以 **元数据运行时** 为重）：

- **metadata / model**：实体、字段、操作、工作流等元数据定义与注册表抽象。
- **service**：面向「通用操作 / 动态数据」的应用级编排（如 `GenericOperationService`、`DynamicDataService`）。
- **query**：SmartQL 解析、SQL 生成、执行与性能相关组件。
- **rule / expression / validation**：业务规则、表达式求值、元数据校验策略。
- **security**：字段级安全、权限评估、审计与脱敏等（部分为演示或扩展点，以类上注释为准）。
- **repository**：元数据仓储接口与内存等实现；**动态物理表** 见 `runtime` 子包（`JdbcRuntimeRecordService`，由宿主如 `bone-metadata-server` 装配）。
- **runtime**：模式 B 动态行读写（JDBC），非独立 HTTP 进程。
- **config**：`SmartMetaAutoConfiguration`、`SmartMetaProperties`、`RuleEngineConfig` 等 Spring 装配。
- **cache / tenant / multi / context**：缓存、租户与请求上下文。
- **annotation**：`@SmartEntity`、`@SmartField`、`@BusinessRule` 等声明式元数据入口。

**依赖建议（阅读代码时）**：从 `MetadataEngine`、`GenericOperationService`、`DynamicDataService` 入口向下追踪，比死记虚构包树更有效。

### 2.1 边界重划（change `refactor/metadata-engine-boundary-ddd`）

按 DDD 端口-适配器在 `core` 内重划边界，依赖方向：`domain（零依赖）← spi（仅接口）← adapter（依赖 SDK/Spring）← starter（Spring 装配）`：

- **`spi`（端口/ports）**：`MetadataRepositoryPort`（读侧契约）、`MetadataPlatformBridge`（租户/事件/已发布实体加载）。**零 `org.springframework.*` / `com.bone.metadata.sdk.*` 依赖**，由 `architecture.EngineArchitectureTest` 固化。
- **`adapter`（运行时/runtime）**：`SdkMetadataRepository`（基于 `bone-metadata-sdk` 的 `Repository<MetaEntityPo, Long>` 读已发布 `meta_entity`/`meta_field`）、`MetaEntityConverter`（防腐层 ACL 转换）、`IamMetadataBridge`（`currentTenantId()` 接 `TenantContext`、`publishEvent()` 接 `ApplicationEventPublisher`）、`InMemoryMetadataRepositoryPort`（内存测试/回退实现）。
- **`architecture`**：`EngineArchitectureTest` 增量门禁。

物理拆分为 `engine-domain`/`engine-ports`/`engine-runtime`/`engine-starter` 四个 Maven 子模块列为后续可选项（T9），当前在 core 内包重划达成边界清晰。

## 3. 子包职责速查（与当前目录一致）

下列为 `com.bone.metadata.engine` 下常见子包及职责摘要（随版本演进以 `bone-metadata-engine-core/src/main/java` 目录为准）：

| 子包 | 职责摘要 |
|------|----------|
| `spi` | 端口（ports）：`MetadataRepositoryPort` / `MetadataPlatformBridge`，仅接口，零 spring/sdk 依赖 |
| `adapter` | 运行时（runtime）：`SdkMetadataRepository` / `IamMetadataBridge` / `MetaEntityConverter` / `InMemoryMetadataRepositoryPort`（防腐层 ACL） |
| `architecture` | ArchUnit 增量门禁（`EngineArchitectureTest`） |
| `annotation` | 实体/字段/规则等注解与类型枚举 |
| `metadata` | 元数据定义类、操作与工作流元数据、处理器协作 |
| `model` | 注册表模型、动态实体、规则结果等运行期模型 |
| `repository` | 元数据持久化/内存仓储抽象与实现 |
| `service` / `service/impl` | 通用操作、动态数据、规则引擎实现等 |
| `query` / `query/ast` | SmartQL、AST、SQL 生成、执行与缓存 |
| `expression` | 表达式求值 |
| `validation` / `validation/strategy` | 元数据与字段校验策略 |
| `rule` | 规则注册、求值上下文工厂等 |
| `security` | 权限、字段级安全、脱敏、演示用安全样例 |
| `cache` | 元数据缓存与统计 |
| `config` | 自动配置与引擎初始化 |
| `tenant` / `multi` / `context` | 租户与多租户上下文、用户上下文 |
| `event` | 元数据变更等事件发布抽象 |
| `exception` / `common` | 异常体系与公共常量 |
| `util` / `analysis` / `impact` / `version` | 工具、影响分析、版本控制等横切能力 |
