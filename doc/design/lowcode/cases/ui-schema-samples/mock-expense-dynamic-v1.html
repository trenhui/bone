走查剧本（5 步）

1. 发票类型选 增值税专票 → 税号现身且必填（linkage 专票规则）。
2. 把申报金额改成与明细合计不一致 → 点动作条外任意处无感，点 提交 被拦（submit 明细合计）。
3. 金额填 6000 → 审批区要求指定审批人（linkage 大额规则）；结束日期改到开始之前 → 行内警告且提交阻断（compare）。
4. 点 提交 → 状态 DRAFT→SUBMITTED，动作条自动换成审批/驳回；点 审批通过 → 出现打款。
5. 点 确认打款 → 填渠道+备注（params_schema 入参表单）→ PAID；再点一次同动作 → 幂等命中提示（未重复执行）。
