## DDL 决策（2026-05-16 终局）

| 项 | 结论 |
|----|------|
| 唯一脚本 | `bone-init.sql`（**50** 张表：IAM 9 + System 4 + Integration 7 + Meta 5 + exts 5 + gen 7 + cnsl 3 + mdm 8 + 兼容 md 2） |
| 主键 | BIGINT Snowflake，禁止 AUTO_INCREMENT |
| 时间/操作人 | 统一 `created_at` / `updated_at` / `created_by` / `updated_by` 及业务 `xxx_at` |
| 集成执行表 | **`int_execution_log`**（非 `int_flow_execution`） |
| 变更 | 改 init → 重建库；`spring.flyway.enabled: false` |
