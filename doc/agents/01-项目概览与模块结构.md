## 1. 项目概述

**Bone**（口号：Build Once, Natively Everywhere）是一个企业级全栈开源快速开发平台，采用**元数据驱动**架构，目标是通过配置减少重复编码，实现一次构建、多端运行。

项目为**前后端分离**的**微服务/模块化单体**混合架构：
- **后端**：Java 21 + Spring Boot 3.5.16 多模块 Maven 工程（版本真源 `bone-parent/pom.xml`；升级记录见 `doc/plans/spring-boot-3.5-upgrade.md`）
- **前端**：React 18 + TypeScript 微前端（Qiankun）工程，使用 npm workspaces 管理

业务定位覆盖四大引擎：
1. **智能元数据引擎**（Smart Metadata）— 动态建模、规则/表达式；**代码生成**见 `studio-generator`（与 engine 混合，见 [元数据能力对照](../design/modules/元数据能力-实现映射与竞品对照.md)）
2. **企业主数据平台**（Master Data）— 主数据治理与质量管控
3. **ExtPoint 扩展引擎**（Extension）— 插件化扩展点机制
4. **集成引擎**（Integration）— 多协议连接器与流程编排

DDD 战略上，Bone **当前只认定**元数据 / 建模为核心域（[ADR-0023](../architecture/adr/0023-core-domain-smart-metadata.md)）；这是一项产品战略决策，不是“DDD 只能有一个核心域”的行业规则。主数据、集成、扩展为支撑域。通用语言见 [doc/glossary.md](../glossary.md)。

## 3. 模块结构

### 3.1 后端模块（Maven 多模块）

根 POM（`pom.xml`）为聚合模块，所有版本与依赖在 `bone-parent/pom.xml` 中统一管理。

```
bone/                          # 根聚合模块
├── bone-parent/               # BOM / 依赖管理 / 插件配置
├── bone-framework/            # 原子核心能力
│   ├── bone-core/             # 基础实体、注解、统一响应、工具类、租户上下文
│   ├── bone-utils/            # 通用工具（当前仅 pom，无源码）
│   ├── bone-datasource/       # 数据源抽象与动态数据源
│   ├── bone-security/         # 安全组件
│   ├── bone-web/              # Web 层封装（Spring Web、校验、AOP、全局异常）
│   └── bone-architecture-test/ # 共享 ArchUnit 规则库（BoneDddArchRules 等 39 条）
├── bone-engine/               # 引擎与核心中间件
│   ├── bone-metadata-sdk/     # 平台数据面（P0 持久化 + 扩展字段：预留列/JSON/EAV）
│   ├── bone-metadata-server/  # 扩展字段 REST（:9001，选配）
│   ├── bone-metadata-engine/  # 智能元数据引擎（domain + ports + runtime + starter，选配）
│   ├── bone-extension-engine/ # 扩展引擎
│   │   ├── bone-extension-sdk/
│   │   └── bone-extension-studio/
│   ├── studio-generator/      # Studio 代码生成（DDD 分层，替代原 bone-tool/bone-codegen）
│   └── go-engine/             # Go 实验目录（不进 Maven reactor；契约与行为以 Java 为准）
├── bone-ai/                   # AI 能力中台（2026-10 新增，根 pom 已聚合，共 10 个子模块）
│   ├── bone-ai-gateway/       # 模型网关（对话 / 嵌入 / 多模态统一出口；熔断 / 重试 / 计量）
│   ├── bone-ai-trace/         # AI 调用 trace 落盘
│   ├── bone-ai-rules/         # 规则治理（QLExpress 执行 + 发布回归门禁）
│   ├── bone-ai-orchestration/ # 编排（HITL 五态状态机）
│   ├── bone-ai-document/      # 文档解析（OCR sidecar 协作）
│   ├── bone-ai-rag/           # RAG 混合检索
│   ├── bone-ai-notification/  # 告警通知
│   ├── bone-ai-integration/   # 外部系统集成
│   ├── bone-ai-app/           # 生产拓扑聚合：全部 AI 节点聚合成可部署 Spring Boot 应用（含评测门禁）
│   └── bone-ai-server/        # 参考宿主：智能理赔场景端到端验证 + REST 演示端点
├── bone-platform/             # 企业共享平台服务
│   ├── bone-iam/              # 身份与访问管理（端口 8081）
│   ├── bone-gateway/          # API 网关（端口 8888；JWT、限流、熔断、路由）
│   ├── bone-masterdata/       # 主数据服务
│   ├── bone-system/           # 系统管理（端口 8083）
│   ├── bone-file/             # 文件上传下载（MinIO）；file_object 元数据表未落库
│   ├── bone-notification/     # 通知服务（目前仅告警通道 Alert）
│   └── bone-integration/      # 唯一集成服务（:8085，/api/v1/integration）
├── bone-apps/                 # 业务应用层（跑在元数据引擎上的业务应用；2026-10 从 bone-engine 迁出）
│   ├── bone-app-expense/      # 报销业务应用：报销单写前钩子 + 借款/报销打款逃逸处理器
│   ├── bone-app-purchase/     # 采购业务应用：采购订单付款逃逸处理器
│   └── synap-claim/           # 智能理赔平台（DDD 四层；原在 bone-engine，2026-10-23 迁入）
├── bone-boot/                 # 组装引导组合根（部署装配）：聚合元数据平台 + 各业务应用，产出可运行 jar
└── bone-blueprint/            # DDD 参考实现（端口 8082，订单示例）

# 不在 Maven reactor 内（根 pom 的 <modules> 聚合 parent/framework/engine/apps/boot/platform/ai/blueprint）：
#   bone-sdk/bone-client-sdk、bone-sdk/bone-openapi-sdk —— ADR-0040 后整棵移除，现存空目录（仅 target/）
#   bone-tool/bone-codegen —— 同上，空目录；代码生成能力已由 bone-engine/studio-generator 承担
```

### 3.2 前端模块（npm workspaces）

> 微应用统一通过 `packages/shared-config` 的 `createQiankunViteConfig(name, port)` 注册端口与网关代理（8888）。新增微应用务必沿用该工厂，避免端口冲突与代理漂移。

```
bone-frontend/
├── apps/                                   # 微应用（Qiankun 子应用，各自独立端口）
│   ├── bone-shell/            # Qiankun 主应用（端口 3000）：布局 / 导航 / 微应用注册
│   ├── bone-iam-app/          # IAM 微应用（端口 3003）
│   ├── bone-metadata-app/     # 元数据微应用（端口 3004）
│   ├── bone-masterdata-app/   # 主数据微应用（端口 3005）
│   ├── bone-integration-app/  # 集成微应用（端口 3006）
│   ├── bone-system-app/       # 系统管理微应用（端口 3007）
│   ├── bone-extension-app/    # 扩展引擎微应用（端口 3008）
│   ├── bone-generator-app/    # Studio 代码生成微应用（端口 3009）
│   ├── bone-commerce-app/     # 交易/商务微应用（端口 3012，承载 blueprint 交易域用户面端点）
│   └── bone-claim-app/        # 智能理赔微应用（端口 3013；对应后端 synap-claim，2026-10 补建）
├── packages/                                 # 共享包（npm workspaces）
│   ├── ui/                   # @bone/ui：共享设计系统（主题 + BoneAppProvider）
│   ├── core/                 # @bone/core：event-bus / performance-monitor / workflow-dsl
│   ├── shared-components/    # @bone/shared-components
│   ├── shared-config/        # @bone/shared-config：Vite/Qiankun 配置工厂（createQiankunViteConfig）
│   ├── shared-services/      # @bone/shared-services
│   ├── shared-types/         # @bone/shared-types
│   ├── shared-utils/         # @bone/shared-utils
│   └── ui-schema/            # @bone/ui-schema：低代码界面 JSON 协议与运行时
├── bench/                    # 性能基准
├── tests/                    # 全局测试（Vitest）
├── tools/                    # 构建 / 代码生成辅助脚本
└── config/                   # 共享构建配置
```

> 根目录非模块支撑目录（`bench/`、`tests/`、`tools/`、`config/`）不计入业务能力模块，仅作工程基建。
