## 根聚合（Maven）

根 [pom.xml](../../pom.xml) 当前聚合模块为：

| 模块路径 | 说明 |
|----------|------|
| `bone-parent` | 依赖版本、插件与 BOM |
| `bone-framework` | `bone-core`、`bone-web`、`bone-security`、`bone-datasource`、`bone-utils` 等基础能力 |
| `bone-engine` | 元数据、智能元数据、扩展引擎、集成引擎等（见下） |
| `bone-platform` | IAM、网关、主数据、系统、文件、通知等平台服务 |
| `bone-business` | 行业业务（`tpa-saas` Java、`tpa-sass-react` / `tpa-sass-vue3`；**规划**：后端 Go、前端统一 React，见 [TPA-MIGRATION.md](../../bone-business/TPA-MIGRATION.md)） |
| `bone-sdk` | 客户端 / OpenAPI SDK |
| `bone-tool` | 代码生成等工具（如 `bone-codegen`） |

> **说明**：**[bone-blueprint](../../bone-blueprint/)**（DDD 蓝图）**默认不**参与根聚合全量构建；本地/CI 使用 `mvn -f bone-blueprint/pom.xml test` 或 `mvn -Pblueprint`（见 [08-blueprint与主工程对齐](./08-blueprint与主工程对齐.md)）。

## 前端 Monorepo（`bone-frontend`）

- **Workspace**：根 [package.json](../../bone-frontend/package.json) 声明 `apps/*`、`packages/*`。
- **主应用**：`apps/bone-shell`（根目录 `npm run dev` 默认启动 Shell）。
- **典型微应用**：`bone-iam-app`、`bone-metadata-app`、`bone-masterdata-app`、`bone-integration-app`、`bone-system-app`、`bone-extension-app`、`bone-generator-app` 等。
- **共享包**：`packages/` 下 `shared-*`、`core` 等（以实际目录为准）。

批量启动脚本与说明见 [bone-frontend/SCRIPT_USAGE.md](../../bone-frontend/SCRIPT_USAGE.md)。

## 分层依赖（后端）

```
adapter/web → application → domain ← infrastructure
```

- **domain**：不依赖 Spring / JPA / MyBatis 等框架注解（领域模型保持纯净）。
- **application**：不直接依赖 `infrastructure` 实现类，通过接口与注入边界协作。
- **持久化 P0**：默认 Bone Metadata SDK + `bone-datasource`（见 [Bone-DDD §12.1](../architecture/Bone-DDD-最终实践方案.md)）。

详见 [05-工程规范与安全](./05-工程规范与安全.md) 与 [doc/architecture/Bone-DDD-最终实践方案.md](../architecture/Bone-DDD-最终实践方案.md)。
