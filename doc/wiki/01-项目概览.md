## 定位

**Bone** 是企业级全栈开源快速开发平台，口号 **Build Once, Natively Everywhere**：通过元数据与平台化能力减少重复编码，支撑 Web 管理端与可扩展的微服务/模块化后端。

---

## 四大引擎（产品视角）

| 引擎 | 职责 |
|------|------|
| **智能元数据** | 动态建模、规则与代码生成，业务与技术解耦 |
| **企业主数据** | 核心数据治理、质量规则、一致可信的主数据服务 |
| **ExtPoint 扩展** | 扩展点、插件生命周期、个性化逻辑注入 |
| **集成** | 连接器、数据转换、流程编排、与外部系统对接 |

协同关系（概念）：元数据定义「是什么」→ 主数据保障质量 → 扩展引擎定制「怎么做」→ 集成引擎连接外部生态。

---

## 技术栈摘要

### 后端

- **语言 / 构建**：Java 17，Maven 3.8+
- **框架**：Spring Boot 3.2.x，Spring Cloud / Alibaba（按 `bone-parent` BOM）
- **数据**：MySQL 8.x，HikariCP；**默认** Bone Metadata SDK + `bone-datasource`（见 [Bone-DDD §12.1](../architecture/Bone-DDD-最终实践方案.md)）；部分模块（如 `bone-iam`）仍为 MyBatis 遗留路径，迁移中
- **缓存 / 消息等**：Redis、Redisson、RocketMQ、Seata 等（见父 POM 与模块依赖）

### 前端

- **运行时**：React 18、TypeScript 5.x、Vite 4.x+
- **UI**：Ant Design 5、Pro Components
- **微前端**：Qiankun + `vite-plugin-qiankun`（子应用）

详细版本表见 [CODE_WIKI.md §2](../../CODE_WIKI.md) 或 [AGENTS.md §2](../../AGENTS.md)。
