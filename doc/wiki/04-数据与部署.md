## 数据库

- **引擎**：MySQL 8.x（InnoDB，`utf8mb4` / `utf8mb4_unicode_ci`）
- **库名**：常见为 `bone`（以环境配置为准）

### 初始化脚本

| 路径 | 用途 |
|------|------|
| [bone-init.sql](../../bone-init.sql) | 根目录初始化脚本（表结构 + 种子数据；开发默认 **admin / 123456**） |
| [doc/architecture/数据库开发规范.md](../architecture/数据库开发规范.md) | MySQL 命名、租户、审计、索引与分区约定 |
| [doc/architecture/初始脚本.sql](../architecture/初始脚本.sql) | 文档化全量 DDL（无种子；表数量以文件为准）；与 `bone-init.sql` 不一致时以迁移与线上一致为准 |
| [doc/deployment/sql/](../deployment/sql/) | 部署相关补充 SQL |

### 表设计共性（多模块约定）

业务表常见字段包括：

- **多租户**：`tenant_id`、`biz_identity_code`
- **时间与操作人**：`created_at`、`updated_at`、`created_by`、`updated_by`；业务时刻统一 `xxx_at`
- **软删**：`deleted`

## 环境变量（开发集中配置）

**推荐**：仓库根 [`.env.example`](../../.env.example) → 复制为 `.env`（已 gitignore），启动前 `source scripts/dev/load-env.sh`。详见 [config/env/README.md](../../config/env/README.md)。

| 变量 | 用途 |
|------|------|
| `BONE_DB_URL` / `BONE_DB_USERNAME` / `BONE_DB_PASSWORD` | MySQL |
| `BONE_REDIS_HOST` / `BONE_REDIS_PORT` / `BONE_REDIS_PASSWORD` | Redis |
| `BONE_JWT_SECRET` | IAM JWT（开发可弱，生产必须轮换） |
| `BONE_SERVER_PORT` | 覆盖 `server.port`（可选） |

校验连通：`./scripts/dev/db-verify.sh`；按 `bone-init.sql` 重建（含 DROP）：`./scripts/dev/db-init.sh`（仅开发）。

## 部署形态

- **后端**：Spring Boot 可执行 **Fat JAR**（`spring-boot-maven-plugin` repackage）。
- **前端**：各微应用 Vite 构建产物，由 Shell（Qiankun）或静态资源服务器加载。
- **容器 / CI**：以仓库当前文件为准；若未提供 Dockerfile / compose，需在运维侧自行补齐。

---

## 安全提示（部署必读）

- 修改默认管理员密码（若初始化数据含默认账号）。
- 生产环境**禁止**在配置中硬编码数据库、Redis、Token 密钥；使用环境变量或配置中心。
- 生产环境收紧 CORS、API 文档暴露范围与 SA-Token / JWT 密钥轮换策略。

更多见 [05-工程规范与安全](./05-工程规范与安全.md)。
