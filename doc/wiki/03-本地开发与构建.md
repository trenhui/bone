## 后端（Maven）

在仓库根目录执行：

```bash
# 首次建议全量安装（可按需跳过测试）
mvn clean install -DskipTests

# 单模块编译示例
mvn compile -pl bone-platform/bone-iam -am

# 单模块测试示例
mvn test -pl bone-platform/bone-masterdata

# 代码格式化（全仓，与 CI 一致）
mvn com.diffplug.spotless:spotless-maven-plugin:2.43.0:check --batch-mode
mvn com.diffplug.spotless:spotless-maven-plugin:2.43.0:apply --batch-mode

# DDD 蓝图示例（独立模块）
mvn -f bone-blueprint/pom.xml test

# 本地复现主 CI（密钥 + spotless + blueprint + verify + 前端）
bash scripts/ci-local.sh
```

阿里云 Maven 镜像已在根 [pom.xml](../../pom.xml) 的 `<repositories>` 中配置。提交前清单见 [CONTRIBUTING.md](../../CONTRIBUTING.md)。

## 前端（npm workspaces）

```bash
cd bone-frontend

# 推荐：与 CI 一致的可重复安装
npm ci

# 可选：为各 workspace 安装依赖（若仓库提供脚本）
bash setup.sh

# 启动 Shell（根 package.json 默认）
npm run dev

# 在某一微应用目录内（开发时可用 npm install；提交前请保证 package-lock 已更新并用 npm ci 验证）
cd apps/bone-masterdata-app
npm run dev
```

全量构建、Lint、测试：

```bash
cd bone-frontend
npm ci
npm run build
npm run lint
npm run test
```

## 常见服务端口（与仓库配置对照）

**以各模块 `application.yml` / `vite.config.ts` 为准**；下表为仓库 As-Is 默认值。若同机多服务默认端口冲突，请修改 yml 或使用 `SERVER_PORT` / `BONE_SERVER_PORT`。

### 后端（`server.port`）

| 模块 | 默认端口 | 配置文件 |
|------|----------|----------|
| bone-masterdata | 8080 | `bone-platform/bone-masterdata/src/main/resources/application.yml` |
| bone-iam | 8081 | `bone-platform/bone-iam/src/main/resources/application.yml` |
| bone-system | 8083 | `bone-platform/bone-system/src/main/resources/application.yml` |
| bone-integration（平台） | 8085（`context-path`：`/api`） | `bone-platform/bone-integration/src/main/resources/application.yml` |
| bone-integration（引擎） | 30888 | `bone-engine/bone-integration/src/main/resources/application.yml` |
| bone-extension-studio | 8080 | `bone-engine/bone-extension-engine/bone-extension-studio/src/main/resources/application.yml` |
| bone-studio-generator | 8085 | `bone-engine/studio-generator/src/main/resources/application.yml` |

**冲突提示**：`bone-masterdata` 与 `bone-extension-studio` 默认均为 **8080**；`bone-platform/bone-integration` 与 `bone-studio-generator` 默认均为 **8085**。同机调试时请只启其一或改端口。

| bone-masterdata-app | 3005 | `bone-frontend/apps/bone-masterdata-app/vite.config.ts` |
| bone-integration-app | 3006 | `bone-frontend/apps/bone-integration-app/vite.config.ts` |
| bone-system-app | 3007 | `bone-frontend/apps/bone-system-app/vite.config.ts` |
| bone-extension-app | 3008 | `bone-frontend/apps/bone-extension-app/vite.config.ts` |

## 运行 Spring Boot 模块

典型方式：

```bash
cd bone-platform/bone-iam
mvn spring-boot:run
```

或使用打包后的可执行 JAR（版本号以实际构建产物为准）：

```bash
java -jar bone-platform/bone-iam/target/bone-iam-1.0.0.jar
```

## 扩展管理（Phase 1 MVP）

详设：[5. 扩展管理模块详细设计方案.md](../design/modules/5.%20扩展管理模块详细设计方案.md) §0.4。

```bash
# 控制面（勿与 masterdata 同占 8080，可改 server.port）
cd bone-engine/bone-extension-engine/bone-extension-studio
mvn spring-boot:run -Dspring-boot.run.profiles=dev   # runtime-sync + Redis

# 微应用（代理 VITE_EXTENSION_STUDIO_URL，默认 http://localhost:8080）
cd bone-frontend/apps/bone-extension-app
npm run dev   # http://localhost:3008

# 业务进程启用路由叠加
# bone.extension.sync.enabled=true
```

控制台 UI：`bone-frontend/apps/bone-extension-app`（`bone-extension-studio-ui` 已删除）。
