# 诊断文档生命周期规范

本规范约束 BONE 工程 `doc/` 树下所有"诊断 / 复核 / review"类文档的创建、存活与销毁，
目标是消灭"已闭环却长期滞留、版本号失真、误导后续评审"的废文档。

> 背景：synapClaim 子域已建立 `role` / `currency` / `superseded_by` 字段纪律与 `09-records/reviews/`
> 暂存区，是正确范式。本规范将其扩到全仓 `doc/`。

## 1. 适用范围

文件满足以下任一条件即属"诊断文档"，须遵守本规范：

- 文件名含 `诊断` / `复核` / `review` / `诊断与优化` / `诊断报告`；
- 内容是"对某份真源（方案 / 设计 / 代码）的缺陷发现与修复建议"，而非规格或功能本身；
- frontmatter 中 `role: review` 或 `role: evidence`。

## 2. 强制 frontmatter

任何诊断文档**头部必须有**：

```yaml
---
doc_id: <稳定唯一 id，kebab-case>
role: review            # review=进行中/未闭环；evidence=闭环后冻结证据
currency: current       # current=仍有效；frozen=已闭环冻结
superseded_by: ""       # 被哪份真源文档/变更取代；闭环后填
closed_at: ""           # 所有发现项解决后填 ISO 日期（YYYY-MM-DD）
related_changes: []     # 指向真源方案/设计文档的 repo 相对路径
---
```

缺失任一字段，机检（`doc/_check_diagnosis.py`）判红。

## 3. 发现项闭环表（必备）

诊断文档**必须**内置一张发现项闭环表，每项至少包含：

```
| id | 严重度 | 指向的真源(文档/代码) | 解决证据(提交/版本号/文件) | 状态 |
```

- 状态取值：`✅ 已闭环` / `⚠️ 目标态(计划中)` / `❌ 未处理`。
- 仅当全部 `❌` 清零、且 `✅` 项均有可追溯证据时，方可进入"闭环"处置。
- **铁律**：发现项必须回写真源（方案章节 / 代码 / 提交），诊断文档永不当真源。

## 4. 生命周期

```
open ──(每项有解决证据)──> actioned ──(全部闭环)──> closed
                                                  │
                       ┌──────────────────────────┘
                       ▼
        ┌──────────────────────────┐
        │ 纯历史取证？              │
        │ 是 → role:evidence /      │
        │     currency:frozen       │
        │     移入 **/records/reviews/
        │ 否 → 删除并清理 README/索引 │
        └──────────────────────────┘
```

- `currency: current` 但 `closed_at` 为空且文件 `mtime > 90 天` → 机检标"陈旧，须闭环或删除"。
- 闭环后二选一：冻结为证据（保留、移入 `records/reviews/`、改 `currency: frozen`），
  或直接删除并同步清理所有 README / 索引指针（防悬空链接）。

## 5. 落地纪律（synapClaim 范式复用）

1. **新结论优先回写真源，不新建文档**：一次诊断的发现，直接在方案/设计里修订并留变更注，
   不要为"记录为什么改"再开一份文档。
2. **诊断文档是代码评审线程，不是设计文档**：缺陷回写后即应消失。
3. **命名与登记**：统一 `YYYY-MM-DD-<主题>-诊断.md` 或 `-复核.md`；在所属域 README 登记，
   删除时同步划掉登记项。
4. **决策记录不要伪装成诊断**：如"暂不加某能力"的论证，归入 ADR / evidence，而非 `诊断`。

## 6. 机检

脚本 `doc/_check_diagnosis.py`（对齐 synapClaim `check_all.py` 风格，ratchet 只减不增）：

- 诊断文档缺 frontmatter / 闭环表 → 判红；
- `currency: current` 且 `closed_at` 空 + `mtime > 90 天` → 标陈旧；
- README / 索引指向已删诊断文档 → 标悬空。

运行：`python3 doc/_check_diagnosis.py`，`--self-test` 自检规则。
