# ADR-0001：数据库 DDL 单轨真源（`bone-init.sql`）

| 项 | 内容 |
|----|------|
| **状态** | 已接受 |
| **日期** | 2026-05-16 |
| **决策者** | 平台架构 |

---

## 背景

Bone 当前为内部演进阶段，需降低「Flyway 增量 + init 全量 + 模块私有 schema」多轨并存带来的漂移与 onboarding 成本。

## 决策

| 项 | 结论 |
|----|------|
| 唯一可执行 DDL | 仓库根目录 **`bone-init.sql`** |
| 变更方式 | 修改 init → 开发环境 `DROP DATABASE` → 重新执行 |
| Flyway | 各服务 `spring.flyway.enabled: false` |
| 历史双轨 | `初始脚本.sql`、`DDL对齐说明.md` **废止**（仅 Git 历史） |

## 理由

- 单真源便于 Code Review 与 AI 契约  
- 无历史客户库兼容负担（当前阶段）  
- 与 [数据库开发规范.md](../数据库开发规范.md) 操作一致  

## 后果

### 正面

- PR 必见全量表结构变化  
- 新成员一条命令初始化  

### 负面

- 生产大表变更须单独运维方案（未来若引入增量迁移需新 ADR）  
- 无法「仅跑增量」回滚  

## 合规与迁移

详见 [数据库开发规范.md](../数据库开发规范.md)、`scripts/dev/db-init.sh`。

旧文档 [ADR-数据库迁移与DDL真源.md](../ADR-数据库迁移与DDL真源.md) 已 supersede。
