## 🎯 **平台架构全景图**

```
bone/
├── 📦 bone-parent/              # 父工程 - 统一依赖管理
├── 🔧 bone-core/                # 核心原子层 - 零业务依赖
├── ⚙️ bone-engine/              # 引擎驱动层 - 四大核心引擎
├── 🏢 bone-platform/            # 平台服务层 - 共享中台
├── 🚀 bone-services/            # 业务服务层 - 微服务实现
├── 📦 bone-starters/            # Starter层 - 开箱即用
├── 🔌 bone-sdk/                 # SDK层 - 多端集成
├── 🛠️ bone-tools/               # 工具层 - DevOps支持
└── 💡 bone-examples/            # 示例层 - 快速上手
```

## 📋 **核心设计原则**

| 原则 | 实施要点 |
|------|----------|
| **分层架构** | 严格分层，单向依赖，禁止循环 |
| **模块化** | 高内聚，低耦合，独立部署 |
| **元数据驱动** | 配置即代码，动态生成 |
| **扩展性** | SPI + 插件化，开闭原则 |
| **企业级** | 多租户、权限、监控、事务 |

## 📜 **命名规范标准**

### 包命名规范
```java
// 分层包名
com.bone.core.common.util          // 核心工具
com.bone.engine.metadata.service   // 元数据服务
com.bone.platform.auth.oauth2      // 认证OAuth2
com.bone.services.admin.system     // 管理系统

// 组件包名
com.bone.xxx.service               // 服务接口
com.bone.xxx.service.impl          // 服务实现
com.bone.xxx.repository            // 数据访问
com.bone.xxx.controller            // 控制器
com.bone.xxx.config                // 配置类
com.bone.xxx.model                 // 数据模型
com.bone.xxx.util                  // 工具类
```

### 类命名规范
| 类型 | 模式 | 示例 |
|------|------|------|
| 实体类 | XxxEntity | UserEntity |
| DTO类 | XxxDTO | UserDTO |
| VO类 | XxxVO | UserVO |
| 服务接口 | XxxService | UserService |
| 服务实现 | XxxServiceImpl | UserServiceImpl |
| 控制器 | XxxController | UserController |
| 仓库接口 | XxxRepository | UserRepository |
| 配置类 | XxxConfig | DataSourceConfig |
| 工具类 | XxxUtil | StringUtil |
| 异常类 | XxxException | BizException |
| 枚举类 | XxxEnum | StatusEnum |
| 常量类 | XxxConstant | SystemConstant |

### 方法命名规范
| 操作类型 | 模式 | 示例 |
|----------|------|------|
| 查询单个 | getXxxById | getUserById |
| 条件查询 | findXxxByYyy | findUserByName |
| 查询列表 | listXxxs | listUsers |
| 分页查询 | pageXxxs | pageUsers |
| 创建 | createXxx | createUser |
| 更新 | updateXxx | updateUser |
| 删除 | deleteXxx | deleteUser |
| 保存 | saveXxx | saveUser |
| 验证 | validateXxx | validateUser |
| 处理 | processXxx | processOrder |

## 🛠️ **Maven配置最佳实践**

### 父POM配置
```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.bone</groupId>
    <artifactId>bone-parent</artifactId>
    <version>1.0.0-SNAPSHOT</version>
    <packaging>pom</packaging>

    <name>Bone Platform Parent</name>
    <description>Bone Enterprise Development Platform</description>

    <modules>
        <module>bone-core</module>
        <module>bone-engine</module>
        <module>bone-platform</module>
        <module>bone-services</module>
        <module>bone-starters</module>
        <module>bone-sdk</module>
        <module>bone-tools</module>
    </modules>

    <properties>
        <!-- 基础配置 -->
        <java.version>17</java.version>
        <maven.compiler.source>${java.version}</maven.compiler.source>
        <maven.compiler.target>${java.version}</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <maven.compiler.version>3.11.0</maven.compiler.version>
        
        <!-- Bone版本 -->
        <bone.version>1.0.0-SNAPSHOT</bone.version>
        
        <!-- 第三方依赖版本 -->
        <spring-boot.version>3.2.0</spring-boot.version>
        <spring-cloud.version>2023.0.0</spring-cloud.version>
        <mybatis-plus.version>3.5.5</mybatis-plus.version>
        <lombok.version>1.18.30</lombok.version>
    </properties>

    <!-- 依赖管理 -->
    <dependencyManagement>
        <dependencies>
            <!-- Spring Boot BOM -->
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-dependencies</artifactId>
                <version>${spring-boot.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
            
            <!-- Bone内部模块统一版本管理 -->
            <dependency>
                <groupId>com.bone</groupId>
                <artifactId>bone-common</artifactId>
                <version>${bone.version}</version>
            </dependency>
            <dependency>
                <groupId>com.bone</groupId>
                <artifactId>bone-datasource</artifactId>
                <version>${bone.version}</version>
            </dependency>
            <dependency>
                <groupId>com.bone</groupId>
                <artifactId>bone-metadata</artifactId>
                <version>${bone.version}</version>
            </dependency>
        </dependencies>
    </dependencyManagement>

    <!-- 构建配置 -->
    <build>
        <pluginManagement>
            <plugins>
                <!-- 编译器插件 -->
                <plugin>
                    <groupId>org.apache.maven.plugins</groupId>
                    <artifactId>maven-compiler-plugin</artifactId>
                    <version>${maven.compiler.version}</version>
                    <configuration>
                        <source>${java.version}</source>
                        <target>${java.version}</target>
                        <encoding>${project.build.sourceEncoding}</encoding>
                        <parameters>true</parameters>
                    </configuration>
                </plugin>
                
                <!-- Spring Boot插件 -->
                <plugin>
                    <groupId>org.springframework.boot</groupId>
                    <artifactId>spring-boot-maven-plugin</artifactId>
                    <version>${spring-boot.version}</version>
                    <configuration>
                        <excludes>
                            <exclude>
                                <groupId>org.projectlombok</groupId>
                                <artifactId>lombok</artifactId>
                            </exclude>
                        </excludes>
                    </configuration>
                </plugin>
            </plugins>
        </pluginManagement>
    </build>
</project>
```
