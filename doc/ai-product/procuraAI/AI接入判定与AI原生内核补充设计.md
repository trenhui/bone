## 1. AI 接入判定准则

四条**同时满足**才接 AI；任一不满足即回退纯规则 / 工作流 / 状态机：

| # | 判据 | 反例（不满足即不接） |
|---|------|----------------------|
| ① | 输入是自然语言 / 非结构化文档或高维模式，规则无法穷举 | 结构化金额字段、固定枚举状态 |
| ② | 输出是**建议 / 摘要 / 线索 / 草稿**，不是资金、授标或终态结论 | 付款指令、授标决定、`FINALIZED` |
| ③ | 有可构造的 ground truth、可写负向用例、可字段级评测 | 无标注、无通过线的主观判断 |
| ④ | 失败能 fail-closed 到纯规则或人工，**不阻断业务主链路** | AI 不可用即主链路停摆 |

> **条件③应用口径（2026-11-14 业界校准修正）**：四条件本身不变，但「可构造 ground truth」须按**输出形态分类**，不得把「分类 / 抽取 / 异常线索 / 排序摘要 / 偏离预警」与「点预测数值 / 自动生成终态决策」混为一类判 C 档。前者只要存在历史标注或人工复核结论，即可构造 ground truth 并写出字段级负向用例——支出品类 UNSPSC 分类、发票匹配异常、重复付款检测、报价偏离预警均为业界已验证成熟形态（中物联《人工智能+采购供应链应用指南》五（一）（五）（七）（九）；Gartner 2026 targeted use cases 口径），按 B 档「只出线索、裁决归人」接入并单列评测集；**只有纯数值点预测与生成终态结论才落入 C 档不接**。此修正**不放宽 ②/④**：任何分类 / 预警能力仍须 `ADVISORY_ONLY` + fail-closed + 人工终决，不得因「可评测」就跳过建议态与降级判据。

**明确不接 AI**（用确定性规则 / 工作流 / 状态机）：

| 环节 | 替代机制 |
|------|----------|
| 金额与税额计算 | 确定性算术 + Money 类型校验 |
| 状态机迁移 | 迁移表 guard（`总纲 §21.1`「迁移表未列出即拒绝」） |
| 三单匹配裁决 | 规则容差 + 三通道台账 |
| 付款许可 | Finance 防腐层 / 资金状态机 |
| 幂等与对账 | 幂等键 + 确定性重放 |
| 授标 / 准入定性 | 人工终决 + 三方会签 |
| 围串标违法定性 | 监管侧职责，企业侧只出线索（G12） |

> **「AI 不碰钱」是本族合规基线**：与 `采购AI-接口契约与数据字典-v2.md §3`「AI 仅辅助 / 人工最终决策 / 自动结案：禁止」、`采购领域架构设计方案.md §2.1` Finance 裁决边界一致。旧 ADR-06「低风险自动归档」**已撤销、禁止复活**（`文档资产登记与真源裁决.md §5`），本文件任何条款不得把它作为有效决策。

### 1.1 四条件与现行真源的对应

| 条件 | 真源锚点 | 不满足时的处置 |
|------|----------|----------------|
| ① 非结构化输入 | `D3-v2 §1.1` 八码均为文档 / 文本 / 信号输入 | 落 `detailed-design/04-采购交易与成本模块详细设计.md` 确定性规则 |

### 2.4 业界校准（决定 B/C 不铺开）

- Gartner 2026-05 供应链专场：**「agentic AI in procurement is still nascent」**、近期机会是 **targeted sourcing and procurement use cases**、须 **guard against agent-washing**。
- Gartner 2026-05-26 新闻稿：**到 2027 年 40% 企业将因治理缺口降级 / 退役自治代理**。
