## 交互原型与演示页面索引

`prototypes/` 是 synapClaim **交互原型（设计稿 / DEMO）**的唯一入口。2026-11-21 按"角色旅程 × 能力域"重整为 **9 页工作台**，过时单文件大 Demo 已删除（其独特能力已升级进新版），下表同时登记"看起来像 DEMO 但不是交互原型"的邻近资产。

### 交互原型（`prototypes/claim-workbench/`，当前唯一版本）

| 分组 | 页面 | 回答什么问题 |
|---|---|---|
| **客户自助** | `customer-journey.html` | 客户在小程序如何报案 → 看 AI 预填 → 查进度 → 读结果 → 申诉 |
| **作业处理** | `claim-manage.html` | 赔案列表、状态/任务视图、七节点作业链、批量拒赔二次确认 |
| | `claim-detail.html` | 单案审核详情、五环节表单视图、责任额度快照、**决策回放（证据链）** |
| | `claim-image-detail.html` | 影像分类、清晰度、票据关联与逐张审阅 |
| **配置治理** | `claim-rule-config.html` | 三层责任矩阵、因子笛卡尔积、语法引导公式、责任编辑分区校验 |
| | `job-config.html` | 平台标准 vs 主体专属继承、显式同步/发布声明 |
| | `form-config.html` | 表单模板 / 设计画布 / 字段属性三栏、发布生成新版本但默认不启用 |
| **数据质量** | `import-record.html` | 批次进度、逐行错误抽屉、定位源行与下载报告 |
| **评测审计** | `evaluation-report.html` | 第 3 幕评测报告样式：指标目标线与现场生成分列、评测集口径、审计日志一键回放 |

**形态约束**：单文件 HTML（内联 CSS/JS）、零 CDN、浏览器直开；九页顶部互跳 + `Ctrl/⌘+K` 命令面板 + 操作指引抽屉；页脚统一标"演示数据已脱敏 · 非真实客户信息"。数据基于测试环境 schema 与脱敏赔案结构还原。

### DEMO ↔ 实现对齐（签约演示口径真源）

9 页原型与实现（bone-frontend/apps/bone-claim-app，22 路由）不是一一对应。下表是**唯一映射**，新增页面或路由必须同批更新，并由 `tools/_check_demo_parity.py` 机检。

| DEMO 页 | 实现落点 | 对齐状态 |
|---|---|---|
| `customer-journey.html` | `/submit` + `/progress`（员工端视角；DEMO 为客户小程序视角） | 视角差异，仅演示客户旅程 |
| `claim-manage.html` | `/workbench` | 对齐 |
| `claim-detail.html` | `/case` + `/review` | 对齐 |
| `claim-image-detail.html` | `/evidence` | 对齐：OCR + 三栏作业台（分类树/关联发票/快捷键）+ 清晰度三态批量标注（后端 `POST /evidences/clarity` + DDL 0133）+ 决策证据锚点页码均已在；仅原型专属的"分类规则浮层"未迁移 |
| `claim-rule-config.html` | `/liability` + 后端规则集 | 部分对齐：矩阵是方案设计，非现网配置面 |
| `job-config.html` | 无现网路由 | 独立配置治理原型 |
| `form-config.html` | 无现网路由 | 独立配置治理原型 |
| `import-record.html` | 无现网路由 | 独立数据质量原型 |
| `evaluation-report.html` | `/ai-governance`（能力相关，非同页） | 报告样式稿；指标不在原型中预置实测值 |

**POC 三案例锚点**（对应 `07-delivery/03-POC演示脚本.md` §三）：

| 案例 | DEMO 落点 | 关键口径 |
|---|---|---|
| A 自动通过 | `customer-journey.html` 结果屏 / `claim-detail.html` 决策回放 | 30 秒为建议结论；到账时效随支付通道确定，不承诺到账时间 |
| B 建议拒赔 + 人工确认 | `claim-detail.html`「建议拒赔」→ 结构化拒赔通知书 | 事实认定 / 条款依据 / 证据位置 / 申诉渠道与时限；核赔员一键确认后生效 |
| C 风险标记转人工 | `claim-manage.html` 置顶风险待办 → 上下文弹窗 | 同日同院同额命中风险规则；人工终审不替代，带证据与决策轨迹移交 |
| 第 3 幕 评测与审计 | `evaluation-report.html` | 目标线与"现场生成"分列，不预置实测值；任意案件可回放到决策链 |

**状态口径**：DEMO 用业务聚合态（待审核 / 审核中 / 待推送 / 已结案 / 挂起 / 推送失败），实现用 14 态枚举（DRAFT … APPEALING，真源 `claimStatus.ts`）。两者不在同一层：DEMO 面向客户演示，实现面向状态机。禁止照抄 DEMO 中文文案到代码，也禁止把英文枚举搬进 DEMO。
