# 09 培训与用户手册

> 用途：Phase B（辅助模式）上线前，让核赔员"会用、敢用"AI 建议；同时给运营/管理员操作指引。**人责归属是培训第一课**：AI 是助手，终审是人工/保司。

## 二、核赔工作台操作手册

### 2.1 待办任务（首页）

- 案件按风险优先级排序：高风险/低置信/大额置顶，普通案件排后
- 字段：案件号、员工（脱敏）、金额、AI 建议类型（建议通过/建议拒赔/建议补件）、置信度、风险标签
- 操作：点开案件进入审核页

### 2.2 案件审核页（四个区域）

|**区域**|**内容**|**作用**|
|---|---|---|
|原始材料|发票/清单/病历影像（加密展示）|核赔员独立判断的第一依据|
|AI 提取字段|结构化字段 + 置信度 + 证据位置高亮|快速核对，低置信字段黄色高亮提醒|
|规则与计算过程|命中的每条规则 + 理算公式分步展示（免赔/比例/封顶）|**金额计算可逐项核对**（AI 不碰钱）|
|决策轨迹|决策图节点执行路径（可缩放）|回答"为什么这么判"|

### 2.3 审核操作（三类）

|**操作**|**适用**|**要求**|
|---|---|---|
|通过（APPROVED）|材料齐全、责任明确、金额无误|大额 ≥1 万需双人复核（第二人提交后生效）|
|拒赔（REJECTED）|不属责任范围/目录外/材料造假|必填结构化五要素（事实认定+条款依据+证据位置+申诉渠道+法定时限；「≥3 条理由」口径已废止）|
|补件（REQUEST_MORE_EVIDENCE）|材料缺失/模糊|自动生成缺件清单，通知员工补充|

**纪律**：
- AI 建议 ≠ 结论：核赔员可采纳、可否决；否决时留备注（差异入审计，用于模型改进）
- 拿不准的案件走"转专家/升级"路径，不硬判
- 操作全程留痕（谁/何时/何决定/何理由）

## 三、AI 人责归属说明（培训第一课，必须讲透）

1. **系统定位**：AI 只提供审核建议与证据，不替代核赔员终审；终审责任在核赔员/保司
2. **什么时候信 AI**：置信度高 + 无风险标记 + 金额小 → 可快速采纳（快赔路径自动通过仅限 ≤500 元低风险）
3. **什么时候必须人工**：金额 ≥1 万、风险标记、AI 置信度三档：<0.7 强制人工终审 / 0.7-0.85 进人工复核 / ≥0.85 且无风险直出（OCR 字段置信度 <0.7 另行走补件/人工校对）、规则冲突、客户申诉
4. **拒赔责任**：AI 拒赔建议必须有条款依据；核赔员确认后由保司名义发出；客户申诉走复议流程（48h 响应）
5. **审计**：所有决策可回放；"AI 出错"不是免责理由，核赔员有核验义务（按手册 2.2 四区域核对）

## 四、常见操作 FAQ

|**问题**|**回答**|
|---|---|
|"AI 建议通过，但我看到发票金额不对怎么办？"|人工否决，修改金额或转补件；系统记录差异（这正是评测改进的数据来源）|
|"为什么这个案件自动支付了？"|金额 ≤500 + 材料完整 + 无风险 + 责任明确四条件全满足走快赔路径；如你发现漏判，走后督申诉流程，案件可冲正|
|"客户申诉怎么办？"|案件进入申诉处理环节（**对客展示仍为“审核中”**，不新增对客状态），48h 内人工复议；复议结论与理由留痕（见 PRD §8.5）|
|"批量通过怎么用？"|仅限低风险案件批量（单次 ≤100 件）；批量前系统强制展示风险提示|
|"怎么看自动化率？"|运营配置台 → 自动化率看板（整体/分保司/分案件类型）|
|"数据保留多久？"|资金/决策日志 7 年，普通操作 180 天；案件数据按合同约定（试点终止删除）|
