## 二、评测集与标注规范（测试可信度保障）

1. **样本量**：MVP 基准集 ≥300 条（覆盖 §四规则书第十节的边界样本要求）
2. **标注规范**：双人独立标注 + 不一致讨论裁决；标注指南（含典型误判案例）成文
3. **标注一致性**：抽 10% 双人复标，一致性 ≥95%（Cohen's Kappa ≥0.85）
4. **测试集/训练集分离**：评估只用测试集；失败案例回收用于规则修正（不入测试集，防过拟合）
5. **报告口径**：每次评测输出五指标报告（字段/规则/复核率/时长/错误率）+ 失败案例回放（区分模型层 vs 规则层 vs 接口层问题）> **错误率统计注**：“重大错误率 0”指 ≥300 条基准集上的测量结果，非总体风险承诺；生产期以后督抽检 ≥5% + 冲正兜底计口径。

## 三、性能基准（指标口径 + 待实测项）

### 3.1 指标定义

|**指标**|**定义**|**目标**|**口径**|
|---|---|---|---|
|建议结论返回 P95|提交→决策结论返回|≤30s（P95）|不含人工环节；含 OCR+规则+理算（AI 可选）|
|自动通过全链路 P95|提交→支付成功（自动通过路径）|≤60s（P95）|不含人工环节；与上行口径不同，二者不可互引|
|接口 P99 延迟|工作台操作接口|≤2 秒|审核操作响应|
|并发处理能力|同时处理案件数|≥50 并发，0 失败|TPS 实测|
|资金操作一致性|两段式状态机并发扣减|0 差错|@Version 乐观锁冲突重试 + 唯一约束 + 条件更新（业务层禁 SELECT FOR UPDATE，AGENTS.md §7 / ADR-0031）|
|可用性|月度 SLA|99.9%（工程门禁档；对外承诺 99.99% 须同城双活，工程落地版 §11.8）|监控统计；口径卡见落地版 §11.2|

> **口径纪律**：30s 与 60s 为两个独立口径，不可互引——30s = 提交→决策结论返回（建议结论），60s = 自动通过路径全链路（提交→支付成功）（工程落地版 §11.2 / PRD §13.1）。
>
> **指标真源**：本表阈值与 PRD §15、工程落地版 §11.2（SLO 口径卡 + 容量阈值表）同源；**自动化率/生产口径人工复核率锚定 Phase C 验收**（Phase A 只读旁路物理上产不出该指标，见 PRD §15 / MOU 附件 B）。

## 四、安全测试要点（金融敏感）

- 越权：跨租户读取（TenantId 隔离）、水平越权（他人案件）——强制用例
- 注入：SQL/NoSQL/命令注入——规则引擎输入面
- 敏感数据：接口响应是否泄露明文身份证/病历（脱敏检查）；日志是否打印敏感字段
- 传输与存储：TLS、AES-256 静态加密验证
- 模型接口：LLM 输出注入（prompt injection 样本 10 条）

## 五、发布门禁（CI 集成，借鉴 Bone 门禁）

```plaintext
静态检查(0违规) → 单元测试(0失败) → 契约(端口)消费者驱动测试 CDC(契约不破) → 评测回归(五指标不下降)
→ 安全扫描(高危0) → 性能冒烟(关键场景) → Shadow 比价门禁(差异率 ≤0.5%) → 发布
```

> **发布卡点**：任一门禁未绿，系统仅允许 Shadow 态，不得进入 Assisted/Automated 对客出结论（工程落地版 §11.11）。

**不 freeze 原则**：门禁全部自动化，任何提交必须过门禁，不靠"冻结版本"保质量。
