# 06 医学目录库建设方案

> 用途：回答"自费剔除、合理用药、责任判断"依赖的目录数据**从哪来、怎么授权、怎么维护**。目录库是规则引擎（R-DIR 系列）与医学知识图谱（工程落地版 §4 领域模型，原设计方案的对应章节已并入）的数据底座。
>
> **V1.0 优化（2026-10-26 业界对标）**：原设计将"医学知识图谱/临床合理性"置于 V2，对标普康宝（内置医保三大目录+ICD-10+全国医疗机构库）与平安/泰康/众安的目录驱动理算，现将**目录底座 + 临床合理性审核升格为 V1.0 必建项**（见 Rulebook R-DIR-06），并作为反欺诈体系（R-FRAUD-08~11）的医学事实底座。理由：门诊小额渗漏主因是搭车收费、过度医疗、诊断-用药不匹配，无目录则理算只能判"责任内按比例"，无法判"该不该赔"。

---

## 一、目录库组成（四类）

|**目录**|**内容**|**MVP 必须**|**数据来源建议**|**授权性质**|
|---|---|---|---|---|
|疾病编码库（ICD-10）|疾病分类编码+名称+中文别名|✓（核责用）|卫健委发布的 ICD-10 中文版（公开）|公开数据，可自由使用|
|药品目录库|国家医保目录（甲/乙类）药品：编码/名称/剂型/甲乙类/限定支付|✓（自费剔除+理算）|国家医保局历年发布的药品目录（公开文件）|公开文件，需自建结构化|
|诊疗项目目录|医保诊疗项目：名称/类别/医保支付标记|✓（R-DIR-02）|各地医保目录（公开）+客户保单口径|公开+客户补充|
|耗材目录|医保支付范围内耗材|△（MVP 可简化）|医保耗材目录（公开）|公开文件，自建结构化|

## 二、数据来源与授权合规

|**数据源**|**获取方式**|**合规要点**|
|---|---|---|
|ICD-10 中文版|卫健委官网公开下载|公开数据，标注版本（如 ICD-10 2019 版）|
|国家医保药品目录|国家医保局官网 PDF 发布|公开文件；自建结构化表格需标注"目录年份+版本"，不主张版权|
|客户保单条款口径|客户业务专家提供（授权）|**客户口径优先**：医保目录是"最低保障口径"，企业补充医疗常扩展目录（如商保目录），以客户条款为准|
|药品/诊疗别名库|专家标注+公开百科交叉验证|人工审核后入库，标注置信来源|

## 三、目录结构规范（入库字段）

**药品目录条目示例**：
```json
{
  "drug_code": "X000123",
  "drug_name": "阿莫西林胶囊",
  "spec": "0.25g*24",
  "category": "医保甲类",          // 甲类/乙类/目录外
  "limited_payment": "限二级及以上医院",  // 限定支付条件
  "source": "国家医保目录2025版",
  "version": "2025",
  "effective_date": "2026-01-01",
  "expire_date": null,
  "review_status": "APPROVED"      // DRAFT/APPROVED/EXPIRED
}
```

**关键设计**：
1. 每条目录带 `version + effective_date`，支持版本切换（年度目录调整）；规则引擎取"生效中版本"
2. 目录外自动标记为"自费"，无需穷举目录外内容（默认不在目录=自费）
3. 药品别名/常见名映射表（如"阿莫西林"→"阿莫西林胶囊"），由业务专家维护，用于 OCR/LLM 提取后的标准名归一

## 四、更新与维护机制

|**周期**|**动作**|**责任人**|
|---|---|---|
|年度（医保目录发布后）|新版本导入 → 差异对比（新增/剔除/限定变化）→ 业务评审 → 发布|理赔负责人+业务专家|
|季度|别名库补充、常见错误归一修正（从评测集失败案例回收）|理赔负责人|
|实时（客户保单）|客户新增险种/扩展目录 → 按客户配置新增目录条目|运营配置（保司配置）|
|每次更新后|**全量评测集回归**（自费剔除、理算准确率不得下降）|理赔负责人|

## 五、目录库与系统的集成

```plaintext
目录数据（ICD/药品/诊疗/耗材，多版本）
    ↓ 导入工具（Excel/JSON → 校验 → 入库）
TiDB 目录表（带版本+生效期）
    ↓
规则引擎查询（R-DIR-01~05：目录内/外判定、限定支付条件）
    ↓
医学知识图谱（诊断-用药-诊疗映射，V1.0 先做最小集：Top100 门诊疾病 × 常用药）
```

## 六、MVP 最小集（先跑通，再扩展）

- 药品：Top 200 门诊常用药（感冒/呼吸道/肠胃/皮肤/慢病常用）+ 国家医保目录自费标记
- 疾病：Top 100 门诊 ICD-10 编码（含中文别名）
- 诊疗：门诊常见诊疗项目 50 项
- 医院等级映射：保司口径（一级/二级/三级）→ 责任范围判定（R-AREA-01）

## 七、V1.0 优化：临床合理性与反欺诈数据底座

> 目录库不只是"自费剔除"的查表源，更是 V1.0 反欺诈与临床合理性的事实底座。本节能直接落地为 Rulebook R-DIR-06 与 R-FRAUD-08~11 的数据支撑。

### 7.1 临床合理性最小知识图谱（R-DIR-06 数据源）

- **诊断-用药适应症映射**：Top100 门诊疾病 ICD-10 × 常用药，标注"适应症/禁忌/常见联用"，用于 R-DIR-06① 适应症矛盾标记。
- **用药剂量/频次常识库**：按药品说明书常规剂量区间，用于 R-DIR-06② 超量标记（超出区间转人工，非自动拒赔）。
- **诊断-诊疗项目关联**：诊断与可报销诊疗项目的合理对应，用于 R-DIR-06④ 搭车收费识别。
- 维护：从评测集失败案例 + 业务专家标注回收，季度扩充。

### 7.2 反欺诈数据底座（R-FRAUD-08~11 数据源）

|**反欺诈规则**|**依赖的目录/图谱数据**|**说明**|
|---|---|---|
|R-FRAUD-08 影像相似度|影像指纹库（pHash + 特征向量，按 tenant 隔离）|跨案件重复/PS/翻拍检测；国寿"识图"已实证百万级重复索赔识别|
|R-FRAUD-09 关系图谱|人-案件-机构-设备-代理人-受益人节点 + 边（同院/同设备/同账户/同地址）|图计算社区发现识别团伙；太保/泰康/众安已落地|
|R-FRAUD-10 知识图谱一致性|复用 §7.1 临床合理性图谱 + 时间轴|诊断-用药-诊疗-时间矛盾推理|
|R-FRAUD-11 跨案件关联|被保险人/证件/手机/收款账户/地址关联索引|化整为零、一人多赔识别|

### 7.3 V1.0 目录库最小集（在原 §六 基础上补强制项）

- 在原 Top200 药品 / Top100 ICD-10 / 50 诊疗项目基础上，**强制纳入"全国医疗机构库"（医院等级/属性/定点标识）**——既是 R-AREA-01 责任范围判定源，也是 R-FRAUD-09 机构节点源（对标普康宝全国医疗机构库）。
- 新增"诊断-用药适应症映射表"与"用药剂量常识表"（§7.1），作为 R-DIR-06 必建项，MVP 即随目录库一并导入。

## 八、风险与依赖

|**风险**|**对策**|
|---|---|
|医保目录版本变化影响赔付口径|版本化管理+客户保单口径优先；目录变化需业务评审后发布|
|目录数据不全导致误判自费|目录外=自费的默认逻辑 + 标记"疑似目录外"转人工复核（保守策略）|
|别名归一错误|别名映射人工审核；评测集覆盖常见药品名变体|
|客户扩展目录未及时维护|保司配置流程绑定目录更新检查（新增险种必查目录）|

> **诚实声明**：目录库是持续维护资产（壁垒层第 2 层"规则资产"的一部分），MVP 先以公开数据+客户口径建最小集，随试点数据逐步扩充。
