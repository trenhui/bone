# synapClaim 智能理赔平台

## 落地交付包清单

版本 V1.0 ｜ 2026-10-12 ｜ Synap（思纳普）出品

---

## 一、交付包定位

本交付包是 synapClaim 智能理赔平台与贵司（保司 / TPA）开展试点合作的完整材料集，覆盖从**协议签署、数据安全、系统接入、业务验证**到**规模化商务**的全过程。

交付包以「可量化、可审计、可回退」为原则：

- **可量化**：每个环节都有明确的指标口径与验收标准，不空谈效果
- **可审计**：每笔审核决策可回放（证据 → 解析 → 核责 → 理算 → 决策）
- **可回退**：试点全程旁路运行，不改变贵司现有理赔流程，随时可关停

## 四、服务承诺（量化口径）

|**指标**|**承诺口径**|**说明**|
|---|---|---|
|单案处理成本|下降 ≥50%|以贵司当前人工处理基线对比|
|审核建议时效|95% 请求 ≤30 秒返回|自动路径（材料解析 + 规则核责 + 理算）|
|字段提取准确率|≥95%|评测集对照人工标注，口径可审计|
|规则匹配准确率|≥90%|规则结果对照人工核责结论|
|人工复核率|≤30%|需人工介入案件占比（Phase C 放量后生产口径；Shadow/辅助阶段报评测集口径，PRD §15）|
|重大错误率|0 容忍|错赔 / 漏赔案件全部转人工兜底|
|试点接入|4-6 周旁路运行|只读接入，不改变现有流程，可随时回退|

> 以上指标均以授权脱敏样本评测集为测量基准，评测方法与样本口径随交付物 04/07 提供，贵司可复核。

## 五、合规与数据安全承诺

1. **数据分级脱敏**：敏感个人信息（病历、身份信息）默认不出域，处理遵循 PIPL 要求
2. **协议保障**：MOU / NDA / DPA 三份契约覆盖数据授权、用途限制、留存与删除义务
3. **审计能力**：每笔决策全程留痕（输入摘要、模型输出、动作结果），资金 / 决策日志保留 ≥7 年
4. **人责归属**：系统输出为辅助建议，最终审核结论由贵司核赔员 / 保司负责；重大错误率 0 容忍
5. **应急响应**：数据安全事件 24 小时内书面通知，附取证、整改与复盘流程
