# 04 业务规则书（Rulebook）—— 门诊小额快赔 MVP 全集

> 用途：把"示例口径"升级为**可开发、可配置、可评测的规则全集**。本规则书是理算引擎、评测集、保司配置三者的共同输入；客户现场可逐条核对。**规则版本号 R1.0（MVP 一期）**
>
> **契约地位**：本规则书为 MVP **规则真源**（规则 ID 如 `R-MAN-01` / `R-FRAUD-*`），被《synapClaim 智能理赔平台-工程详细设计（落地版）》§8.2 / §10.6 引用对齐；规则变更须经业务评审 + 评测集回归方可发布。
>
> **版本修订（2026-10-26 业界对标优化）**：在 R1.0 基础上，将反欺诈由 7 条规则升级为 11 条（新增 R-FRAUD-08~11：影像相似度、关系图谱+设备指纹、知识图谱一致性、跨案件关联），R-FRAUD-05 由 V2 单维标记升格为 V1.0 图计算团伙识别；目录规则新增 R-DIR-06 诊断-用药-诊疗合理性（原 V2 临床知识图谱前置）。依据：平安财险 13 模型+208 规则、太保/泰康关系图谱团伙识别、国寿"识图"影像相似度、众安图像+关系图谱联合反诈。

---

## 一、规则管理规范

|**项**|**约定**|
|---|---|
|版本管理|每条规则含 version、effective_date、expire_date；生效规则唯一|
|变更流程|规则变更 → 业务评审（理赔负责人+客户业务专家）→ 审批 → 入评测集回归 → 发布（30 秒热生效）|
|冲突裁决|多规则命中冲突时按"优先级裁决表"（见 §七）；裁决过程留痕显示|
|评测联动|每次规则变更跑一次基准测试集回归（字段/规则/复核率不下降才可发布）|

## 二、责任范围规则（R-AREA）

|**规则ID**|**规则内容**|**默认值/口径**|**可配置**|
|---|---|---|---|
|R-AREA-01|就诊机构范围|二级及以上公立医院（含社区医院定点）|是|
|R-AREA-02|就诊类型范围|门诊（含急诊留观）；不包含住院、体检、美容|是|
|R-AREA-03|责任期间|保单生效后、等待期结束后发生的费用；等待期 30 天（企业补充医疗常见）|是|
|R-AREA-04|被保险人范围|在职员工本人（不含家属，可选扩展）|是|
|R-AREA-05|既往症|等待期前已确诊的慢性病相关费用可除外（按保单条款）|是|

## 三、目录与自费剔除规则（R-DIR）

|**规则ID**|**规则内容**|**默认值/口径**|**依赖目录**|
|---|---|---|---|
|R-DIR-01|药品目录范围|国家医保目录内（甲类/乙类）药品|医保目录库|
|R-DIR-02|诊疗项目范围|医保诊疗项目目录内|诊疗目录库|
|R-DIR-03|耗材范围|医保支付范围内耗材|耗材目录库|
|R-DIR-04|自费剔除|自费药品、保健品、营养品、美容整形、牙科美容不赔付|目录外自动剔除|
|R-DIR-05|单次处方限额|单次就诊药品数量超 5 种或金额超 300 元 → 标记人工核验（防"一单多药"套赔）|—|
|R-DIR-06|诊断-用药-诊疗合理性（**V1.0 升格，原 V2 临床知识图谱前置**）|依据医学目录底座（ICD-10 + 药品/诊疗目录 + 最小临床知识图谱）校验：① 诊断编码与所开药品/诊疗项目不存在适应症矛盾（如感冒诊断开抗生素→标记）；② 用药剂量/频次超出说明书常规范围→标记；③ 诊断日期晚于用药日期或就诊日期矛盾→标记（与 R-FRAUD-03 时间轴交叉）；④ 搭车收费：诊断/主诉与收费项目明显无关→标记人工核验。命中不自动拒赔，进入人工复核档并附证据|医学目录底座 + 最小临床知识图谱（Top100 门诊疾病 × 常用药，见 07-delivery/06 §五）|

## 四、免赔额规则（R-DED）

|**规则ID**|**规则内容**|**默认值/口径**|**可配置**|
|---|---|---|---|
|R-DED-01|免赔方式|年累计免赔（按保单年度滚动），非单次免赔|是|
|R-DED-02|免赔额|300 元/年/人（社保内费用累计达 300 元后开始赔付）|是（按保司）|
|R-DED-03|免赔计算口径|以“社保范围内个人自付部分”累计计入免赔（**数据源=医保结算单/票据三段拆分：统筹支付/个人自付/个人自费**，见 MVP In Scope 医保字段解析）|是（按保司）|
|R-DED-04|多案件共享|同一保单年度内多起案件共享免赔累计（状态：年度已用免赔额）|是|

## 五、赔付比例规则（R-RAT）

|**规则ID**|**规则内容**|**默认值/口径**|**可配置**|
|---|---|---|---|
|R-RAT-01|基础赔付比例|社保范围内费用 90%（数据源同 R-DED-03 三段拆分；**未经社保结算者按保单条款降比例**，须显式配置）|是|
|R-RAT-02|社区医院上浮|一级/社区医院就诊比例上浮至 95%（引导基层医疗，可选）|是|
|R-RAT-03|目录外比例|目录外费用 0%（不赔付）|是|
|R-RAT-04|金额取整|赔付金额按分计算，四舍五入到分|固定|

## 六、封顶线规则（R-CAP）

|**规则ID**|**规则内容**|**默认值/口径**|**可配置**|

## 七、决策路径规则（R-DEC，冲突裁决优先级）

|**优先级**|**规则ID**|**规则内容**|
|---|---|---|
|P0（最高）|R-FRAUD-*|风险标记命中（重复报销/时间轴矛盾/金额异常）→ 一律转人工，不自动通过|
|P1|R-CAP-02|已达封顶 → 不再自动赔付|
|P2|R-DIR-04|自费剔除 → 剔除项不赔，其余继续理算|
|P3|R-AREA-*|责任范围不符 → 拒赔（带条款依据）|
|P4|R-DED/R-RAT|免赔/比例正常理算|
|P5（最低）|—|材料缺失/模糊 → 补件，不阻塞其他案件|

## 八、快赔路径与人工兜底规则（R-FAST / R-MAN）

|**规则ID**|**规则内容**|**默认值/口径**|
|---|---|---|
|R-FAST-01|快赔自动通过条件（四条件全满足）|① 理算金额 ≤500 元 ② 材料完整无缺失（含发票票面查验通过，见 R-FRAUD-06）③ 无风险标记 ④ 责任范围明确无争议|
|R-FAST-02|快赔支付|自动走两段式资金状态机 → 支付（资金幂等键=`{claimNo}:{stage}:{attempt}`（`attempt` 为占额周期序号，工程落地版 §7.5），见工程落地版 §7.5）|
|R-MAN-01|强制转人工|金额 ≥1 万元（双人复核）；风险标记命中；**AI 决策置信度三档：<0.7 强制人工终审 / 0.7-0.85 进复核档 / ≥0.85 且无风险直出**；OCR 置信度 <0.7（独立字段，契约 ocr_confidence）；规则冲突无法裁决|
|R-MAN-02|人工复核时限|48 小时内响应（转人工案件 SLA）|
|R-MAN-03|拒赔必答|结构化拒赔通知书：**事实认定 + 条款依据 + 证据位置 + 申诉渠道 + 法定时限**（《保险法》第24条：核定后 3 日内书面通知并说明理由；“≥3 条理由”非法定要求，废止）|
|R-MAN-04|申诉复议|案件进入**内部状态码 `60`（申诉中）**，**对外仍投影 `REVIEWING`**（不新增对外枚举值，契约见 05“对外仅 `PENDING_EVIDENCE`/`REVIEWING`”）；48h 响应；复议结果留痕（PRD §8.5）|

## 九、风控标记规则（R-FRAUD）

|**规则ID**|**规则内容**|**触发条件示例**|
|---|---|---|
|R-FRAUD-01|重复报销检测|同人同日同院同额（假名化关联）|
|R-FRAUD-02|金额异常检测|单案金额超同类案件 3σ 或超保额 80%|
|R-FRAUD-03|时间轴矛盾|用药日期早于就诊日期/诊断日期晚于就诊日期等|
|R-FRAUD-04|材料一致性|发票金额与清单合计不一致（差额 >1 元）|
|R-FRAUD-05|团伙关联（**V1.0 升格，由单维标记升级为图计算**）|同医院/同科室/同代理人/同设备多人同类高额案件聚集，多维权关联（就诊时间聚集、金额聚集、材料相似度、关系图谱邻接度）；输出团伙风险分（0–1）与关联案件清单，供 R-FRAUD-09 图计算复核|关系图谱 + 设备指纹（V1.0 启用，详见 R-FRAUD-09）|
|R-FRAUD-06|票据验真（票面查验）|发票代码/号码/金额等票面要素核验（税局/电子票据平台通道，通道接入前按“查验不通过或无法查验一律转人工”从严处置）；查验不通过禁止进入自动通过路径|
|R-FRAUD-07|发票唯一性（硬约束）|同一发票在同一租户内只允许一笔赔案；由数据库唯一约束 uk(tenant_id, invoice_code, invoice_no) 强制（规则判定为辅），命中返回 409 且不回传已存在案件引用（防枚举）|
|R-FRAUD-08|影像相似度检索（**V1.0 新增，对标国寿"识图"**）|对上传发票/清单/病历影像提取感知哈希（pHash/aHash）+ 关键区域特征向量，跨租户历史案件库检索 Top-K 相似影像；相似度 ≥阈值（如 ≥0.92）且非同一案件 → 标记"疑似重复报案/PS 翻拍"，转人工并附相似源案件；支持同一张发票被不同人/不同案复用检测|影像指纹库（按 tenant_id 隔离）+ 向量检索（TiDB Vector / Milvus）|
|R-FRAUD-09|关系图谱 + 设备指纹团伙识别（**V1.0 新增，对标太保/泰康/众安**）|构建"人-案件-机构-设备-代理人-受益人"关系图谱，基于图计算（社区发现/PageRank/子图同构）识别团伙网络；设备指纹（上传终端特征、IP、账号设备绑定）识别同设备多账号、设备聚集；与 R-FRAUD-05 多维权融合输出团伙风险分；命中高置信团伙 → P0 强制转人工并进入风控专项|图数据库（如 NebulaGraph/TuGraph，轻量可用 Neo4j 或 TiDB 图计算）+ 设备指纹服务|
|R-FRAUD-10|知识图谱一致性推理（**V1.0 新增**）|基于医学目录底座 + 理赔知识图谱，推理"诊断-用药-诊疗-时间轴"内部矛盾（如诊断与用药无适应症关联、诊疗项目与诊断不匹配、时间轴倒置）；与 R-DIR-06 临床合理性互补（R-DIR-06 做确定性规则标记，本规则做图谱推理增强）|医学目录底座 + 理赔知识图谱（V1.0 最小集）|
|R-FRAUD-11|跨案件关联网络（**V1.0 新增**）|同被保险人/同证件/同手机号/同收款账户/同邮寄地址的多案件关联分析，识别"化整为零"（单案均 ≤阈值但聚合超保额）、"一人多投多赔"、收款账户聚集；输出关联案件簇与风险标签|案件关联索引 + 关系图谱（复用 R-FRAUD-09 底座）|

## 十、评测集联动清单（每条规则至少 3 条评测样本）

|**规则类别**|**覆盖样本要求**|
|---|---|
|责任范围|超范围医院/超范围诊疗/等待期内 各 ≥3 条|
|目录自费|目录外药品/保健品/超处方限额/诊断-用药不合理（R-DIR-06） 各 ≥3 条|
|免赔比例|免赔累计中/跨案件共享/社区上浮 各 ≥3 条|
|封顶|未达/已达/重置 各 ≥3 条|
|风险标记|R-FRAUD-01~11 每类 ≥3 条（正/反例成对，与 §十 每规则 ≥3 统一）；其中 R-FRAUD-08/09/10/11 须含：① 跨案件影像重复/PS 正例、② 团伙子图正例、③ 诊断-用药矛盾正例、④ 化整为零聚合超保额正例，每类配反例|
|边界|金额恰为 500/10000 临界、AI 置信度恰为 0.7 与 0.85 临界、OCR 置信度恰为 0.7 临界|

> **说明**：本规则书为 MVP 一期口径（R1.0），随客户保单条款差异可配置调整；正式开发前须与客户业务专家逐条评审确认（评审输出为 R1.0 定稿 + 变更清单）。
