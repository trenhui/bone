## 三、交叉引用约定（防漂移）

- 引用其他文档须用 **`《文档名》 §X（标题）`** 稳定形式；禁止用产品名简写代指章节（如裸 `synapClaim §X`）。
- 领域模型 / 聚合 → 引《工程落地版》§4（设计方案的对应章节已并入，不再单列）；**契约细节（规则 ID / 对外枚举 / MVP 端点）引 `delivery/04-05`（真源）**；DDL / 全量 OpenAPI / 非功能 / 时序 → 引《工程落地版》§9 / §10 / §11；需求 → 引 PRD。
- 已建跨文档引用校验 **`_check_xref.py`**：CI / 提交前运行，报告未解析的 § 引用与裸 `synapClaim §` 引用。
