一、交付包定位

本交付包是 synapClaim 智能理赔平台与贵司（保司 / TPA）开展试点合作的完整材料集，覆盖从协议签署、数据安全、系统接入、业务验证到规模化商务的全过程。

交付包以「可量化、可审计、可回退」为原则：

  • 可量化：每个环节都有明确的指标口径与验收标准，不空谈效果
  • 可审计：每笔审核决策可回放（证据 → 解析 → 核责 → 理算 → 决策）
  • 可回退：试点全程旁路运行，不改变贵司现有理赔流程，随时可关停

五、合规与数据安全承诺

  1. 数据分级脱敏：敏感个人信息（病历、身份信息）默认不出域，处理遵循 PIPL 要求
  2. 协议保障：MOU / NDA / DPA 三份契约覆盖数据授权、用途限制、留存与删除义务
  3. 审计能力：每笔决策全程留痕（输入摘要、模型输出、动作结果），资金 / 决策日志保留 ≥7 年
  4. 人责归属：系统输出为辅助建议，最终审核结论由贵司核赔员 / 保司负责；重大错误率 0 容忍
  5. 应急响应：数据安全事件 24 小时内书面通知，附取证、整改与复盘流程
