## 三条阅读纪律

1. **先看真源声明**。每份文档头部都标了"我是哪块内容的真源、权威边界在哪"。冲突时以真源为准，不要跨文档拼口径。
2. **过程记录不等于当前设计**。`reviews/` 里的诊断与整改是**某时点的取证与台账**，结论已回写到设计层；需要"现在是什么样"请读 design/ 与 SSOT。
3. **新增内容优先回写章节，而不是新建文档**。见《文档地图》§三治理规则——这条规则的由来，是本目录曾在 7 天内从 13 份涨到 45 份。
