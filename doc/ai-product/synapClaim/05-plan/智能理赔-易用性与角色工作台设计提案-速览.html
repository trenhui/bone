一、现状诊断（2026-11-12 主工作树实测）

每条结论都带代码定位，完整证据见方案第一章与附录。

D1

菜单平铺、无角色差异

15 条一级叶子挂同一目录，仅用 3 个读权限码；/menus/current 只判 scopes.contains(permission)，全员同一套。

D2

按流程环节而非「角色＋对象」

菜单顺序自述＝作业链路，一件赔案要跨 8 个菜单；菜单是系统能力目录，不是「我今天要干的活」。

D3

作业断点：6 页先手输 ID

6 个单案页用 CaseIdBar；全仓 navigate() 0 处带 claimId ⇒ 0 条案件级深链；8 环节 ≥14 次无价值操作。

D4

查询缺口

claimApi 零 keyword 检索；进度页只认纯数字案件 ID；筛选在 5 个页面各写一遍，无保存视图。

D5

效率设施缺失

0 个 rowSelection、0 个 onKeyDown；详设里「审核疲劳防控四项」只在文档、未上屏。

D6

AI 悬空

AiSuggestion 前端 0 展示、采纳/驳回 0 回流；对话式 ClaimAssistant 三端点已实现但前端 0 引用。

二、v2.0 实证补正：两条会推翻原方案的事实

这不是保守，而是避免「配了不生效」和「假成功」。

① 仓库里没有理赔业务角色码

bone-init.sql:281-285 只有 SUPER_ADMIN / USER / TENANT_ADMIN_demo；uat/gen.py:239-252 是 12 个平台通用 DEMO_* 角色。照字面做「按角色渲染」只能拿到空数组。
裁定：改用权限码能力画像 —— 写权限码是运行时唯一有区分度的信号；角色码降为未来 IAM 下发后的可选优先信号。

② 后端没有 AI 建议采纳端点

bone-ai 的 HitlController 有 confirm/reject/modify 与 ReasonType 四值，但网关不转发 /api/ai/v1/**。发一个必然 404 却提示「已保存」＝假绿。
裁定：先落结构化本地事件，事件带 persisted:false / backendContract:'pending'，界面明写未落库；端点就绪后在事件总线一处接线。

三、信息架构：15 条平铺 → My Home 四空间

Fiori Launchpad 的 role-based 落点是首页，不是菜单树。

现状 · 按流程环节平铺

  • 15 条一级叶子，顺序＝初审→核赔→理算→材料→资金→申诉→挂起→后督
  • 默认落点「核赔工作台」对所有人一样
  • 可见性只看权限码，角色无维度
  • 换菜单丢一次上下文、重输一次 19 位 ID
  • AI 治理 / 盲标藏在 hidden 面板，靠核赔页两个按钮进入
→

目标 · 按「人今天要办什么事」

  • 我的工作台为默认落点：4 个 Section（作业 / 查询 / 配置 / 治理），按画像排序
  • 侧栏常驻四空间分组标题：15 条菜单不折叠、不减条目、可直接点击任一功能
  • 一套骨架 + 能力画像卡片，不复制 N 套菜单
  • 案件 360：?claimId=&tab= 单一 case record，7 个深链 Tab 自动带 ID
  • ⌘K 命令面板常驻 shell 顶栏，只取 IAM 可见菜单
  • AI 结论卡进主决策面；治理按画像给入口
侧栏怎么分组？ 取 NN/g 隐藏导航实测结论：可见导航可发现性 48–50%、隐藏式仅 27%（降 >20%）、完成任务时间 +39%——故采用常驻可见的四空间分组标题（作业 / 查询 / 配置 / 治理），不折叠、不减条目、不改顺序、不动 permission 与 0078 SIGNAL；菜单数据、权限、后端契约一律未动，撤菜单另立 change。当前实现：可见 15 条菜单与顺序完全不变，仅展示层加分组标题，新增两条 hidden 路由。

六、AI 深度融合：从「一个面板」到「每一屏的一层」

L1 建议进主决策面 P0+后端联调已落地

结论 + 依据 + 五要素 + 可解释 trace + AI 参与显著标识；采纳 / 驳回（必选原因码）/ 修改后采纳，曝光/裁决已落库 append-only 表并经网关真机联调。金额与资金仍由确定性引擎计算，AI 卡只读。

L2 Copilot 常驻 P1

接已有 ClaimAssistant 三端点，上下文自动带 claimId；工具白名单不含拒赔 / 调账 / 支付。

L3 主动推送 P1–P2

高风险 / 重复发票 / OCR 低置信 / SLA 临期 / 质检 DIFF 进待办，每条带「为什么推给我」。

L4 治理可见 P2

采纳率、驳回原因分布、校准曲线、漂移 PSI、评测集覆盖上屏；P0 已在工作台 Govern Section 按画像给入口。

分级自动化（不可让步）：全自动 STP＝低风险小额 + 事后 100% 质检；人工确认后生效＝自动通过建议；仅建议、人做终审＝拒赔 / ≥1 万 / FRAUD / 质检 DIFF。禁批量：拒赔、调账、支付、恢复 FRAUD 挂起、≥1 万复核。
