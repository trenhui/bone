# synapClaim 理算引擎验证套件（场景 · 探针 · 变异）

> **定位**：理算能力**唯一验证资产真源**。合并原先三处分散的验证材料——《理算引擎真实 TPA 场景测试用例与优化》的场景清单、《理算引擎内部设计》§7 的探针表、以及《业务细节与测试用例（深化篇）》第 3 章的用例矩阵——它们描述的是**同一套**验证资产（业务场景 / 性质探针 / 变异），分三处维护必然出现"用例以谁为准"的漂移。
>
> **可执行实现**：`doc/ai-product/synap-claim-oracle/synap-claim-settlement/`（JDK 21，`mvn test`）。本文所有编号、名称、期望值均取自该实现的源码，未做臆造。
>
> **口径校正**：既有文档对探针总数有 "P1–P28" 与 "P1–P30" 两种写法。实机核对为 **P1–P28 共 28 个编号、30 条断言**（P3/P3b 与 P5 正反双断言），本文以实机为准。
>
> **分界**：§2–§6 为**已实现可跑**（有代码、有确定性期望值）；§7 为**设计待建**（未实现，只给验收口径）。严禁把 §7 当作已通过。

## 1. 测试分层与"防假绿"纪律

| 层 | 目的 | 载体 | 现状 |
|---|---|---|---|
| L1 单元 | 单函数/策略正确 | JUnit | 有 |
| L2 性质 | 断言**不变式**（非巧合值） | `ProbeSuite` P1–P28 | ✅ 30 条断言全绿 |
| L3 变异 | "删掉实现哪一行会红" | 19 类 `EngineFlags` 变异 | ✅ 19/19 全被捕获 |
| L4 真实场景 | 端到端确定性期望 | `ScenarioSuite` S1–S28 | ✅ 28/28 通过 |
| L5 集成/契约 | 端口 / DB 方言 / Outbox | `JdbcPortsIntegrationTest`、`SqlDialectTest`、`OutboxRelayTest`、`JdbcPortsMySqlCompatTest` | 有 |
| L6 并发 | 租约 / 乐观锁 / 压测 | `ConcurrencyLockSeamTest`、`DbLeaseConcurrencyLockTest`、`...StressTest` | 有 |
| L7 流程 / 反欺诈 / AI / STP / 安全 | 编排层与横切面 | — | ❌ 设计待建（§7） |

**"防假绿"是本套件的核心纪律**：判据不是"用例数量够多"，也不是"正确引擎全绿"，而是**正确引擎全绿 且 每一类变异都被捕获**。有逃逸即判探针失辨（`runAll()` 在有逃逸时返回非零）。这条纪律来自一次真实教训：第一轮 20 个场景全通过、10 类变异全捕获，第二轮刻意去找"没有对应探针的维度"，又坐实 10 项缺陷（含 4 个 P0），其中 N10 是**被测试数据系统性掩盖的静默少赔**——详见《理算引擎诊断记录》。

## 4. 性质探针 P1–P28（30 条断言）

探针键名取自 `ProbeSuite.java` 的 `r.put(...)`，每条断言一个性质：

| 探针 | 断言的性质 | 变异对照（关掉即红） |
|---|---|---|
| `P1_integration` | 引擎**实际被调用**，产出 2 行且合计 > 0 | 双源漂移（不走 `SettleClaimUseCase`） |
| `P2_snapshotFreeze` | V1 理算后改源为 V2，用快照复算金额不变 | `livePlan` |
| `P3_negativeClamp` / `P3b_deductibleExceedsFee` | 负值钳零；免赔 > 费用不产负赔付 | `noRatioClamp`（类型层，不可关） |
| `P4_limitMin` | 三维限额 1000/800/500 → 实付 500 | `noMin` |
| `P5_noBonusWhenUnconfirmed` / `P5_bonusWhenConfirmed` | AI 未确认不加成；已确认 +10% | `ignoreConfirm` |
| `P6_portIsolation` | 占额/发布/trace 均经端口，引擎零 Feign/DB | 端口内联外部调用 |
| `P7_occupyInvariant` | `total == public + individual` | 分账漏账 |
| `P8_attribution` | 行级金额之和 == 合计（归因完备） | 归因缺失 |
| `P9_explainability` | 每条费用行含命中规则 ID + `explain()` 文本 | `noTrace` |
| `P10_accumDeductible` | 年度免赔跨案累计、作用于费用基数 | `noAccum` / `dedAfterRatio` |
| `P11_accumLimit` | 年度限额封顶语义、跨案累计 | `noAccum` |
| `P12_idempotency` | 同请求重复提交不双计 | `noIdem` |
| `P13_tenantIsolation` | 键含 `tenantId`，跨租户不串用 | `noTenantScope` |
| `P14_indemnityPrinciple` | 第三方已付先抵扣，赔付 + 已付 ≤ 总额 | `noIndemnity` |
| `P15_ratioClamp` | 赔付比例 ≤ 100%（含 AI 加成后） | `noRatioClamp` |
| `P16_deductibleBeforeRatio` | 免赔额先于比例（作用于费用基数） | `dedAfterRatio` |
| `P17_fraudHold` | 风控 P0 → HOLD，`reserveCalls == 0` | 风控未接理算 |
| `P18_accumulationConflict` | 累计乐观锁失配 → fail-closed | 无版本约束 |
| `P19_liabilityAccumulation` | 责任限额跨案累计 | `noLiabAccum` |
| `P20_recalculationReversal` | 重算先冲正旧占用 | `noReversal` |
| `P21_preAuthFrozen` | 预授权进 `frozen`，多次授权不超年限额 | `noPreAuthFrozen` |
| `P22_preAuthRemainingLiability` | 授权用**剩余**责任限额（非总额） | `totalLiabInPreAuth` |
| `P23_zeroAuthWhenAllRejected` | 无可赔费用 → 授权 0 | `authWhenAllRejected` |
| `P24_rejectRowZeroDeduct` | 拒赔行 `feeDeduct=0`（拒赔 ≠ 免赔） | `rejectDeductPollution` |
| `P25_idempotencyCAS` | 并发下幂等租约 CAS 生效 | `noCAS` |
| `P26_reversal` | `reverseSettlement` 回退三项占用 | `noReversal` |
| `P27_roundingApportionment` | 最大余数配平，逐行合计 == 总额口径 | `noApportion` |
| `P28_zeroMeansUnlimited` | `feeSubLimit=0` 视为未配置，正常赔付 | `zeroIsLimit` |

## 5. 19 类变异（防假绿门禁）

`EngineFlags` 每项对应一条护栏的"关掉开关"。**19 类全部被捕获**才允许合入；任一逃逸说明该护栏的测试判别力不足：

`noMin` · `livePlan` · `ignoreConfirm` · `noTrace` · `noAccum` · `noIdem` · `noTenantScope` · `noIndemnity` · `noRatioClamp` · `dedAfterRatio` · `noLiabAccum` · `noReversal` · `noPreAuthFrozen` · `totalLiabInPreAuth` · `authWhenAllRejected` · `rejectDeductPollution` · `noCAS` · `noApportion` · `zeroIsLimit`

> 变异套件是**资金类护栏的准入条件**：新增任一金额相关护栏，必须同时提交"关掉即红"的变异开关，否则视为未验证（不能只靠文档宣称）。

## 6. 边界场景索引（判定 → 用例）

| 边界场景 | 判定 | 处理 | 锚点 |
|---|---|---|---|
| 免赔额 > 费用额 | — | 赔付 0，不得负值 | P3b |
| 负金额输入 | 钳零 | `base=0` | P3 |
| 未配费用子限额（0） | `0 = 未配置` | 不作"限额为零"全额拒付 | S25 / P28 |
| 全部费用目录外 | 无可赔费用 | 直付授权 = 0 | P23 |
| 拒赔行 | `rejectType` 非空 | payout 0、免赔记 0、原因单列 | S26 / P24 |
| 补交发票 | 输入指纹变 | 冲正旧占用后重算 | S22 / P20 |
| 撤件 / 后督改判 | 存在旧结论 | `reverseSettlement` 归零 | S24 / P26 |
| 达封顶 | 累计 = 限额 | PARTIAL/REJECT 提示 + 通知书 | S6 |
| 并发重复提交 | 租约占用 | fail-closed | S28 / P25 |
| 并发累计冲突 | 版本失配 | CONFLICT 转重试/人工 | P18 |
| 跨租户同保单号 | `tenantId` 前缀 | 互不串用 | S20 / P13 |
| 多保单 / 共保 | 独立理算 | 按配置 | S13 |
| 风控 P0 | `fraudHold` | HOLD，不出金额不占额 | S18 / P17 |
