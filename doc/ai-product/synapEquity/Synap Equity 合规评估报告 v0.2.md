# Synap Equity 合规评估报告（MVP 版）

> **文档编号**：SE-COMP-001　**版本**：v0.2　**日期**：2026-10-14　**作者**：产品委员会
> **对应 PRD**：《Synap Equity 产品方案》v0.17 §14、附录 B「T1 合规评估报告」
> **定位**：回答两个问题——**① 我们做的是不是"持牌业务"？② 上线前必须做到哪些合规动作？** 本文是 B 端采购的准入证据，也是 C 端内容红线。
>
> ⚠️ **诚实边界**：本文为内部初步合规分析，**不构成法律意见**；正式上线（尤其 B 端签约）前须由外部证券法律顾问**复核并出具意见**。监管规则取值时点：2026-10，后续须跟踪更新。

## 1. 结论先行

| 结论 | 内容 |
|---|---|
| 产品定性 | **金融信息服务 / 研究辅助工具**，不属于证券投资咨询业务（**不持牌、不荐股、不代客理财**） |
| 合规可行 | ✅ C 端 Freemium 与研究卡片可行（前提：内容与产品严格隔离"建议"） |
| B 端可行 | ✅ 券商投顾工作台属"工具输出给持牌机构"，由持牌机构承担适当性责任（日志留痕为**合同必备条款**） |
| 三条红线 | ❌ 不荐股 ❌ 不导流开户 ❌ 不代客交易（触碰即定性为非法证券投资咨询/变相营销） |
| 最大风险 | 内容"越界"（把研究结论表述成投资建议）；须以**内容三态 + AI 标识 + 免责声明**三重机制约束 |

## 2. 产品定性与监管依据

### 2.1 定性论证

| 判断项 | 结论 | 依据 |
|---|---|---|
| 是否证券投资咨询业务 | **否** | 不针对具体证券提供"买入/卖出"建议，**不收取证券投资咨询费用；订阅费为研究工具使用费**；仅提供估值计算工具与信息整理 |
| 是否需持牌 | **否**（C 端工具）；B 端由机构持牌承接 | 工具属性 + 输出为"规则解释与状态匹配度"，非投资建议 |
| 是否涉及资产管理 | **否** | 不代客理财、不碰资金、不提供交易通道 |
| 是否涉及上市公司信息披露 | **用公开信息**，不涉及内幕 | 仅使用 A 级公开披露数据 |

> **收费口径（与《产品方案》§15.8 逐字一致）**：**不收取证券投资咨询费用；订阅费为研究工具使用费**。区分标准三条：① 收费对应功能清单限于数据/档案/提醒工具；② 不含个别化投资建议；③ 不承诺收益、不与收益挂钩。
>
> **定性前提（2026-10-14 补）**：上述"工具属性 / 不涉投资咨询"为**待专项法律意见确认的假设，非最终定性**；费用名目**不构成**定性依据——监管按功能实质认定，边界以"不构成对具体证券的价值/时机/仓位建议"为唯一标尺（§2.3 荐股软件红线同步约束）。

### 2.2 主要监管规则（取值 2026-10）

| 规则 | 关键约束 | 对我们的影响 |
|---|---|---|
| 《证券法》《证券、期货投资咨询管理暂行办法》 | 未经许可不得从事证券投资咨询 | 产品不得输出"建议买卖某证券" |
| 《证券基金投资咨询业务管理办法》 | 投顾业务须持牌、须适当性管理 | B 端由券商持牌主体承担，我们仅提供工具 |
| 《金融产品网络营销管理办法》（2026 施行） | 第三方不得为金融机构产品变相营销、导流 | **不做开户导流**，不做"点击开户"类设计 |
| 《互联网信息服务深度合成管理规定》《生成式 AI 服务管理暂行办法》+ AI 内容标识办法 | AI 生成内容须标识 | 报告/卡片含 AI 生成部分**须显式标识** |
| 《个人信息保护法》《数据安全法》 | 最小必要、告知同意、安全存储 | 用户数据加密、不用于训练、可注销 |
| 《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》 | 提供具体投资品种选择 + 买卖时机建议的功能即属荐股软件，**无论是否收费**，须证券投资咨询资质 | 策略模块输出限定为"标的状态匹配度 + 规则陈述"，禁用"分档买入/高估减持"类表述 |
| 交易所/巨潮披露规则 | 公开披露信息可合法使用 | A 级数据源合规 |

---

### 2.3 红线清单（P0，2026-10-14 业界实践复核修订新增）

**规则**：《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》——**提供具体投资品种选择 + 买卖时机建议的功能即属荐股软件，无论是否收费**，须取得证券投资咨询资质。

**执法口径（外部案例，仅作风险提示，非本文法律意见）**：

- 无资质销售荐股软件，曾以**非法经营罪**追责；
- "金投顾"类软件因具备**品种选择**与**提示买卖时机**功能，被责令**暂停新增客户**。

**对 FR-S1/S2 的处置（已同步《产品方案》§7.6）**：

1. 策略模块输出措辞统一为"**标的状态匹配度 + 规则陈述**"；
2. "分档买入 / 高估减持"改为"**纪律规则说明**（不构成买卖建议，页面同屏展示方法与局限）"；
3. MVP **延后**"分档买入纪律"引导文案（随 P1 完整版上线，MVP 不展示）；
4. §10 待确认清单增列"FR-S1/S2 输出文案专项法律意见"。

## 3. 三条红线（硬约束，写入产品与内容规范）

| 红线 | 具体禁止 | 产品侧落地 |
|---|---|---|
| ❌ 不荐股 | 不得出现"买入/卖出/加仓/目标价达 XX 可买"等指令性表述；不得推荐具体标的 | 策略引擎只输出"规则解释 + 状态匹配度"；文案库禁用词校验；无"推荐池" |
| ❌ 不导流开户 | 不得嵌入券商开户链接、不得为产品导流 | 全文无开户入口；分享内容无导流按钮 |
| ❌ 不代客交易 | 不接交易通道、不碰资金 | 无下单能力；无资金账户体系 |

## 4. 内容三态设计（核心合规机制）

> 按"公域认知 / 私域讲解 / 账户服务"三态区分内容边界（对应 PRD §3.3 口径）。

| 内容态 | 定义 | 允许内容 | 禁止内容 |
|---|---|---|---|
| **公域认知**（对外传播） | 公众号/雪球/知乎等公开内容 | 估值方法科普、"如何用工具研究一只股票"、案例复盘（**不列具体买卖建议**） | 具体标的目标价、"现在可以买 XX" |
| **私域讲解**（用户自用） | 登录后的研究卡片/报告 | 单标的估值区间、假设、风险、档位状态（**客观陈述 + 数据溯源**） | 指令性建议、"建议买入" |
| **账户服务**（B 端机构） | 投顾工作台（机构持牌场景） | 研究卡片 → 投顾建议稿（**由持牌投顾判断与署名**）、合规留痕 | 系统自动生成对外投资建议 |

**关键**：B 端建议稿中"建议"的主体是**持牌投顾本人**，系统仅提供素材与留痕，不替投顾做决策（"AI 准备、人决策、全程留痕"）。

## 5. AI 内容标识（显式 + 隐式）

| 类型 | 要求 | 落地 |
|---|---|---|
| 显式标识 | 用户可感知的提示 | 报告/卡片含"本内容由 AI 辅助生成，数据由确定性引擎计算，仅供研究参考" |
| 隐式标识 | 元数据标记 | 生成内容 metadata 含 AI 标识字段（供应商/时间/标识码） |
| 数字免责 | 区分"计算"与"生成" | 明确标注：**数字来自确定性引擎（可复算），文字由 AI 组织** |
| 免责声明 | **双层** | 注册/付费流程内**显著提示**（《民法典》第 496 条格式条款提示义务）+ 页面底部/报告页脚**常驻**"研究性内容，不构成投资建议" |

## 6. 数据合规（复用 PRD FR-D1 分级）

| 级别 | 来源 | 合规动作 |
|---|---|---|
| A 级 | 公开披露 | 标注来源，合法使用 |
| B 级 | 数据商 | 签署授权协议，约定用途/期限/排他 |
| C 级 | 爬取 | **禁止** |
| 用户数据 | 自选池/组合/反馈 | 最小必要收集、加密存储、**不用于模型训练**、支持导出与注销 |

---

## 7. 广告与营销合规（C 端获客红线）

| 事项 | 要求 |
|---|---|
| 内容营销 | 公域内容须走三态中的"公域认知"边界，**发布前合规词审查**（禁用"稳赚/必涨/推荐买入"等） |
| 效果宣传 | 不得承诺收益；胜率/区间命中率展示须注明样本口径与"历史不代表未来" |
| 付费推广 | 若投放，须符合广告法；金融类投放平台有额外资质要求（评估后再定） |
| 自媒体合作 | 合作内容同样受"不得变相荐股"约束，需合同约定 |

---

## 8. B 端合规要点（券商投顾工作台）

| 要点 | 落地 |
|---|---|
| 责任划分 | 合同明确：系统为工具，投资建议由机构持牌投顾作出并署名 |
| 集中统一决策 | 支持机构"统一观点库"，投顾不自行生成对外建议（对应监管导向） |
| 全程留痕 | 建议稿含证据链、假设、时间戳，可导出审计；**日志留痕为合同必备条款（非加分项）**：工具方操作日志保存 **≥1 年**；投顾机构侧资料按其监管要求由**机构**保存，保存期责任分界写入合同 |
| 数据不出机构 | 私有化部署，数据存机构内网 |
| 品牌与标识 | 机构品牌化；AI 标识按机构合规要求配置 |

## 10. 风险与待确认

| 风险 | 等级 | 对策 |
|---|---|---|
| "研究结论"被认定为"投资建议" | 中-高 | 三态 + 禁用词 + 免责三重约束；定期内容抽检 |
| 监管细则更新（投资咨询办法修订等） | 中 | 合规顾问跟踪；产品边界按最新口径调整 |
| 效果指标被质疑为"收益承诺" | 中 | 一律注明样本口径 + 历史不代表未来 |
| 平台（微信/应用市场）类目限制 | 中 | 载体走 Web（PRD §4.4），规避金融类目审核 |

> **待确认（须外部法律顾问复核）**：① "估值区间"展示是否构成投资建议的边界；② 提醒功能（价格进入区间）是否被视为"择时建议"；③ B 端建议稿的署名与责任划分表述；④ 是否需办理 ICP/相关备案；⑤ FR-S1/S2 输出文案专项法律意见（见 §2.3）。
