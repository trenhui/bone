# Synap Equity 测试与评测方案

> **文档编号**：SE-TEST-001　**版本**：v0.2　**日期**：2026-10-14　**作者**：产品委员会
> **对应 PRD**：《Synap Equity 产品方案》v0.17 §7.5/§13、FR-Q1、附录 B「T1 测试方案」
> **配套**：《估值方法学 v0.2》《技术方案 v0.2》
> **定位**："结果我验"的落地机制——把 PRD 的质量指标（字段提取 ≥95%、引用 ≥98%、可复算 100%）变成**可运行的门禁**，而非口号。

---

## 1. 测试分层总览

| 层 | 目标 | 工具 | 门禁 |
|---|---|---|---|
| L1 单元测试 | 引擎数学正确性、幂等、边界 | pytest | 必须 100% 通过 |
| L2 契约测试 | API 入参/出参/溯源字段 | pytest + schemathesis | 必须通过 |
| L3 数据校验测试 | 快照口径、勾稽、防泄漏 | pytest | 必须通过 |
| L4 集成测试 | 取数→估值→卡片→档案→对账全链路 | pytest | 必须通过 |
| L5 评测（质量） | 字段提取、引用正确率、方向命中 | 评测脚本 + 黄金集 | 阈值达标 |
| L6 提醒测试 | 漏报/误报率 | 回放脚本 | 漏报 ≤5%、误报 ≤10% |
| L7 性能与安全 | 响应时间、并发、越权 | locust + 手工 | 见 §7 |

---

## 2. L1 估值引擎测试（最关键）

| 用例类型 | 内容 | 期望 |
|---|---|---|
| 幂等 | 同 `(快照, 参数)` 执行 100 次 | 输出逐位一致 |
| 精度 | Decimal 定点化，金额 2 位/比率 4 位 | 无浮点漂移 |
| 区间锚定 | 交集非空/空/PE≤0 三类 | 分别正常/降级标注/转 PB |
| 主法判定 | 盈利/亏损/金融/净资产为负 | 正确选择主法或拒绝产出 |
| DCF 边界 | g ≥ WACC、g > 5%、n 越界 | 拒绝或钳制 |
| 缺失降级 | 扣非缺失、TTM 不足 4 季 | 降级 + 标注，不臆造 |
| 三情景 | 基准=3y CAGR、×0.5、×1.3 | 数值正确 |
| 档位映射 | 价格 vs 区间三分档 | 正确归类 |

**属性测试（property-based）**：随机生成合法财报输入，断言 `fair_low ≤ fair_mid ≤ fair_high` 恒成立。

---

## 3. L3 数据校验与防泄漏测试

| 用例 | 期望 |
|---|---|
| `as_of` 早于披露日 | 数据不可见（拒绝消费） |
| 快照被"修改" | 不可变约束生效，只能追加新版本 |
| 重述处理 | 生成新快照版本，历史不变 |
| 勾稽不平 | 软校验标注"待复核"，不阻断 |
| 未来数据注入 | 审计脚本检出（抽查披露时间戳） |
| 分位数/同业对比/散点使用未来时点数据 | 同样受 `as_of` 约束（计算时点审计，防前视偏差——不只财报/行情快照） |

---

## 4. L4 全链路集成测试

```text
取数(Mock)→ 校验 → 快照 → 估值 → 数字注入 → 卡片生成 → 发布档案 → 对账 → 误差入库
```

**关键断言**：① 卡片每个数字命中注入清单；② 档案版本链完整；③ 对账误差正确入评测库；④ 无未来数据参与。

---

## 5. L5 质量评测（对应 PRD §13.1）

| 指标 | 目标 | 评测集 | 方法 |
|---|---|---|---|
| 字段提取准确率 | ≥95% | 10 标的×4 期（40 份） | 与人工核对答案逐字段比对 |
| 引用正确率 | ≥98% | 每期抽 20 条 | 引用是否支持结论 |
| 报告数字可追溯率 | 100% | 全量 | 数字清单校验 |
| 估值可复算率 | 100% | 全量 | 幂等测试 |
| 提醒漏报率 | ≤5% | 回放触发实例 | 应触发未触发占比 |
| 建议稿留痕完整性 | 无来源结论=0 | B 端抽检 | 结论-来源可追溯 |

**黄金标注集建设**：40 份财报答案由懂财报成员从巨潮原始 PDF 人工核对（约 2–3 人天），标注人/时间/修订理由留痕（Backlog 裁剪项生效时降为 ≥20 份，缺口列 P1 补齐）。

**幸存者偏差与 ground truth（2026-10-14 补）**：
- **回放样本必须含退市/ST 标的**：种子池全为存续标的会高估策略表现——FR-S4 回测的防幸存者偏差要求同样适用于 L5 回放（至少补 2 只历史退市标的完整用例）；
- **估值误差 ground truth**：市价 ≠ 公允价值，“区间命中”以 **12 个月后可观测价格区间**为可观察代理（本产品 A 级数据无一致预期源，不引用一致预期区间），仅作观测指标、不作发布闸门（发布闸门仍为字段/引用/可追溯等可验证指标）；
- **抽样节奏**：季报频率下“每标的 ≥10 期”需 2.5 年，MVP 阶段按“每标的全量可得期数（≥4 期）”执行，≥10 期列 P1。

## 6. LLM 数字注入与拦截测试

| 用例 | 期望 |
|---|---|
| 正常生成 | 报告数字全部命中注入清单 |
| 模型编造数字 | **被拦截**（数字不在清单）→ 重试 → 仍失败则降级纯模板 |
| 引用越界 | 引用不存在的数据源 → 拒绝 |
| 缺少假设 | 无假设 → `422` 拒绝产出 |

**拦截率指标**：编造数字拦截率 = 100%（抽取注入测试集验证）。

---

## 7. L7 性能与安全

| 项 | 目标（MVP） |
|---|---|
| 估值计算响应 | < 2s（单标的，本地） |
| 卡片生成（含 LLM） | < 30s |
| 并发 | 种子内测 20 用户，无阻塞 |
| 越权 | 用户只能访问自己自选池/提醒 |
| 密钥 | 不入仓、不入库 |

---

## 8. CI 门禁流水线

```text
push → L1/L2/L3 单元与契约测试
     → L4 集成测试（Mock 数据）
     → L5 评测（黄金集，夜间/发布前）
     → 指标达标？ → 允许发布
                 → 否则阻断并报告差异
```

**发布铁律**：任何一项质量指标低于阈值，版本**禁止发布**（PRD §13.3）。
